# AWS 常時無料サービス 一覧 (Always Free Services)

Amazon Web Services の常時無料枠（Always Free Services）はアカウント作成後の12ヶ月間のみ利用できる無料枠（Free Tier）とは異なり、**一定の使用量までは期限なく無料**で利用できるサービス群です。完全に無制限で無料というわけではなく、各サービスごとに定められた無料枠を超えた場合は従量課金が発生します。

本記事では、AWS公式が公開している常時無料対象サービスを一覧で整理しています。個人開発・学習・コスト最適化の参考として活用してください。

👉 English version: https://zenn.dev/good_sleeper/articles/aws-always-free-en

## 💻 コンピューティング

### AWS Lambda

AWS Lambdaは、サーバーのプロビジョニングや管理を一切行わずに、イベントに応答してコードを実行できるサービスです。例えば、S3バケットにファイルがアップロードされた際に自動で画像のリサイズを行ったり、API Gatewayと連携してサーバーレスなWeb APIを構築したり、データベースの変更をトリガーに通知を送信するといった多様な用途で活用できます。これにより、開発者はインフラ管理から解放され、アプリケーションロジックの開発に集中できます。

🔗 https://aws.amazon.com/jp/lambda/?did=ft_card2&trk=ft_lambda

## 🧱 データベース

### Amazon Aurora DSQL

Amazon Aurora DSQLは、常時利用可能なアプリケーション向けに、最速でスケーラブルなサーバーレス分散SQLデータベースを提供します。これにより、急激なトラフィック増加にも自動的に対応し、高い可用性とパフォーマンスを維持しながら、データベースの運用管理負荷を大幅に軽減できます。例えば、ECサイトのバックエンド、SaaSアプリケーション、IoTプラットフォームなど、予測困難なアクセスパターンを持つワークロードに最適であり、開発者はインフラ管理に煩わされることなく、アプリケーション開発に集中できます。

🔗 https://aws.amazon.com/jp/rds/aurora/dsql/?did=ft_card2&trk=ft_dsql

---

### Amazon SimpleDB

Amazon SimpleDB は、Web アプリケーションなどのデータ保存を容易にする、柔軟でスケーラブルな NoSQL データベースサービスです。プロビジョニングやパッチ適用などのデータベース管理作業が不要なため、開発者はアプリケーション開発に集中できます。例えば、ユーザープロファイル、設定情報、製品カタログなどのデータを保存するのに適しており、データ構造が頻繁に変化する場合でも容易に対応できます。高い可用性と耐久性を備え、必要に応じて自動的にスケールするため、予期せぬトラフィックの増加にも安心してお使いいただけます。

🔗 https://aws.amazon.com/jp/simpledb/?did=ft_card2&trk=ft_simpledb

## 🧩 アプリケーション統合

### Amazon Cognito

Amazon Cognitoは、Webおよびモバイルアプリケーション向けに、シンプルかつセキュアなユーザーのサインアップ、サインイン、そしてアクセス制御を可能にするサービスです。開発者は、 Cognitoを利用することで、ゼロから認証システムを構築する手間を省き、ユーザー管理やセキュリティに関する複雑な実装をAWSに任せることができます。例えば、ソーシャルログイン（Google, Facebookなど）やカスタム認証フローを容易に実装でき、アプリケーションのユーザーエクスペリエンスを向上させながら、不正アクセスからユーザーデータを保護します。これにより、開発者はアプリケーションのコア機能開発に集中できるようになります。

🔗 https://aws.amazon.com/jp/cognito/?did=ft_card2&trk=ft_cognito

---

### Amazon DynamoDB

Amazon DynamoDBは、あらゆる規模で1桁ミリ秒のパフォーマンスを提供するサーバーレスでフルマネージドなNoSQLデータベースです。これにより、ウェブサイトのセッション管理、リアルタイムのゲームスコア、IoTデバイスからのデータ収集など、高速かつスケーラブルなデータストレージが必要なアプリケーションを構築できます。サーバーレスであるため、インフラストラクチャの管理はAWSに任せ、アプリケーション開発に集中できます。また、自動スケーリング機能により、トラフィックの増減に合わせてパフォーマンスを維持し、コスト効率の良い運用が可能です。

🔗 https://aws.amazon.com/jp/dynamodb/?did=ft_card2&trk=ft_dynamodb

---

### Amazon EventBridge

Amazon EventBridgeは、AWSサービス、既存のシステム、SaaSアプリケーションにわたるイベント駆動型アプリケーションを大規模に構築するための、サーバーレスなイベントバスサービスです。これにより、アプリケーションのコンポーネント間でイベントをルーティングし、連携させることが可能になります。例えば、S3バケットにファイルがアップロードされたことをトリガーにLambda関数を実行してデータを加工したり、EC2インスタンスのステータス変更を検知して自動的に通知を送信するといった、様々なユースケースで活用できます。EventBridgeは、イベントのフィルタリングやルーティングを柔軟に行えるため、疎結合でスケーラブルなシステム設計を実現する上で重要な役割を果たします。

🔗 https://aws.amazon.com/jp/eventbridge/?did=ft_card2&trk=ft_eventbridge

---

### Amazon SNS

Amazon SNSは、アプリケーション、システム、デバイス間でメッセージを迅速かつ柔軟に配信できる、完全マネージド型のプッシュメッセージングサービスです。このサービスを利用することで、例えば、ECサイトで注文が確定した際に顧客にSMSで通知したり、システム障害発生時に運用担当者へメールでアラートを送信したりすることが可能です。また、異なるアプリケーション間でのイベント駆動型の連携や、モバイルアプリへのプッシュ通知配信など、多様なユースケースに対応できます。開発者はインフラ管理の手間なく、メッセージング機能を手軽に実装・拡張することができます。

🔗 https://aws.amazon.com/jp/sns/?did=ft_card2&trk=ft_sns

---

### Amazon SQS

Amazon SQSは、アプリケーションコンポーネント間でやり取りされるメッセージを、信頼性高く、スケーラブルに管理できるキューイングサービスです。これにより、分散システムにおけるコンポーネント間の疎結合を実現し、処理の遅延や一時的な障害からアプリケーションを保護します。例えば、Webサーバーが大量のデータ処理リクエストを受け取った際に、SQSキューにメッセージを投入することで、バックエンドの処理システムがキューからメッセージを順次取り出して処理することができ、Webサーバーの応答性低下を防ぎます。また、マイクロサービスアーキテクチャにおいて、サービス間の非同期通信基盤としても活用されます。

🔗 https://aws.amazon.com/jp/sqs/?did=ft_card2&trk=ft_sqs

---

### Amazon SWF

Amazon Simple Workflow Service (SWF) は、クラウドアプリケーションにおける複雑なワークフローの実行を調整し、その状態を管理するためのサービスです。これにより、複数のマイクロサービスやアプリケーションコンポーネントが連携して実行される処理の、開始から完了までを確実に追跡・管理できます。例えば、オンラインショッピングの注文処理において、在庫確認、決済処理、出荷指示といった一連のステップをSWFで管理することで、各ステップの成功・失敗を検知し、必要に応じて再実行やエラーハンドリングを行うことができます。このサービスは、人手による確認や承認が必要なワークフローや、長時間実行される処理、または失敗から回復する必要がある処理に適しています。

🔗 https://aws.amazon.com/jp/swf/?did=ft_card2&trk=ft_swf

---

### AWS Step Functions

AWS Step Functionsは、分散アプリケーションのコンポーネントを視覚的にオーケストレーションし、耐久性のあるワークフローを構築できるサーバーレスなサービスです。これにより、マイクロサービス、AWS Lambda関数、その他のAWSサービスを組み合わせた複雑な処理の流れを、コードを書かずに定義・管理できます。例えば、ECサイトでの注文処理において、在庫確認、決済、配送手配といった一連のタスクを状態遷移図で定義し、各ステップの成功・失敗に応じて自動的に処理を進めることが可能です。これにより、開発者はビジネスロジックに集中でき、ダウンタイムの最小化やエラーハンドリングの自動化を実現します。

🔗 https://aws.amazon.com/jp/step-functions/?did=ft_card2&trk=ft_stepfunctions

## 🌐 ネットワーク

### Amazon CloudFront

Amazon CloudFrontは、世界中に分散されたエッジロケーションを利用して、ウェブサイトやアプリケーションのコンテンツをエンドユーザーの近くにキャッシュし、低レイテンシーかつ高速なデータ転送を実現するコンテンツデリバリーネットワーク（CDN）サービスです。これにより、動画ストリーミング、ゲーム、ソフトウェアのダウンロード、ウェブアプリケーションの高速化など、応答速度が求められるあらゆるユースケースで、ユーザーエクスペリエンスを劇的に向上させることができます。例えば、グローバルに展開するECサイトでは、世界中の顧客に対して商品画像やページを瞬時に表示し、購買体験をスムーズにします。

🔗 https://aws.amazon.com/jp/cloudfront/?did=ft_card2&trk=ft_cloudfront

---

### Amazon Route 53

Amazon Route 53 は、ドメイン名の登録、DNS ルーティング、およびヘルスチェックを統合的に提供する、高可用性かつスケーラブルなクラウド DNS ウェブサービスです。これにより、ユーザーはインターネット上で Web サイトやアプリケーションを簡単に公開・運用できます。例えば、Web サイトのトラフィックを複数のサーバーに分散させたり、異常を検知して正常なサーバーに自動的にルーティングするフェイルオーバー機能を実装したりすることが可能です。また、グローバルなインフラストラクチャを活用し、低レイテンシーでの名前解決を実現するため、世界中のユーザーに快適なアクセス体験を提供します。

🔗 https://aws.amazon.com/jp/route53/?did=ft_card2&trk=ft_route53

## 🔐 セキュリティ

### AWS Certificate Manager

AWS Certificate Manager (ACM) は、AWS、ハイブリッド、マルチクラウド環境で SSL/TLS 証明書を簡単にプロビジョニング、管理、デプロイできるサービスです。これにより、ウェブサイトやアプリケーションへの安全な接続を確立し、データの暗号化を確保できます。例えば、Elastic Load Balancing (ELB) や Amazon CloudFront と連携させることで、インターネットに公開するリソースのセキュリティを強化し、ユーザーに信頼感を提供します。ACM を利用すれば、手動での証明書購入、更新、インポートといった煩雑な作業から解放され、セキュリティ管理の負担を大幅に軽減できます。

🔗 https://aws.amazon.com/jp/certificate-manager/?did=ft_card2&trk=ft_certmanager

---

### AWS Key Management Service

AWS Key Management Service（KMS）は、AWS内外のデータ保護を容易にする、フルマネージドな暗号化キー管理サービスです。KMSを使用すると、暗号化キーの作成、管理、使用を安全かつ効率的に行うことができ、データの機密性とコンプライアンスを確保します。例えば、Amazon S3に保存するデータの暗号化、Amazon RDSデータベースの保護、カスタムアプリケーションにおける機密情報の暗号化など、幅広いユースケースで活用されます。KMSは、AWSの他のサービスとシームレスに連携し、FIPS 140-2検証済みのハードウェアセキュリティモジュール（HSM）によって保護されたキーを使用するため、高いセキュリティレベルを提供します。これにより、開発者は複雑な暗号化の実装やキー管理の負担から解放され、ビジネスロジックの開発に集中できます。

🔗 https://aws.amazon.com/jp/kms/?did=ft_card2&trk=ft_kms

---

### AWS Resource Access Manager

AWS Resource Access Manager（RAM）は、AWSアカウント間またはAWS組織内のリソースを安全かつ効率的に共有できるサービスです。これにより、例えば、複数のAWSアカウントで共有したいVPC、Amazon Machine Image（AMI）、Systems Managerパラメータなどのリソースを、手動でコピーしたり、複雑なアクセス権限設定を行うことなく、集中管理で共有できます。例えば、開発環境と本番環境でAMIを共有したり、組織内の全アカウントで共通のセキュリティグループを共有するなどのユースケースが考えられます。RAMを利用することで、リソースの重複を防ぎ、管理の手間を削減し、セキュリティポリシーの一貫性を保つことが可能になります。

🔗 https://aws.amazon.com/jp/ram/?did=ft_card2&trk=ft_resourceaccess

---

### AWS Shield

AWS Shieldは、ネットワークセキュリティ設定の分析とマネージドDDoS（分散型サービス拒否）保護により、お客様のネットワークとアプリケーションを保護するサービスです。これにより、悪意のあるトラフィックからウェブサイトやアプリケーションを常時稼働させ、ビジネスの中断を防ぎます。例えば、大規模なDDoS攻撃を受けた場合でも、AWS Shieldは自動的に脅威を検知・緩和し、通常のトラフィックが顧客に届くようにします。ゲーム、eコマース、金融サービスなど、高い可用性が求められるあらゆるユースケースで、安定したサービス提供を支える重要な役割を果たします。

🔗 https://aws.amazon.com/jp/shield/?did=ft_card2&trk=ft_shield

---

### AWS WAF Bot Control

AWS WAF Bot Controlは、一般的なウェブボットからウェブアプリケーションを保護し、不正なトラフィックをブロックすることで、ウェブサイトのパフォーマンス低下や悪意のある攻撃を防ぎます。例えば、コンテンツスクレイピング、アカウント乗っ取り、DDoS攻撃などに利用されるボットを検知・軽減することが可能です。これにより、正規のユーザー体験を損なうことなく、セキュリティを強化し、ビジネスの継続性を確保することができます。

🔗 https://aws.amazon.com/jp/waf/features/bot-control/?did=ft_card2&trk=ft_WAFbc

## 📊 データ分析

### Amazon DataZone

Amazon DataZoneは、組織内のあらゆる部門や外部パートナーが、組み込みのガバナンス機能を利用して安全かつ簡単にデータを発見、共有、利用できるサービスです。例えば、マーケティング部門が顧客データを分析し、新製品開発部門がその結果を基に製品戦略を立案するといった、部門を横断したデータ活用を促進します。これにより、データのサイロ化を防ぎ、データに基づいた意思決定を加速させることができます。

🔗 https://aws.amazon.com/jp/datazone/?did=ft_card2&trk=ft_datazone

---

### Amazon OpenSearch Service

Amazon OpenSearch Serviceは、インタラクティブなログ分析、リアルタイムのアプリケーションモニタリング、ウェブサイト検索といった高度なユースケースを、マネージドサービスとして容易に実現できるサービスです。このサービスを利用することで、開発者やデータアナリストは、インフラストラクチャの管理に煩わされることなく、データの検索、可視化、分析に集中できます。例えば、ウェブサイトのトラフィックをリアルタイムで分析してユーザー行動を理解したり、アプリケーションのログを収集・分析して問題の早期発見やパフォーマンス改善に役立てたりすることが可能です。

🔗 https://aws.amazon.com/jp/opensearch-service/?did=ft_card2&trk=ft_opensearch

---

### AWS Glue

AWS Glueは、データレイクやデータウェアハウスの構築を容易にする、フルマネージドなETL（抽出、転送、ロード）サービスです。データカタログ機能でメタデータを一元管理し、サーバーレスなETLジョブを実行できるため、インフラ管理の手間なく、様々なデータソースからデータを抽出し、変換・加工してAmazon S3やAmazon Redshiftなどのデータストアにロードできます。これにより、ビッグデータ分析基盤の構築や、ビジネスインテリジェンスレポート作成のためのデータ準備を効率的に行うことが可能です。

🔗 https://aws.amazon.com/jp/glue/?did=ft_card2&trk=ft_glue

## 🧠 AI

### Amazon Q Developer

Amazon Q Developerは、ソフトウェア開発を支援する生成AI搭載のアシスタントです。コードの生成、バグの検出、既存コードの分析、ドキュメント作成などを効率化し、開発者の生産性を向上させます。例えば、新しい機能のコードを迅速に作成したり、複雑なシステムのエラー箇所を特定したり、既存のコードベースの理解を深めたりする際に活用できます。これにより、開発者はより創造的な作業に集中できるようになり、開発ライフサイクル全体のスピードアップに貢献します。

🔗 https://aws.amazon.com/jp/q/developer/?did=ft_card2&trk=ft_q

### AWS HealthLake

AWS HealthLakeは、ヘルスケアおよびライフサイエンス分野の顧客が、安全かつコンプライアンスに準拠した方法で、医療データを数分で保存、変換、取引、分析できるマネージドサービスです。このサービスは、FHIR（Fast Healthcare Interoperability Resources）標準に基づいて構築されており、さまざまなソースからの電子健康記録（EHR）データを標準化された形式で取り込み、クエリおよび分析を容易にします。これにより、医療機関は患者のケアを改善するための洞察を得たり、研究者は新たな発見を加速させたりすることが可能になります。例えば、複数の病院システムにまたがる患者の包括的なタイムラインを作成し、個々の患者の健康状態をより深く理解するために活用できます。

🔗 https://aws.amazon.com/jp/healthlake?did=ft_card2&trk=ft_healthlake

## 🛠️ 開発者ツール

### Amazon CodeCatalyst

Amazon CodeCatalystは、AWS上でアプリケーションを大規模かつ迅速に構築・配信するための統合開発環境です。開発者は、CI/CDパイプラインの自動化、コードリポジトリ、プロジェクト管理、インフラストラクチャのプロビジョニングなどを、直感的なUIを通じて単一のプラットフォームで実現できます。例えば、マイクロサービスアーキテクチャの構築において、コードのコミットからテスト、デプロイまでの一連のプロセスを自動化し、開発チームの生産性向上と市場投入までの時間短縮に貢献します。これにより、開発者はインフラ管理から解放され、より本質的な開発業務に集中できるようになります。

🔗 https://aws.amazon.com/jp/codecatalyst/?did=ft_card2&trk=ft_codecatalyst

### AWS CodeArtifact

AWS CodeArtifactは、ソフトウェア開発における依存関係管理を効率化する、セキュアでスケーラブルなパッケージ管理サービスです。開発者は、npm、Maven、PyPI、NuGetなどの様々なパッケージリポジトリから取得したライブラリや、自社で開発したカスタムパッケージをCodeArtifactに保存・管理できます。これにより、社内でのコード共有や、外部依存関係のバージョン管理を容易にし、ビルドとデプロイのプロセスを安定させることができます。例えば、企業が独自のライブラリを開発し、それを複数のプロジェクトで再利用したい場合、CodeArtifactを利用することで、そのライブラリを安全かつ効率的に配布・管理することが可能になります。

🔗 https://aws.amazon.com/jp/codeartifact/?did=ft_card2&trk=ft_codeartifact

### AWS CodePipeline

AWS CodePipelineは、コードの変更から本番環境へのデプロイまで、アプリケーションのリリースプロセス全体を自動化し、迅速かつ信頼性の高いソフトウェア提供を実現する継続的デリバリーサービスです。開発者がコードをリポジトリにプッシュすると、CodePipelineは自動的にビルド、テスト、そしてデプロイの各ステージを実行します。例えば、Webアプリケーションの頻繁なアップデートや、マイクロサービスアーキテクチャにおける継続的な機能追加といったシナリオで、手作業によるミスを減らし、開発サイクルの高速化に大きく貢献します。このサービスを利用することで、チームはより頻繁に、より自信を持って新しい機能を顧客に届けることが可能になります。

🔗 https://aws.amazon.com/jp/codepipeline/?did=ft_card2&trk=ft_codepipeline

<br><br>
## 🏛️ 管理とガバナンス

### Amazon CloudWatch

Amazon CloudWatch は、AWS のリソースやアプリケーションの状態をリアルタイムで監視し、パフォーマンスの把握や問題の特定に役立つサービスです。例えば、EC2 インスタンスの CPU 使用率やネットワークトラフィックを可視化して、リソースの逼迫を早期に発見したり、Lambda 関数の実行回数やエラー発生状況を把握して、アプリケーションの正常性を確認したりできます。また、これらのメトリクスに基づいてアラームを設定し、閾値を超えた場合に通知を受け取ることで、障害発生時の迅速な対応を可能にします。さらに、アプリケーションのログを収集・分析して、デバッグやトラブルシューティングを効率化することもできます。

🔗 https://aws.amazon.com/jp/cloudwatch/?did=ft_card2&trk=ft_cloudwatch

---

### Amazon Managed Service for Prometheus

Amazon Managed Service for Prometheus は、Prometheus と互換性のあるフルマネージドサービスとして、コンテナ化されたアプリケーションのメトリクスを収集、保存、分析し、アラートを発令することを可能にします。これにより、Kubernetes 環境におけるリソース使用状況の監視や、アプリケーションのパフォーマンスボトルネックの特定、異常検知と迅速な対応といったユースケースで、運用チームはインフラストラクチャの管理負荷を軽減し、アプリケーションの可用性と信頼性の向上に集中できます。Prometheus のクエリ言語である PromQL をそのまま利用できるため、既存の運用ノウハウを活かしながら、スケーラブルで高可用性な監視基盤を容易に構築できます。

🔗 https://aws.amazon.com/jp/prometheus/?did=ft_card2&trk=ft_msfp

---

### AWS CloudFormation

AWS CloudFormationは、インフラストラクチャをコードで定義し、自動的にプロビジョニング・管理できるサービスです。これにより、EC2インスタンス、S3バケット、VPCなどのAWSリソースを、YAMLやJSON形式のテンプレートファイルで記述します。例えば、開発環境や本番環境のインフラをテンプレート化しておくことで、ワンクリックで同じ構成を再現したり、変更を容易に適用したりすることが可能です。これにより、手作業によるミスを防ぎ、インフラの迅速な展開や一貫性の維持、トラブルシューティングの効率化を実現します。

🔗 https://aws.amazon.com/jp/cloudformation/?did=ft_card2&trk=ft_cloudformation

---

### AWS CloudTrail

AWS CloudTrailは、AWSアカウントで行われた操作を記録し、継続的に監視するためのサービスです。これにより、誰が、いつ、どこで、どのリソースに対してどのような操作を行ったのかを把握でき、セキュリティ分析や運用監査、トラブルシューティングに役立ちます。例えば、不正なアクセスや設定変更の検出、コンプライアンス遵守の証明、インフラストラクチャの変更履歴の追跡などに活用できます。CloudTrailは、すべてのAWS APIコールをイベントとして記録し、そのログをS3バケットに保存するため、過去の操作履歴を安全に保管・参照することが可能です。

🔗 https://aws.amazon.com/jp/cloudtrail/?did=ft_card2&trk=ft_cloudtrail

---

### AWS Control Tower

AWS Control Towerは、セキュアで統制のとれたマルチアカウントAWS環境を迅速に構築・管理できるサービスです。組織全体でAWSアカウントを効率的に展開し、セキュリティベストプラクティスやコンプライアンス要件を自動適用することで、ガバナンスを強化します。例えば、新規プロジェクトごとにアカウントを払い出し、アクセス権限を中央集権的に管理したり、監査ログを収集・分析してセキュリティインシデントを検知したりする際に活用できます。これにより、AWS利用の複雑さを軽減し、開発チームはより迅速にイノベーションに集中できるようになります。

🔗 https://aws.amazon.com/jp/controltower/?did=ft_card2&trk=ft_controltower

---

### AWS License Manager

AWS License Manager は、AWS 上のアプリケーションで利用されるサードパーティ製ソフトウェアライセンスの管理、検出、およびレポート作成を自動化するサービスです。これにより、顧客はライセンスのコンプライアンスを維持し、不要なコストを削減できます。例えば、特定のライセンスが意図しないインスタンスで利用されている場合にアラートを発したり、ライセンス使用状況を定期的にレポートしたりすることで、ライセンス違反のリスクを低減します。また、ライセンスの購入、展開、および更新プロセスを簡素化し、IT 資産管理の効率を高めることが可能です。

🔗 https://aws.amazon.com/jp/license-manager/?did=ft_card2&trk=ft_license-manager

---

### AWS re:Post

AWS re:Postは、AWSの技術的な課題解決を支援するコミュニティ主導の質疑応答サービスです。ユーザーはここで質問を投稿したり、他のユーザーからの質問に回答したりすることで、問題解決の糸口を見つけることができます。例えば、特定のサービスの設定方法が分からない場合や、エラーメッセージの原因が特定できない場合に、re:Postで経験豊富なAWSユーザーや専門家からアドバイスを得られます。これにより、迅速な問題解決やベストプラクティスの習得が促進され、AWSの利用効率向上に繋がります。

🔗 https://www.repost.aws/jp/?did=ft_card2&trk=ft_repost

---

### AWS Resource Explorer

AWS Resource Explorerは、AWSアカウント内のリソースをリージョンを横断して素早く検索・発見できるサービスです。例えば、特定のタグが付いたEC2インスタンスや、特定のVPCに属するRDSインスタンスなど、条件を指定してリソースを探し出すことが可能です。これにより、複数のアカウントやリージョンにまたがる複雑なAWS環境においても、目的のリソースを効率的に特定し、運用管理やトラブルシューティングにかかる時間を大幅に削減できます。

🔗 https://aws.amazon.com/jp/resourceexplorer/?did=ft_card2&trk=ft_resourceexplorer

---

### AWS Systems Manager

AWS Systems Manager は、Amazon EC2 インスタンスやオンプレミスサーバーなどの AWS リソース全体にわたる運用データを一元管理し、パッチ適用、設定管理、アプリケーションデプロイといったタスクを自動化できるサービスです。例えば、数千台の EC2 インスタンスに対して最新のセキュリティパッチを一斉に適用したり、特定のソフトウェアのバージョンを全サーバーで統一したりする作業を効率化できます。これにより、運用担当者は手作業によるミスや工数を大幅に削減し、より戦略的な業務に集中することが可能になります。

🔗 https://aws.amazon.com/jp/systems-manager/?did=ft_card2&trk=ft_systemsmanager

## ✈️ 移行

### AWS Application Discovery Service

AWS Application Discovery Serviceは、オンプレミスのサーバーやアプリケーションに関する詳細な情報を収集し、AWSへの移行計画を支援するサービスです。サーバーのハードウェア仕様、CPUやメモリの使用率といったパフォーマンスデータ、さらに実行中のプロセスやネットワーク接続情報までを自動的に収集・分析することで、アプリケーションの依存関係を可視化し、移行すべきリソースの特定や、移行先のAWS環境のサイジングに役立てることができます。これにより、複雑なITインフラストラクチャの現状把握を効率化し、ダウンタイムを最小限に抑えたスムーズなAWS移行を実現します。

🔗 https://aws.amazon.com/jp/application-discovery/?did=ft_card2&trk=ft_appdiscovery

---

### AWS Migration Hub

AWS Migration Hubは、オンプレミスや他のクラウドからAWSへのアプリケーション移行プロセス全体を、単一の場所で包括的に追跡・管理できるサービスです。これにより、移行対象のサーバーやアプリケーションの発見から、移行計画の策定、実行状況の可視化、そして完了まで、各段階の進捗を把握し、移行プロジェクトの全体像を把握することが容易になります。例えば、多数のアプリケーションを段階的に移行する際、各アプリケーションの移行ステータスや依存関係を一覧で確認し、ボトルネックを特定して迅速な意思決定を支援します。また、移行ツールの統合も可能で、様々な移行手法やツールを利用する場合でも、一元的な管理を実現します。

🔗 https://aws.amazon.com/jp/migration-hub/?did=ft_card2&trk=ft_migrathub

---

### AWS Service Catalog

AWS Service Catalog は、組織内で承認済みの IT サービス（アプリケーション、インフラストラクチャ、データサービスなど）のカタログを作成・管理できるサービスです。これにより、ユーザーは簡単に、そして安全に、事前に定義された IT リソースをデプロイできるようになり、IT 管理者はコンプライアンスとガバナンスを維持できます。例えば、開発チームが標準化された開発環境を迅速にプロビジョニングしたり、新しいプロジェクトで承認済みのデータベースインスタンスを簡単に選択したりする際に活用されます。このサービスを利用することで、IT 部門の負担を軽減し、開発者の生産性を向上させることが可能です。

🔗 https://aws.amazon.com/jp/servicecatalog/?did=ft_card2&trk=ft_servicecatalog

---

### Migration Evaluator

Migration Evaluator は、オンプレミス環境の資産を AWS で運用した場合の予測コストを迅速に把握できるサービスです。これにより、IT 担当者は既存のサーバーやアプリケーションの利用状況を分析し、AWS への移行がもたらすコスト削減効果を具体的に見積もることが可能です。例えば、データセンターの老朽化に伴うリプレイスや、クラウドへの全面移行を検討する際に、初期段階での投資対効果を正確に把握するために活用されます。このサービスを活用することで、よりデータに基づいた意思決定を行い、クラウド移行プロジェクトを円滑に進めることができます。

🔗 https://aws.amazon.com/jp/migration-evaluator/?did=ft_card2&trk=ft_migeval
