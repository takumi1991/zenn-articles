# AWS 常時無料サービス 一覧 (Always Free Services)

Amazon Web Services の常時無料枠（Always Free Services）はアカウント作成後の12ヶ月間のみ利用できる無料枠（Free Tier）とは異なり、**一定の使用量までは期限なく無料**で利用できるサービス群です。完全に無制限で無料というわけではなく、各サービスごとに定められた無料枠を超えた場合は従量課金が発生します。

本記事では、AWS公式が公開している常時無料対象サービスを一覧で整理しています。個人開発・学習・コスト最適化の参考として活用してください。

👉 English version: https://zenn.dev/good_sleeper/articles/aws-always-free-en

## 💻 コンピューティング

### AWS Lambda

## AWS Lambda

AWS Lambdaは、サーバーやクラスターの管理を一切不要にして、コードをイベント駆動で実行できるサービスです。例えば、S3バケットに画像がアップロードされたら自動でサムネイルを生成したり、DynamoDBのデータ変更をトリガーに通知を送信したりといった処理を、コードを書くだけで実現できます。これにより、インフラ管理の手間を省き、開発者はアプリケーションのロジック開発に集中できます。また、実行時間に応じた従量課金制のため、コスト効率も高いのが特徴です。

🔗 https://aws.amazon.com/jp/lambda/?did=ft_card2&trk=ft_lambda

## 🧱 データベース

### Amazon Aurora DSQL

Amazon Aurora DSQLは、最速のサーバーレス分散SQLデータベースとして、常時利用可能なアプリケーションの構築を可能にします。これにより、大規模なデータセットであっても、優れたパフォーマンスと高い可用性を維持しながら、スケーリングが容易なデータベースソリューションを実現できます。特に、急激なトラフィック変動に対応する必要があるECサイトや、グローバルに展開するSaaSアプリケーション、IoTデータのリアルタイム分析など、高いスケーラビリティと可用性が求められるユースケースでその真価を発揮します。インフラ管理の手間を省き、開発者がアプリケーション開発に集中できる環境を提供します。

🔗 https://aws.amazon.com/jp/rds/aurora/dsql/?did=ft_card2&trk=ft_dsql

---

### Amazon DynamoDB

Amazon DynamoDBは、あらゆる規模で1桁ミリ秒のパフォーマンスを実現するサーバーレスNoSQLフルマネージドデータベースです。これにより、アプリケーションのデータストレージを高速かつスケーラブルに管理できます。例えば、リアルタイムのパーソナライゼーション、ゲームのランキング、IoTデバイスからのデータ収集といった、低レイテンシと高いスループットが求められるユースケースでその真価を発揮します。フルマネージドサービスであるため、インフラストラクチャの管理や運用の手間なく、開発者はアプリケーション開発に集中することができます。

🔗 https://aws.amazon.com/jp/dynamodb/?did=ft_card2&trk=ft_dynamodb

---

### Amazon SimpleDB

Amazon SimpleDBは、データベース管理の負担なく、構造化されていないデータや半構造化データを容易に保存・取得できるNoSQLデータベースサービスです。スケーラビリティと可用性に優れており、Webアプリケーションのメタデータ管理や、リアルタイムでのログ分析、IoTデバイスからのデータ収集など、多様なユースケースで活用できます。リレーショナルデータベースのようなスキーマ定義や複雑なクエリが不要なため、開発者はアプリケーションロジックに集中できます。

🔗 https://aws.amazon.com/jp/simpledb/?did=ft_card2&trk=ft_simpledb

## 🧩 アプリケーション統合

### Amazon EventBridge

Amazon EventBridgeは、AWSサービス、自社システム、SaaSアプリケーションを連携させ、イベント駆動型アプリケーションを構築するためのサーバーレスサービスです。例えば、EC2インスタンスの起動や停止、S3バケットへのファイルアップロードといったAWSのイベントをトリガーとして、Lambda関数を実行したり、他のAWSサービスに通知したりできます。また、カスタムアプリケーションやSalesforce、ShopifyといったSaaSからのイベントも取り込み、ルーティングルールに基づいて指定されたターゲットへ配信することが可能です。これにより、システム間の疎結合化やリアルタイムな連携を実現し、自動化や高度なワークフロー構築を容易にします。

🔗 https://aws.amazon.com/jp/eventbridge/?did=ft_card2&trk=ft_eventbridge

---

### Amazon SNS

Amazon SNSは、アプリケーション、システム、デバイス間で、高速かつ柔軟なプッシュメッセージングを可能にする、完全マネージド型のサービスです。これにより、例えば、システム障害発生時に担当者に即座に通知したり、ユーザーのデバイスにプロモーション情報をプッシュしたりすることが可能です。また、IoTデバイスからのデータ受信や、マイクロサービス間のイベント通知など、多様なシナリオで活用できます。複雑なメッセージングインフラストラクチャの構築・運用が不要になり、開発者はアプリケーションロジックに集中できます。

🔗 https://aws.amazon.com/jp/sns/?did=ft_card2&trk=ft_sns

---

### Amazon SQS

Amazon SQSは、アプリケーションコンポーネント間でやり取りされるメッセージを、信頼性が高くスケーラブルな方法で格納・転送するマネージドサービスです。これにより、システム内の異なるサービスが非同期で連携し、一時的な障害や負荷の変動があっても、メッセージの損失なく処理を継続できます。例えば、Webアプリケーションからの注文情報をバックエンドの処理システムへ渡す際にSQSを利用することで、注文の急増時でも処理システムがダウンすることなく、着実に注文を捌くことができます。また、バッチ処理やマイクロサービス間でのタスクのキューイングにも活用され、システム全体の可用性と応答性を向上させます。

🔗 https://aws.amazon.com/jp/sqs/?did=ft_card2&trk=ft_sqs

---

### Amazon SWF

Amazon Simple Workflow Service（SWF）は、クラウドアプリケーションにおける複雑なタスクの実行順序を管理し、その状態を追跡するためのサービスです。これにより、複数のステップからなる処理や、人間による判断を挟むようなワークフローを、信頼性高く自動化できます。例えば、オンラインショッピングにおける注文処理、データ分析パイプラインの実行、あるいは複雑なバッチ処理のオーケストレーションなどに利用され、各ステップの実行状況をSWFが管理することで、処理の成功や失敗、再試行などを容易に扱えます。

🔗 https://aws.amazon.com/jp/swf/?did=ft_card2&trk=ft_swf

---

### AWS Step Functions

AWS Step Functionsは、分散アプリケーションのコンポーネントを視覚的にワークフローとして定義し、実行できるサーバーレスオーケストレーションサービスです。これにより、Lambda関数やECSタスクなどの複数のAWSサービスを連携させ、複雑なビジネスプロセスを構築・管理できます。例えば、ECサイトでの注文処理において、在庫確認、決済、注文ステータス更新、顧客への通知といった一連の処理をStep Functionsで定義し、自動化することで、エラーハンドリングやリトライ処理を容易に実装し、信頼性の高いアプリケーションを実現します。

🔗 https://aws.amazon.com/jp/step-functions/?did=ft_card2&trk=ft_stepfunctions

## 🌐 ネットワーク

### Amazon CloudFront

Amazon CloudFrontは、世界中のエッジロケーションにコンテンツをキャッシュすることで、低レイテンシーかつ高速なデータ転送を実現し、ユーザーにウェブコンテンツやAPIを効率的に配信するCDNサービスです。これにより、ウェブサイトの表示速度向上や動画ストリーミングの品質向上、アプリケーションの応答性改善といったユースケースで、グローバルなユーザー体験を劇的に向上させることができます。例えば、世界中に顧客を持つECサイトがCloudFrontを利用することで、どの地域からのアクセスでも快適なショッピング体験を提供し、離脱率の低下やコンバージョン率の向上に貢献します。

🔗 https://aws.amazon.com/jp/cloudfront/?did=ft_card2&trk=ft_cloudfront

---

### Amazon Route 53

Amazon Route 53 は、ウェブサイトやアプリケーションへのトラフィックを、インターネット上のどこからでもアクセス可能なドメイン名（例: example.com）でルーティングする、高可用性・高スケーラビリティのDNSサービスです。これにより、ユーザーはIPアドレスを覚える必要がなく、簡単に目的のサービスにたどり着けます。例えば、ウェブサイトのドメイン名を登録・管理し、そのドメイン名がどのサーバーを指すかを設定することで、ウェブサイトの公開や、グローバルに展開するアプリケーションのトラフィックを、地理的に近いサーバーへ自動的に振り分けるといったユースケースで活用されます。さらに、ヘルスチェック機能を備え、異常を検知したサーバーへのトラフィックを停止し、正常なサーバーへ誘導することで、サービス停止のリスクを最小限に抑えます。

🔗 https://aws.amazon.com/jp/route53/?did=ft_card2&trk=ft_route53

## 🔐 セキュリティ

### Amazon Cognito

Amazon Cognitoは、Webおよびモバイルアプリケーション向けのセキュアなユーザーサインアップ、サインイン、およびアクセスコントロールを簡単かつ迅速に実装できるサービスです。開発者は、ユーザーディレクトリの作成、認証フローのカスタマイズ、ソーシャルIDプロバイダー（Google、Facebookなど）やSAML 2.0対応IDプロバイダーとの連携を容易に行えます。これにより、例えば、ECサイトでの顧客アカウント管理や、SaaSアプリケーションでのテナントごとのアクセス制御といったユースケースにおいて、ユーザー管理の複雑さを軽減し、セキュリティを確保しながら迅速なサービス開発を支援します。

🔗 https://aws.amazon.com/jp/cognito/?did=ft_card2&trk=ft_cognito

---

### AWS Certificate Manager

AWS Certificate Manager (ACM) は、AWS、ハイブリッド、マルチクラウド環境でSSL/TLS証明書のプロビジョニングと管理を簡素化するサービスです。ACMを利用することで、ウェブサイトやアプリケーションへの安全な接続を容易に実現できます。例えば、Amazon CloudFrontやElastic Load Balancingと連携させ、HTTPS通信を有効化することで、ユーザーデータの保護やSEO対策に貢献します。また、証明書の更新も自動で行われるため、手作業による管理の手間を大幅に削減し、セキュリティ運用を効率化できます。これにより、開発者はインフラ管理よりもアプリケーション開発に集中することが可能となります。

🔗 https://aws.amazon.com/jp/certificate-manager/?did=ft_card2&trk=ft_certmanager

---

### AWS Key Management Service

AWS Key Management Service (KMS) は、AWSサービスで生成・管理される暗号化キーを使用して、データの暗号化と復号を容易にするマネージドサービスです。S3バケット内の機密データ、RDSデータベースの情報を保護したり、EC2インスタンスのEBSボリュームを暗号化したりするなど、AWS内外の様々なリソースのデータを安全に保つことができます。KMSは、キーの作成、管理、使用状況の監査をAWSが行うため、お客様は暗号化の複雑な管理から解放され、セキュリティとコンプライアンスの要件を満たすことが容易になります。

🔗 https://aws.amazon.com/jp/kms/?did=ft_card2&trk=ft_kms

---

### AWS Resource Access Manager

AWS Resource Access Manager (RAM) は、AWS アカウント間または組織内で、Amazon S3 バケットや AWS Systems Manager Parameter Store のパラメータといった AWS リソースを安全かつ容易に共有できるサービスです。これにより、異なる AWS アカウントが同じリソースにアクセスできるようになり、例えば、開発環境と本番環境で共通の設定情報を共有したり、複数のアカウントで共有ストレージを利用したりといったユースケースで、リソース管理の効率化とコスト削減を実現できます。RAM を使用することで、リソースのコピーや複雑なアクセス権限設定を行う必要がなくなり、管理負担を軽減できます。

🔗 https://aws.amazon.com/jp/ram/?did=ft_card2&trk=ft_resourceaccess

---

### AWS Shield

AWS Shieldは、DDoS攻撃からお客様のAWS上のアプリケーションとネットワークを保護するマネージド型のDDoS防御サービスです。ネットワークセキュリティ設定の分析を通じて、潜在的な脆弱性を特定し、継続的な保護を提供します。例えば、ゲーム、金融サービス、eコマースといった、常に高可用性が求められるビジネスでは、DDoS攻撃によるサービス停止は直接的な収益損失やブランドイメージの低下に繋がるため、AWS Shieldによる堅牢な防御が不可欠となります。Standardプランは全てのAWSのお客様に無料で提供され、基本的なDDoS保護機能を利用できます。より高度な保護、迅速なインシデント対応、コスト削減といったメリットを享受したい場合は、AWS Shield Advancedへのアップグレードも可能です。

🔗 https://aws.amazon.com/jp/shield/?did=ft_card2&trk=ft_shield

---

### AWS WAF Bot Control

AWS WAF Bot Controlは、一般的なウェブボットによる攻撃からウェブアプリケーションを保護し、不正なトラフィックをブロックするマネージドサービスです。これにより、アカウント乗っ取り、コンテンツスクレイピング、DDoS攻撃などの悪意あるボット活動を効果的に軽減できます。例えば、ECサイトでボットによる不正な商品購入や在庫枯渇を防いだり、APIへの過剰なアクセスを抑制したりする際に活用できます。このサービスは、既知のボットのシグネチャや行動パターンを学習・分析し、自動的に防御策を適用するため、専門知識がなくても手軽に導入・運用が可能です。

🔗 https://aws.amazon.com/jp/waf/features/bot-control/?did=ft_card2&trk=ft_WAFbc

## 📊 データ分析

### Amazon DataZone

Amazon DataZoneは、組織内のあらゆる場所にあるデータを、セキュリティとガバナンスを維持しながら、より多くの人が容易に発見・アクセス・共有できるデータカタログおよびデータガバナンスサービスです。例えば、マーケティング部門が営業データと連携してキャンペーンの効果を分析したり、研究開発部門が過去の実験データを参照して新製品開発のヒントを得たりする際に、データサイエンティストやアナリストは、事前に定義されたポリシーに基づき、安全かつ効率的に必要なデータを見つけ出し、活用できます。これにより、データサイロを解消し、データ主導の意思決定を加速させることが可能になります。

🔗 https://aws.amazon.com/jp/datazone/?did=ft_card2&trk=ft_datazone

---

### Amazon OpenSearch Service

Amazon OpenSearch Serviceは、インタラクティブなログ分析、リアルタイムなアプリケーションのモニタリング、ウェブサイト検索といった高度なデータ分析を容易にするマネージドサービスです。このサービスを利用することで、開発者やオペレーションチームは、大量のログデータから迅速にインサイトを抽出し、アプリケーションのパフォーマンス問題を特定・解決したり、ユーザー体験を向上させるための検索機能を構築したりすることが可能になります。例えば、ウェブサイトのアクセスログを分析して人気コンテンツを把握したり、サーバーログをリアルタイムで監視して障害の兆候を早期に検知するといったユースケースが挙げられます。AWSがインフラストラクチャの管理を担うため、ユーザーは分析に集中できます。

🔗 https://aws.amazon.com/jp/opensearch-service/?did=ft_card2&trk=ft_opensearch

---

### AWS Glue

AWS Glueは、データエンジニアリングタスクを簡素化するフルマネージドETL（抽出、変換、ロード）サービスです。データカタログ機能により、様々なデータソースのメタデータを自動的に検出し、一元管理することで、データの発見と準備を容易にします。これにより、データウェアハウスへのデータロードや、データレイクの構築、機械学習モデルのためのデータ前処理など、多様なデータ活用ユースケースを効率的に実現できます。サーバーレスで実行されるため、インフラストラクチャの管理が不要で、使用した分だけの料金でコスト効率に優れています。

🔗 https://aws.amazon.com/jp/glue/?did=ft_card2&trk=ft_glue

### AWS HealthLake

AWS HealthLakeは、ヘルスケアおよびライフサイエンス業界向けに設計された、安全でスケーラブルなデータレイクサービスです。このサービスを利用することで、患者の電子カルテ、臨床試験データ、ゲノムデータなどのヘルスデータを、HIPAAなどの規制に準拠した安全な環境で、短時間で保存、変換、分析することが可能になります。例えば、複数の医療機関に分散している患者データを統合し、疾患の早期発見や個別化医療の推進、公衆衛生上のトレンド分析などに活用できます。HealthLakeは、FHIR (Fast Healthcare Interoperability Resources) 標準に準拠しており、データの相互運用性を高め、AI/MLを活用した高度な分析基盤を容易に構築できるため、医療の質の向上と研究開発の加速に貢献します。

### AWS CodePipeline

AWS CodePipelineは、コードの変更から本番環境へのデプロイまで、アプリケーションのリリースプロセス全体を自動化し、迅速かつ信頼性の高いアプリケーション更新を実現する継続的デリバリーサービスです。開発者がコードをチェックインすると、CodePipelineはコードのビルド、テスト、およびデプロイといった各ステージを順次実行し、手作業によるエラーのリスクを低減します。例えば、Webアプリケーションの機能追加やバグ修正を迅速にユーザーに届けたい場合、CodePipelineを活用することで、開発からリリースまでのリードタイムを大幅に短縮し、市場の変化に素早く対応できるようになります。

🔗 https://aws.amazon.com/jp/codepipeline/?did=ft_card2&trk=ft_codepipeline

<br><br>
## 🏛️ 管理とガバナンス

### Amazon CloudWatch

Amazon CloudWatchは、AWSのクラウドリソースとアプリケーションのパフォーマンスを包括的に監視できるサービスです。EC2インスタンスのCPU使用率やディスクI/O、Lambda関数の実行回数やエラー率などをリアルタイムで収集・追跡し、異常を検知した際にはアラームを発報することが可能です。これにより、ウェブサイトの可用性監視や、アプリケーションのボトルネック特定、リソースの最適化といった運用管理を効率化し、ビジネスの安定稼働を支援します。また、アプリケーションのログも一元管理できるため、問題発生時の原因究明にも役立ちます。

🔗 https://aws.amazon.com/jp/cloudwatch/?did=ft_card2&trk=ft_cloudwatch

---

### Amazon Managed Service for Prometheus

Amazon Managed Service for Prometheus は、Prometheus と互換性のあるマネージドサービスであり、コンテナ化されたアプリケーションのメトリクスを収集・保存・分析し、アラートを発報することで、システムの健全性を常時監視できます。Kubernetes 環境で動作するマイクロサービス群のパフォーマンスをリアルタイムで把握し、異常発生時には迅速な検知と対応を可能にするため、システム障害の予兆を捉え、ダウンタイムを最小限に抑えるユースケースで特に活用されます。これにより、運用チームは Prometheus の運用管理の手間から解放され、アプリケーション開発やサービス改善に集中できるようになります。

🔗 https://aws.amazon.com/jp/prometheus/?did=ft_card2&trk=ft_msfp

---

### AWS CloudFormation

AWS CloudFormationは、コード（テンプレート）を用いてAWSインフラストラクチャ全体を定義し、自動的にプロビジョニングするサービスです。これにより、開発環境や本番環境といった複数の環境で、一貫性のあるリソース構成を迅速に作成・管理できます。例えば、Webアプリケーションをデプロイする際に、必要なEC2インスタンス、RDSデータベース、ロードバランサーなどをテンプレートに記述しておけば、ボタン一つでそれらがまとめて作成されます。さらに、コードとして管理することで、インフラ構成の変更履歴を追跡したり、設定ミスを防いだりすることも可能になり、運用の効率化と信頼性向上に貢献します。

🔗 https://aws.amazon.com/jp/cloudformation/?did=ft_card2&trk=ft_cloudformation

---

### AWS CloudTrail

AWS CloudTrailは、AWSアカウントで行われた操作（APIコール）を記録し、継続的に監視することで、インフラストラクチャ全体のガバナンス、コンプライアンス、およびセキュリティ監査を可能にします。誰が、いつ、どこで、どのようなAWSリソースに対して操作を行ったかを把握できるため、不正なアクティビティの検出や、リソース変更時の原因究明に役立ちます。例えば、セキュリティインシデント発生時の原因調査や、コンプライアンス要件を満たすための操作履歴の記録、あるいは誤操作による設定変更の追跡などに活用されています。CloudTrailは、これらのアクティビティログをS3バケットに保存し、必要に応じて検索・分析できるようにします。

🔗 https://aws.amazon.com/jp/cloudtrail/?did=ft_card2&trk=ft_cloudtrail

---

### AWS Control Tower

AWS Control Towerは、セキュアで設定済みのマルチアカウントAWS環境を迅速に構築・管理できるサービスです。これにより、組織はAWSのベストプラクティスに基づいたガバナンスとセキュリティを最初から実現できます。例えば、新規プロジェクトごとにアカウントを自動作成し、アクセス権限やコンプライアンス設定を一元管理することで、セキュリティリスクの低減と運用の効率化を同時に達成できます。企業がAWSへの移行を進める際に、基盤となる環境を安全かつ管理しやすく整えるために利用されます。

🔗 https://aws.amazon.com/jp/controltower/?did=ft_card2&trk=ft_controltower

---

### AWS License Manager

AWS License Managerは、Amazon EC2インスタンスやオンプレミスサーバーなどの環境で利用されているサードパーティ製ソフトウェアライセンスの使用状況を、事前に定義したルールに基づいて一元的に管理、検出、レポートできるサービスです。これにより、ライセンス違反のリスクを低減し、コスト最適化に貢献します。例えば、特定のアプリケーションのライセンスが、意図しないインスタンスで起動されていないかを確認したり、ライセンスの購入・更新時期を把握したりといったユースケースで活用できます。ソフトウェアライセンスのコンプライアンス遵守と効率的な管理を実現するための強力なツールです。

🔗 https://aws.amazon.com/jp/license-manager/?did=ft_card2&trk=ft_license-manager

---

### AWS re:Post

AWS re:Postは、AWSをご利用のお客様が技術的な疑問や課題について、他のユーザーやAWSの専門家から回答を得られるコミュニティ主導の質疑応答サービスです。例えば、特定のサービスの設定方法がわからない、エラーの原因を特定したい、あるいはアーキテクチャ設計に関するベストプラクティスを知りたいといった場合に、re:Postで質問を投稿することで、経験豊富なコミュニティメンバーやAWSの担当者からの知見や解決策を得ることができます。これにより、問題解決の迅速化、学習機会の拡大、そしてAWS活用の深化に繋がります。

🔗 https://www.repost.aws/jp/?did=ft_card2&trk=ft_repost

---

### AWS Resource Explorer

AWS Resource Explorerは、AWSアカウント全体でリソースを横断的に検索・発見できるサービスです。例えば、特定のリソースタイプ（EC2インスタンスなど）やタグが付与されたリソースを、複数のリージョンにわたって一度に探し出すことができます。これにより、複雑なAWS環境におけるリソースの所在確認や管理作業の効率が大幅に向上し、インベントリ管理やトラブルシューティングの時間を短縮するのに役立ちます。

🔗 https://aws.amazon.com/jp/resourceexplorer/?did=ft_card2&trk=ft_resourceexplorer

---

### AWS Service Catalog

AWS Service Catalog は、組織内で利用が承認された IT サービス（アプリケーション、データベース、インフラストラクチャなど）のカタログを作成・管理し、ユーザーにセルフサービスで提供できるサービスです。これにより、IT 管理者は標準化された安全な方法でリソースをプロビジョニングできるようになり、開発者やエンドユーザーは承認済みのテンプレートから迅速に必要なサービスを展開できます。例えば、新しいプロジェクトチームがインフラストラクチャを構築する際に、あらかじめ定義されたセキュリティ要件を満たす環境を簡単に選択・デプロイできるため、コンプライアンス遵守とガバナンス強化に貢献します。

🔗 https://aws.amazon.com/jp/servicecatalog/?did=ft_card2&trk=ft_servicecatalog

---

### AWS Systems Manager

AWS Systems Managerは、AWSリソースの運用データを一元管理し、様々なタスクを自動化できるサービスです。これにより、パッチ適用、設定管理、リモートでのコマンド実行、インベントリ収集などを効率的に行えます。例えば、多数のEC2インスタンスのOSパッチ適用を自動化したり、特定の設定が適用されているかを確認したり、問題発生時にリモートからログを取得して調査したりといった運用管理作業を簡略化・効率化できます。AWS Systems Managerを活用することで、運用担当者の作業負担を軽減し、システム全体の信頼性向上に貢献します。

🔗 https://aws.amazon.com/jp/systems-manager/?did=ft_card2&trk=ft_systemsmanager

## ✈️ 移行

### AWS Application Discovery Service

AWS Application Discovery Serviceは、オンプレミスのサーバー環境の棚卸しと可視化を支援するサービスです。サーバーのハードウェア仕様、CPUやメモリの使用率といったパフォーマンスデータ、さらに実行中のプロセスやネットワーク接続情報まで収集し、アプリケーションの依存関係を把握することを可能にします。これにより、AWSへの移行計画をより正確に立てることができ、移行後のインフラストラクチャ設計やサイジングの最適化に役立ちます。特に、多数のサーバーが稼働する複雑なシステムをAWSへ移行する際の、情報収集と分析の負担を大幅に軽減します。

🔗 https://aws.amazon.com/jp/application-discovery/?did=ft_card2&trk=ft_appdiscovery

---

### AWS Migration Hub

AWS Migration Hub は、クラウド移行プロジェクト全体の進捗状況を一元的に把握できるサービスです。オンプレミス環境からAWSへのアプリケーション移行や、AWS内でのリプラットフォーム、リホストなどの様々な移行戦略をサポートし、各アプリケーションの移行フェーズやステータスを可視化することで、移行計画の策定、実行、監視を効率化します。例えば、多数のアプリケーションを抱える大企業が、段階的にAWSへ移行する際に、どのアプリケーションがどの段階にあるのか、課題は何かといった情報をまとめて管理し、移行チーム間の連携をスムーズにするのに役立ちます。

🔗 https://aws.amazon.com/jp/migration-hub/?did=ft_card2&trk=ft_migrathub

---

### Migration Evaluator

Migration Evaluator は、オンプレミスのIT資産をAWSで運用した場合のコストを迅速に予測できるサービスです。このサービスを利用することで、お客様は既存のサーバーやストレージなどの資産情報をアップロードするだけで、AWS上での移行後の概算コストを把握できます。例えば、データセンターの移行計画を立てる際に、物理的なサーバーのスペックや利用状況を入力し、AWSの各サービスで代替した場合の費用を比較検討するといったユースケースで活用されます。これにより、移行プロジェクトの初期段階で費用対効果を評価し、より精度の高い予算策定を支援します。

🔗 https://aws.amazon.com/jp/migration-evaluator/?did=ft_card2&trk=ft_migeval
