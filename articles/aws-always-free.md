# AWS 常時無料サービス 一覧 (Always Free Services)

Amazon Web Services の常時無料枠(Always Free Services) はアカウント作成後の12ヵ月間だけ利用できる無料利用枠(Free Tier)とは異なり、12ヶ月を超えても **特定の使用量まではずっと無料で使えるサービス群** です。

完全に無制限で無料というわけではなく、各サービスの無料枠（リクエスト数、GB、クォータなど）を超えた部分は通常の従量課金が発生します。

本記事では AWS が公開している Always Free 対象サービスを一覧でまとめています。  
クラウドサービスの学習、個人開発、コスト最適化の参考にぜひご活用ください。
※なお、リージョンごとに常時無料対象のサービスが異なることがあります。本記事は日本リージョンを対象としています。


## AWS Glue

**AWS Glue** は、AWS が提供するサーバーレスでスケーラブルなデータ統合サービスです。このサービスを利用することで、ETL (Extract, Transform, Load) ジョブを簡単に作成・実行でき、様々なデータソースからのデータを効率的に処理・分析できます。

例えば、EC2 インスタンスで稼働するデータベースや S3 バケットに保存されたデータを、データウェアハウスである Amazon Redshift にロードする際に AWS Glue を活用できます。コーディングなしでもデータカタログを作成し、データの発見や準備を自動化できるため、初心者でも直感的に利用しやすいのが特徴です。データ分析基盤の構築をスムーズに進めたい場合に役立つ AWS のサービスです。

🔗 https://aws.amazon.com/jp/glue/?did=ap_card&trk=ap_card

## Amazon Simple Email Service (SES)

AWS（Amazon Web Services）のAmazon Simple Email Service (SES) は、大量のメール送信を低コストかつ柔軟に行えるクラウドベースのサービスです。これにより、顧客へのプロモーションメール、トランザクションメール（注文確認、パスワードリセットなど）、ニュースレターなどを、アプリケーションから直接送信できます。Webサイトの会員登録確認メールや、ECサイトからの購入完了通知といったユースケースに最適です。API連携も容易なため、開発者にも扱いやすく、スケーラブルなメール配信基盤を構築したい場合に役立ちます。

🔗 https://aws.amazon.com/jp/ses/?did=ap_card&trk=ap_card

## AWS CodePipeline

AWS CodePipelineは、AWSが提供する継続的デリバリーサービスです。このAWSサービスを利用することで、開発したソフトウェアを自動的にビルド、テスト、デプロイするパイプラインを構築し、迅速かつ信頼性の高いリリースを実現できます。例えば、コードの変更をGitリポジトリにプッシュすると、CodePipelineが自動的に検知し、ビルド、テスト実行、そして本番環境へのデプロイまでを一連の流れで実行します。これにより、開発者は手作業によるミスを減らし、より効率的にソフトウェア開発を進めることができます。AWS CodePipelineは、DevOpsを実践し、アジャイルな開発サイクルを加速するための強力なツールです。

🔗 https://aws.amazon.com/jp/codepipeline/?did=ap_card&trk=ap_card

## AWS WAF

AWS WAFは、**AWS**のセキュリティサービスで、Webアプリケーションへの悪意のあるトラフィックをフィルタリングし、Webサイトやアプリケーションを保護します。SQLインジェクションやクロスサイトスクリプティング（XSS）などの一般的な攻撃から守ることで、大切なデータを安全に保ちます。例えば、ECサイトで不正なアクセスをブロックしたり、ブログサイトでスパムコメントを防いだりするのに役立ちます。この**サービス名**は、Web Application Firewallの略で、Webアプリケーションのセキュリティを強化するのに非常に有効です。導入も比較的簡単で、**用途**も多岐にわたるため、初心者の方でも安心して利用できます。

🔗 https://aws.amazon.com/jp/waf/?did=ap_card&trk=ap_card

## AWS Application Discovery Service

AWS Application Discovery Service は、**AWS** クラウドへの移行を検討しているお客様が、オンプレミスの IT 環境を把握するための **サービス名** です。この **用途** では、サーバーやアプリケーションの依存関係を自動的に検出し、可視化します。これにより、複雑なシステム構成の全体像を把握し、移行計画の精度を高めることができます。例えば、多数のサーバーが連携している基幹システムをクラウドに移行する際に、どのサーバーがどのアプリケーションと連携しているかを正確に把握することで、ダウンタイムを最小限に抑え、リスクを低減することが可能です。初心者の方でも、このサービスを利用することで、移行対象のアプリケーションを合理的に特定し、スムーズなクラウド移行を実現できます。

🔗 https://aws.amazon.com/jp/application-discovery/?did=ap_card&trk=ap_card

## AWS CloudFormation

AWS CloudFormationは、AWSのサービスをテンプレートというコードで定義し、自動的にインフラを構築・管理できるサービスです。AWS初心者でも、このテンプレートを使うことで、サーバーやデータベースなどのリソースを簡単に作成できます。例えば、Webアプリケーションをデプロイするために必要なEC2インスタンス、RDSデータベース、Elastic Load Balancerなどをまとめて定義し、ワンクリックで展開可能です。これにより、手作業によるミスを防ぎ、インフラの再現性を高めることができます。

🔗 https://aws.amazon.com/jp/cloudformation/?did=ap_card&trk=ap_card

## Amazon Simple Notification Service (SNS)

AWSのサービスであるAmazon Simple Notification Service (SNS)は、アプリケーション間のメッセージングや、ユーザーへの通知を簡単に行うためのサービスです。Publish/Subscribe (pub/sub) モデルを採用しており、発行者（Publisher）がメッセージを発行すると、登録している購読者（Subscriber）に一斉配信されます。このAWSサービスは、SMS、Eメール、モバイルプッシュ通知など、多様なエンドポイントにメッセージを送信できるため、様々な用途で活用できます。例えば、システム障害発生時の管理者へのアラート通知、ECサイトでの注文完了通知、IoTデバイスからのデータ受信通知などに利用できます。AWS初心者でも容易に導入できるのが特徴です。

🔗 https://aws.amazon.com/jp/sns/?did=ap_card&trk=ap_card

## AWS CodeCommit

**AWS CodeCommit** は、AWSが提供するマネージド型のソースコード管理サービスです。この **AWS サービス** を利用することで、開発者は **CodeCommit** を使用して、プライベートな Git リポジトリにコードを安全に保存・管理できます。

**用途**としては、チームでのソフトウェア開発において、コードのバージョン管理、変更履歴の追跡、複数人での共同作業を円滑に行うことが挙げられます。例えば、Webアプリケーション開発で、最新のソースコードをどこに保管するか、誰がいつどのような変更を加えたかを把握したい場合に非常に便利です。初心者の方でも、AWSの他のサービスとの連携も容易なため、手軽に始められます。

🔗 https://aws.amazon.com/jp/codecommit/?did=ap_card&trk=ap_card

## AWS CodeArtifact

AWS CodeArtifact は、AWS が提供する、ソフトウェア開発におけるアーティファクト（ライブラリや依存関係など）を管理するためのセキュアでスケーラブルなサービスです。この AWS サービスを利用することで、開発チームは社内外で利用する様々なパッケージを、一元管理し、セキュアに共有できます。例えば、社内共通のライブラリや、外部の公開リポジトリから取得した依存関係を CodeArtifact に保存・管理することで、ビルドの再現性を高め、セキュアな開発プロセスを構築できます。用途としては、Maven、npm、PyPI などの各種パッケージマネージャーに対応しており、依存関係の管理が複雑になりがちな、初心者にも扱いやすいサービスです。

🔗 https://aws.amazon.com/jp/codeartifact/?did=ap_card&trk=ap_card

## AWS Migration Hub

**AWS Migration Hub** は、**AWS** へのリフト＆シフトやハイブリッドクラウド移行など、複数のサーバー移行プロジェクトを単一の場所から一元管理できる無料のサービスです。この **サービス名** の主な **用途** は、移行の進捗状況を可視化し、リソースの検出、計画、追跡を効率化することです。例えば、オンプレミスのアプリケーションを **AWS** に移行する際、Migration Hub を利用することで、どのサーバーが移行済みで、どのサーバーが計画段階にあるのかを一覧で把握できます。これにより、移行プロジェクトの全体像を把握しやすくなり、初心者でも安心して移行を進めることができます。

🔗 https://aws.amazon.com/jp/migration-hub/?did=ap_card&trk=ap_card

## Amazon DynamoDB

AWSが提供するAmazon DynamoDBは、スケーラブルで高性能なマネージドNoSQLデータベースサービスです。AWSのサービスを活用したアプリケーション開発において、高速なデータ読み書きが求められる場面で特に活躍します。例えば、オンラインゲームのスコア管理、IoTデバイスからのデータ収集、モバイルアプリケーションのユーザープロファイル保存など、多岐にわたるユースケースで利用されています。初心者でも簡単に利用開始でき、インフラ管理の手間なく、アプリケーションの成長に合わせて自動的にスケールする点が大きなメリットです。

🔗 https://aws.amazon.com/jp/dynamodb/?did=ap_card&trk=ap_card

## Amazon Simple Queue Service (SQS)

AWSのサービス、Amazon Simple Queue Service (SQS) は、アプリケーション間の連携を容易にするマネージドメッセージキューです。このAWSサービスは、システムコンポーネントを疎結合にし、信頼性の高いメッセージングを実現します。例えば、Webアプリケーションからバックエンドの処理システムへ、大量の注文データを非同期に送信する際に、SQSを利用することで、処理が一時的に遅延してもデータが失われる心配がありません。初心者でも簡単に利用でき、スケーラブルなシステム構築に貢献します。

🔗 https://aws.amazon.com/jp/sqs/?did=ap_card&trk=ap_card

## Amazon Cognito

AWSのAmazon Cognitoは、アプリケーションにID管理と認証・認可機能を簡単に組み込めるマネージドサービスです。これにより、開発者はユーザー登録、ログイン、パスワード管理といった複雑な認証フローを自社で実装する手間なく、安全かつスケーラブルなID基盤を構築できます。例えば、モバイルアプリやWebサイトで、ユーザーがGoogleやFacebookアカウントでログインできるようにしたり、独自のアカウントを発行・管理したりする際に活用できます。初心者でも容易に導入でき、アプリケーションのセキュリティとユーザーエクスペリエンスを向上させるのに役立ちます。

🔗 https://aws.amazon.com/jp/cognito/?did=ap_card&trk=ap_card

## AWS CloudTrail

AWS CloudTrailは、AWSアカウント内のユーザーアクティビティとAPIコールを記録・追跡できるサービスです。このAWSサービスを活用することで、誰が、いつ、どのような操作を行ったかを把握でき、セキュリティ監査やトラブルシューティングに役立ちます。例えば、意図しない設定変更や不正アクセスがないかを確認する用途に最適です。初心者でも簡単に利用でき、AWS環境の可視性を高めるための重要なツールと言えます。

🔗 https://aws.amazon.com/jp/cloudtrail/?did=ap_card&trk=ap_card

## Migration Evaluator (旧 TSO Logic)

AWS Migration Evaluator（旧 TSO Logic）は、AWSへのクラウド移行のビジネスケース作成を支援するサービスです。IT環境の現状を分析し、AWSで運用した場合のコスト削減効果やTCO（総所有コスト）を算出することで、移行のメリットを可視化します。例えば、オンプレミスサーバーの稼働状況やアプリケーション構成をインポートすると、AWSでの代替リソースとその費用が提示され、移行による経済的な効果を具体的に把握できます。このサービスは、クラウド移行を検討し始めたばかりの初心者にとって、データに基づいた意思決定を助ける強力なツールとなります。

🔗 https://aws.amazon.com/jp/migration-evaluator/?did=ap_card&trk=ap_card

## AWS CodeBuild

AWS CodeBuildは、AWSのサービスの一つで、ソースコードのコンパイル、テスト、デプロイ準備を自動化するために利用されます。このサービスは、開発者がコードをビルドする手間を省き、アプリケーション開発の効率を向上させることを目的としています。例えば、WebアプリケーションのコードをGitHubから取得し、それをコンパイルして実行可能な形式に変換し、さらに単体テストを実行するといった一連の作業をCodeBuildに任せることができます。これにより、開発者はコードを書くことに集中でき、インフラストラクチャの管理から解放されます。初心者でも簡単に利用できるため、DevOpsの導入を検討しているチームにとって非常に有用です。

🔗 https://aws.amazon.com/jp/codebuild/?did=ap_card&trk=ap_card

## AWS Systems Manager

**AWS Systems Manager** は、AWSクラウド環境におけるオペレーションを効率化し、運用時のインサイトに基づいて改善を支援するサービスです。AWSの運用管理を統合的に行うことができ、サーバーのパッチ適用、設定変更、ログ管理、インベントリ収集など、多岐にわたるタスクを自動化・可視化できます。

例えば、多数のEC2インスタンスのOSアップデートを一度に行ったり、特定の設定が適用されているかを確認したりすることが可能です。これにより、管理者は手作業によるミスを減らし、セキュリティリスクの低減やコンプライアンス遵守に集中できます。初心者でも容易に導入できるため、AWSでのシステム運用を始める方におすすめのサービスです。

🔗 https://aws.amazon.com/jp/systems-manager/?did=ap_card&trk=ap_card

## AWS X-Ray

AWS X-Rayは、AWS上で稼働するアプリケーションのパフォーマンスを分析し、デバッグを支援する**AWSサービス**です。この**サービス名**は、アプリケーションがどのようにリクエストを処理しているかを可視化し、ボトルネックとなっている箇所やエラーの原因を特定するのに役立ちます。例えば、Webアプリケーションでレスポンスが遅い場合、X-Rayを使うことで、APIゲートウェイ、Lambda、データベースなど、どのコンポーネントで時間がかかっているのかを具体的に把握できます。これにより、開発者は効率的に問題箇所を特定し、アプリケーションの改善に繋げることが可能です。**用途**は、アプリケーションの高速化や安定性向上に不可欠です。

🔗 https://aws.amazon.com/jp/xray/?did=ap_card&trk=ap_card

## AWS Storage Gateway

**AWS Storage Gateway** は、AWS クラウドストレージとオンプレミス環境をシームレスに統合するハイブリッドストレージサービスです。このサービスを利用することで、既存のオンプレミスアプリケーションは、あたかもローカルストレージのようにAWSの各種ストレージサービス（Amazon S3、Amazon EBS、Amazon FSxなど）にアクセスできるようになります。

主な用途としては、バックアップのオフロード、災害対策、アーカイブ、そしてオンプレミスデータとクラウドデータの連携などが挙げられます。例えば、オンプレミスのファイルサーバーのデータをStorage Gateway経由でAmazon S3にバックアップすることで、ストレージコストを削減し、管理を簡素化できます。また、頻繁にアクセスしないデータはS3 Glacierにアーカイブすることで、さらにコスト効率を高めることも可能です。

初心者の方でも、Storage Gatewayはオンプレミス環境に仮想アプライアンスまたはハードウェアアプライアンスをデプロイするだけで簡単に利用を開始でき、AWSの強力なスケーラビリティや耐久性をオンプレミスから享受できます。

🔗 https://aws.amazon.com/jp/storagegateway/?did=ap_card&trk=ap_card

## AWS Organizations

AWS Organizationsは、複数のAWSアカウントをまとめて管理できるサービスです。AWSの利用において、組織全体のガバナンスを強化したい場合に特に役立ちます。例えば、部署ごとやプロジェクトごとにAWSアカウントを分けて利用する際に、各アカウントのアクセス権限を一元管理したり、請求を一元化したりすることが可能です。これにより、セキュリティポリシーの適用やコスト管理が容易になり、AWSの利用をより安全かつ効率的に進められます。初心者の方でも、組織的なAWS利用の第一歩として理解しやすいサービスです。

🔗 https://aws.amazon.com/jp/organizations/?did=ap_card&trk=ap_card

## Amazon Honeycode

**AWS**が提供する**Amazon Honeycode**は、プログラミングの知識がなくても、直感的な操作でモバイルおよびウェブアプリケーションを簡単に構築できるサービスです。Excelのようなスプレッドシートのようなインターフェースでデータ管理を行い、ワークフローの自動化やチーム間の情報共有を円滑にするアプリケーションを作成できます。
