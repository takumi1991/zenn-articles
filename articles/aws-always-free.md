# AWS 常時無料サービス 一覧 (Always Free Services)

Amazon Web Services の常時無料枠（Always Free Services）はアカウント作成後の12ヶ月間のみ利用できる無料枠（Free Tier）とは異なり、**一定の使用量までは期限なく無料**で利用できるサービス群です。完全に無制限で無料というわけではなく、各サービスごとに定められた無料枠を超えた場合は従量課金が発生します。

本記事では、AWS公式が公開している常時無料対象サービスを一覧で整理しています。個人開発・学習・コスト最適化の参考として活用してください。

👉 English version: https://zenn.dev/good_sleeper/articles/aws-always-free-en

## 💻 コンピューティング

### AWS Lambda

AWS Lambdaは、サーバーのプロビジョニングや管理を一切不要にし、イベントに応答してコードを直接実行できるコンピューティングサービスです。例えば、S3バケットへのファイルアップロードをトリガーとして画像のリサイズや変換処理を行ったり、DynamoDBテーブルへのデータ変更を検知して通知を送信したりするなどの自動化が可能です。また、API Gatewayと連携してサーバーレスなWeb APIを構築したり、定期的なタスクを実行するためにスケジュール設定したりすることもできます。これにより、開発者はインフラ管理から解放され、アプリケーションのロジック開発に集中できるようになります。

🔗 https://aws.amazon.com/jp/lambda/?did=ft_card2&trk=ft_lambda

<br><br>
## 🗄️ ストレージ

### Amazon SimpleDB

Amazon SimpleDBは、スケーラブルで柔軟なNoSQLデータベースとして、ウェブアプリケーションやモバイルバックエンドで大量の構造化データを簡単に保存、取得、管理できます。データベース管理の複雑さから解放され、開発者はアプリケーションロジックに集中できます。例えば、ユーザープロファイル、製品カタログ、イベントログなどのデータを効率的に扱うのに適しており、インデックス作成やクエリが容易なため、迅速なデータアクセスが可能です。

🔗 https://aws.amazon.com/jp/simpledb/?did=ft_card2&trk=ft_simpledb

<br><br>
## 🧱 データベース

### Amazon Aurora DSQL

Amazon Aurora Serverless v2 は、常時利用可能なアプリケーション向けに、自動的にスケールする最速の分散 SQL データベースです。負荷に応じてコンピューティング容量が分単位で増減するため、予測不能なワークロードにも柔軟に対応できます。例えば、急激なトラフィック増加に対応する必要のあるECサイトや、ピークタイムとオフピークタイムで利用量が大きく変動するSaaSアプリケーションなどに最適です。これにより、インフラの過剰プロビジョニングを避けつつ、パフォーマンスを維持・向上させることが可能です。

🔗 https://aws.amazon.com/jp/rds/aurora/dsql/?did=ft_card2&trk=ft_dsql

---

### Amazon DynamoDB

Amazon DynamoDBは、あらゆる規模で1桁ミリ秒という高速なパフォーマンスを提供する、サーバーレスでフルマネージドなNoSQLデータベースです。これにより、アプリケーションのレイテンシを最小限に抑え、ユーザーエクスペリエンスを向上させることができます。例えば、リアルタイムのゲーム、IoTデバイスからのデータ収集、モバイルアプリケーションのバックエンド、またはリアルタイムのパーソナライゼーションなど、高いスケーラビリティと低レイテンシが求められる様々なユースケースで活用されています。DynamoDBは、インフラストラクチャの管理をAWSに任せることができるため、開発者はアプリケーションの開発に集中できます。

🔗 https://aws.amazon.com/jp/dynamodb/?did=ft_card2&trk=ft_dynamodb

## 🧩 アプリケーション統合

### Amazon EventBridge

Amazon EventBridge は、AWS、オンプレミスシステム、SaaS アプリケーションにわたるイベントをルーティングし、イベント駆動型アプリケーションを大規模に構築できるサーバーレスイベントバスサービスです。これにより、様々なソースからのイベントをリアルタイムで検知し、Lambda 関数、SQSキュー、SNSトピックなどのターゲットにルーティングすることで、システム間の連携を自動化できます。例えば、EC2インスタンスの起動イベントをトリガーに、自動でスナップショットを作成する、S3バケットへのオブジェクト追加を検知して、AIによる画像分析を実行するといったユースケースに活用できます。EventBridge を利用することで、複雑なインフラストラクチャ管理から解放され、ビジネスロジックの開発に集中できるようになります。

🔗 https://aws.amazon.com/jp/eventbridge/?did=ft_card2&trk=ft_eventbridge

---

### Amazon SNS

Amazon SNSは、アプリケーションのプッシュ通知、SMS、電子メールなどのメッセージを、複数のサブスクライバーに効率的に配信できる、完全マネージド型のメッセージングサービスです。例えば、アプリケーションのアップデートや重要なお知らせをユーザーに一斉通知したり、システム障害発生時に担当者に迅速なアラートを送信したりといったユースケースに活用できます。このサービスを利用することで、開発者はメッセージングインフラストラクチャの管理から解放され、アプリケーション開発に集中することが可能になります。

🔗 https://aws.amazon.com/jp/sns/?did=ft_card2&trk=ft_sns

---

### Amazon SQS

Amazon SQS（Simple Queue Service）は、アプリケーションコンポーネント間の通信を簡素化し、スケーラブルなメッセージキューイングを提供するマネージドサービスです。これにより、異なるサービスやシステム間で非同期にメッセージをやり取りできるようになります。例えば、ウェブアプリケーションがバックエンドの処理サービスにタスクを依頼する際に、SQSキューにメッセージを送信することで、処理サービスはキューからメッセージを取得して非同期に処理を進めることができます。これにより、アプリケーションの応答性を向上させ、リクエストの急増にも柔軟に対応することが可能になります。

🔗 https://aws.amazon.com/jp/sqs/?did=ft_card2&trk=ft_sqs

---

### Amazon SWF

Amazon Simple Workflow Service（SWF）は、クラウドアプリケーションにおける複雑なタスクの実行順序や状態を管理し、確実な処理を実現するサービスです。例えば、オンラインショッピングの注文処理において、在庫確認、決済、発送、顧客への通知といった一連のステップを、各タスクが成功・失敗した場合の再試行やタイムアウト処理を含めて、堅牢にオーケストレーションすることができます。これにより、分散システムにおける状態管理の複雑さを解消し、信頼性の高いワークフローを構築することが可能になります。

🔗 https://aws.amazon.com/jp/swf/?did=ft_card2&trk=ft_swf

---

### AWS Step Functions

AWS Step Functionsは、分散アプリケーションのコンポーネントを視覚的にワークフローとして定義し、実行を調整することで、複雑な処理を自動化できるサービスです。例えば、マイクロサービス間の連携や、バッチ処理、データパイプラインの構築といった、複数のステップからなる処理を確実に実行・管理する際に役立ちます。処理の各ステップの状態を追跡し、エラー発生時のリトライや、条件分岐による処理の振り分けも容易に行えるため、堅牢でスケーラブルなアプリケーション開発を支援します。

🔗 https://aws.amazon.com/jp/step-functions/?did=ft_card2&trk=ft_stepfunctions

## 🌐 ネットワーク

### Amazon CloudFront

Amazon CloudFrontは、世界中のユーザーに低レイテンシーで高速なコンテンツ配信を実現するCDNサービスです。ウェブサイトの画像や動画、APIリクエストなどを、ユーザーの地理的に最も近いエッジロケーションからキャッシュ配信することで、ページの表示速度を劇的に向上させます。これにより、グローバルなECサイトの顧客体験向上や、ストリーミングサービスの快適な視聴環境提供、SaaSアプリケーションの応答性改善といった、様々なユースケースで利用されています。

🔗 https://aws.amazon.com/jp/cloudfront/?did=ft_card2&trk=ft_cloudfront

---

### Amazon Route 53

Amazon Route 53 は、ドメイン名をウェブサイトやアプリケーションのIPアドレスに変換する、信頼性と拡張性に優れたDNSサービスです。これにより、ユーザーは覚えやすいドメイン名で簡単にリソースにアクセスできるようになります。例えば、ウェブサイトのトラフィックを複数のサーバーに分散させて可用性を高めたり、地理的に近いサーバーにユーザーを誘導して応答速度を向上させたりすることが可能です。また、ドメイン名の登録・管理や、ヘルスチェックによるリソースの健全性監視、DNSベースのルーティングポリシーの適用など、ウェブサイトやアプリケーションの運用に不可欠な機能を提供します。

🔗 https://aws.amazon.com/jp/route53/?did=ft_card2&trk=ft_route53

## 🔐 セキュリティ

### Amazon Cognito

Amazon Cognitoは、Webおよびモバイルアプリケーションで、シンプルかつセキュアなユーザーのサインアップ、サインイン、およびアクセスコントロールを実現するマネージドサービスです。開発者は Cognito を利用することで、ユーザーディレクトリの管理、認証フローの実装、ソーシャルIDプロバイダー（Google, Facebookなど）との連携、そしてユーザーのアクセス権限管理といった複雑な認証・認可機能を自社で構築・維持する手間なく、迅速にアプリケーションに組み込むことができます。例えば、ECサイトで顧客アカウントを管理したり、SaaSアプリケーションで企業ごとのユーザーグループを作成したりする際に、Cognitoは安全でスケーラブルなユーザー基盤を提供します。

🔗 https://aws.amazon.com/jp/cognito/?did=ft_card2&trk=ft_cognito

---

### AWS Certificate Manager

AWS Certificate Manager (ACM) は、AWS、ハイブリッド、マルチクラウド環境でSSL/TLS証明書のプロビジョニングと管理を簡素化するサービスです。ACMを利用することで、ウェブサイトやアプリケーションのセキュリティを強化し、ユーザーの信頼を得るためのSSL/TLS証明書を、簡単に、かつ無料で取得・更新・展開できます。例えば、Elastic Load Balancing (ELB) やAmazon CloudFront と連携させることで、HTTPS通信を容易に実装し、安全なウェブサイト運用を実現したり、オンプレミスのサーバーや他のクラウド環境のワークロードに対しても、ACMで発行した証明書をインポートして利用したりすることが可能です。これにより、証明書のライフサイクル管理にかかる手間やコストを大幅に削減できます。

🔗 https://aws.amazon.com/jp/certificate-manager/?did=ft_card2&trk=ft_certmanager

---

### AWS Key Management Service

AWS Key Management Service (KMS) は、AWSサービスとアプリケーションでデータを暗号化するための、安全かつ管理が容易なキー管理サービスです。KMSを使用することで、お客様は暗号化キーの作成、管理、利用をAWSに委任し、機密データを保護できます。例えば、Amazon S3に保存する機密文書や、Amazon RDSのデータベースを暗号化する際にKMSを活用することで、不正アクセスからデータを保護し、コンプライアンス要件を満たすことが可能になります。KMSは、強力な暗号化機能と詳細なアクセス制御を提供し、お客様が安心してデータを保護できるよう支援します。

🔗 https://aws.amazon.com/jp/kms/?did=ft_card2&trk=ft_kms

---

### AWS Resource Access Manager

AWS Resource Access Manager (RAM) は、AWS アカウント間または組織内で、VPC、EC2 AMI、RDS スナップショットなどの AWS リソースを安全かつ効率的に共有するためのサービスです。これにより、複数のアカウントで共通のリソースを利用したい場合や、組織内の開発チーム間でリソースを共有したい場合に、リソースの複製や複雑な権限設定を行う必要がなくなり、管理負担を大幅に軽減できます。例えば、中央集権的なセキュリティチームが管理する VPC を複数の開発アカウントと共有することで、ネットワーク設定の一貫性を保ちながら、各開発チームは自身のアプリケーション開発に集中できるようになります。RAM は、リソースへのアクセスを細かく制御できるため、セキュリティを確保しながら、リソース共有の柔軟性を高めることができます。

🔗 https://aws.amazon.com/jp/ram/?did=ft_card2&trk=ft_resourceaccess

---

### AWS Shield

AWS Shieldは、マネージド型のDDoS（分散型サービス拒否）攻撃保護を提供するクラウドベースのサービスです。ネットワークトラフィックを常時監視し、悪意のあるトラフィックを自動的に検知・軽減することで、お客様のアプリケーションとインフラストラクチャをDDoS攻撃から保護します。例えば、ゲーム、金融、eコマースといった、常に高い可用性が求められるサービスにおいて、突然のトラフィック急増によるサービス停止を防ぎ、ビジネス継続性を確保するために不可欠なサービスです。AWS Shield StandardはすべてのAWSのお客様に無料で提供され、AWS Shield Advancedでは、より高度な保護機能や専門家によるサポートが利用できます。

🔗 https://aws.amazon.com/jp/shield/?did=ft_card2&trk=ft_shield

---

### AWS WAF Bot Control

AWS WAF Bot Controlは、一般的なウェブボットの脅威からウェブアプリケーションを保護し、不正なアクティビティを効果的にブロックするサービスです。例えば、スクレイピングによる機密情報の窃取、DDoS攻撃の踏み台、アカウント乗っ取りなどを未然に防ぎ、ビジネスの健全性を維持します。このサービスを活用することで、解析ツールによるデータ収集や、悪意あるボットによるサイト改ざんといったリスクを軽減し、ユーザーエクスペリエンスの向上とシステムリソースの最適化に貢献します。

🔗 https://aws.amazon.com/jp/waf/features/bot-control/?did=ft_card2&trk=ft_WAFbc

## 📊 データ分析

### Amazon DataZone

Amazon DataZoneは、組織全体で安全かつ効率的にデータを探索、共有、管理できるサービスです。例えば、マーケティング部門が営業部門の顧客データを参照して、よりパーソナライズされたキャンペーンを展開する際に、アクセス権限の管理やデータ品質の維持といったガバナンスを強化しながら、必要なデータへのアクセスを容易にします。これにより、データサイエンティストは分析に必要なデータを素早く見つけ出し、ビジネスアナリストは最新のビジネスインサイトを迅速に把握できるようになり、データに基づいた意思決定を加速させることが可能になります。

🔗 https://aws.amazon.com/jp/datazone/?did=ft_card2&trk=ft_datazone

---

### Amazon OpenSearch Service

Amazon OpenSearch Service は、ログ分析、アプリケーションモニタリング、ウェブサイト検索などを簡単かつスケーラブルに実行できるマネージドサービスです。このサービスを利用することで、膨大なログデータをリアルタイムで収集・分析し、システムの異常検知やパフォーマンス改善に役立てることができます。また、ウェブサイトの検索機能に高度な検索体験を導入したり、ビジネスインテリジェンスのためのダッシュボードを構築したりすることも可能です。インフラストラクチャの管理をAWSに任せられるため、開発者は分析やインサイトの抽出に集中できます。

🔗 https://aws.amazon.com/jp/opensearch-service/?did=ft_card2&trk=ft_opensearch

---

### AWS Glue

AWS Glueは、データレイクの構築、データ分析、機械学習の準備を支援する、フルマネージドなETL（抽出、転送、ロード）サービスです。データカタログ機能により、様々なデータソースからのメタデータを自動的に検出し、一元管理できるため、データの可視化や分析が容易になります。例えば、複数のデータベースやS3バケットに散在するデータを統合し、分析基盤や機械学習モデルの学習データとして利用する際に、複雑なコーディングなしで効率的にデータ処理パイプラインを構築できます。サーバーレスで実行されるため、インフラ管理の負担がなく、利用した分だけの課金でコスト効率も優れています。

🔗 https://aws.amazon.com/jp/glue/?did=ft_card2&trk=ft_glue

### AWS HealthLake

AWS HealthLakeは、ヘルスケアおよびライフサイエンス組織が、構造化されていないデータや非構造化データを含む、さまざまな形式のヘルスデータを数分で安全に保存、変換、分析できるフルマネージドサービスです。このサービスを利用することで、例えば、患者の電子カルテ情報を標準化し、疾患の早期発見や治療効果の分析に活用したり、臨床試験データを統合して研究開発を加速させたりすることが可能になります。HealthLakeは、 HIPAAなどの規制要件を満たすために設計されており、データのプライバシーとセキュリティを確保しながら、医療従事者がより迅速かつ的確な意思決定を行えるよう支援します。

## 🛠️ 開発者ツール

### Amazon CodeCatalyst

Amazon CodeCatalystは、AWS上でアプリケーションを大規模かつ迅速に構築・配信するための統合開発環境です。開発者がコードの記述、ビルド、テスト、デプロイといった一連のDevOpsプロセスを効率的に実行できるよう、これらの作業を自動化し、管理するための機能を提供します。例えば、CI/CDパイプラインの迅速な構築、インフラストラクチャのコード化、開発チーム間のコラボレーション促進などが主なユースケースとして挙げられます。これにより、開発チームはインフラ管理の複雑さから解放され、より迅速なアプリケーション開発と市場投入が可能になります。

🔗 https://aws.amazon.com/jp/codecatalyst/?did=ft_card2&trk=ft_codecatalyst

### AWS CodeArtifact

AWS CodeArtifactは、ソフトウェア開発における依存関係管理を効率化する、セキュアでスケーラブル、かつコスト効率に優れたマネージド型アーティファクトリポジトリサービスです。開発者は、Maven、Gradle、npm、PyPIなど、多様なパッケージマネージャーに対応したライブラリやフレームワークをCodeArtifactに保存・管理することで、組織内のコード資産をセキュアに共有できます。これにより、外部の公開リポジトリへの依存を減らし、ビルドの再現性を高め、セキュリティリスクを低減させることが可能です。また、CI/CDパイプラインとの連携も容易で、開発ライフサイクル全体で一貫した依存関係管理を実現します。

🔗 https://aws.amazon.com/jp/codeartifact/?did=ft_card2&trk=ft_codeartifact

### AWS CodePipeline

AWS CodePipelineは、コードの変更から本番環境へのデプロイまで、アプリケーションのリリースプロセス全体を自動化する継続的デリバリーサービスです。開発者がコードをコミットすると、CodePipelineはビルド、テスト、デプロイといった一連のパイプラインステージを自動的に実行し、迅速かつ信頼性の高いアプリケーション更新を可能にします。例えば、Webアプリケーションの機能追加やバグ修正を頻繁に行う場合、CodePipelineを利用することで、手作業によるミスを減らし、開発サイクルを大幅に短縮できます。これにより、チームはより迅速に顧客に価値を提供できるようになります。

🔗 https://aws.amazon.com/jp/codepipeline/?did=ft_card2&trk=ft_codepipeline

## 🏛️ 管理とガバナンス

### Amazon CloudWatch

Amazon CloudWatch は、AWS のリソースとアプリケーションのパフォーマンスをリアルタイムで監視し、運用上の問題の特定やトラブルシューティングを支援するサービスです。例えば、EC2 インスタンスの CPU 使用率やネットワークトラフィックを収集・表示し、閾値を超えた場合にアラームを発報することで、リソースの過負荷を早期に検知し、自動的にスケールアウトするなどの対応につなげることができます。また、アプリケーションのログを収集・分析することで、エラーの発生原因を特定し、迅速な修正を可能にします。これにより、システムの可用性向上や運用コストの最適化に貢献します。

🔗 https://aws.amazon.com/jp/cloudwatch/?did=ft_card2&trk=ft_cloudwatch

---

### Amazon Managed Service for Prometheus

Amazon Managed Service for Prometheus は、Prometheus 互換のマネージドサービスであり、コンテナ化されたアプリケーションのメトリクスを効率的に収集、保存、クエリ、アラート設定できます。これにより、Kubernetes環境などでの複雑な監視インフラストラクチャの構築・運用負荷を大幅に軽減し、アプリケーションの健全性やパフォーマンスをリアルタイムで把握することが可能になります。例えば、マイクロサービスアーキテクチャにおける各サービスの稼働状況の監視や、リソース使用率の異常検知によるプロアクティブな問題解決に役立ちます。

🔗 https://aws.amazon.com/jp/prometheus/?did=ft_card2&trk=ft_msfp

---

### AWS CloudFormation

AWS CloudFormationは、テキストファイル（テンプレート）でAWSインフラストラクチャ全体をコードとして定義し、自動的にプロビジョニングできるサービスです。これにより、Webアプリケーションのサーバー、データベース、ロードバランサーなどのリソースを、手作業なしで一貫性をもって構築・管理できます。例えば、開発環境やステージング環境を素早く立ち上げたり、災害復旧のためのインフラを迅速に展開したりする際に非常に役立ちます。インフラ構成をコードで管理することで、変更履歴の追跡や、誤った設定の自動修正によるコンプライアンス維持、問題発生時の迅速な原因特定と復旧が可能になります。

🔗 https://aws.amazon.com/jp/cloudformation/?did=ft_card2&trk=ft_cloudformation

---

### AWS CloudTrail

AWS CloudTrailは、AWSアカウントで行われたAPIアクティビティを記録し、継続的に監視することで、セキュリティ分析、リソース変更の追跡、およびトラブルシューティングを支援します。例えば、誰がいつ、どのリソースに対してどのような操作を行ったかを把握できるため、不正アクセスや意図しない設定変更の検出に役立ちます。これにより、コンプライアンス要件の遵守や、インフラストラクチャのガバナンス強化にも貢献します。

🔗 https://aws.amazon.com/jp/cloudtrail/?did=ft_card2&trk=ft_cloudtrail

---

### AWS Control Tower

AWS Control Towerは、セキュリティとガバナンスを強化したマルチアカウントAWS環境を迅速かつ容易に構築・管理できるサービスです。組織全体で共通のセキュリティポリシーを適用し、アカウントの作成やアクセス管理を自動化することで、コンプライアンス遵守を支援します。例えば、新規プロジェクトごとに隔離されたアカウントを自動生成し、各アカウントの利用状況を集中管理するといったユースケースで、セキュリティリスクの低減と運用効率の向上に貢献します。

🔗 https://aws.amazon.com/jp/controltower/?did=ft_card2&trk=ft_controltower

---

### AWS License Manager

AWS License Managerは、AWS環境で利用するサードパーティ製ソフトウェアのライセンスを効率的に管理、検出、およびレポートするためのサービスです。このサービスを利用することで、組織はライセンスのコンプライアンスを維持し、不要なライセンスコストの発生を防ぐことができます。例えば、大規模なインフラストラクチャや複雑なソフトウェア構成を持つ企業では、各ライセンスが正しく適用されているかを確認するのに役立ちます。また、ライセンスの棚卸しや、各ライセンスの利用状況を把握することで、ライセンスの最適化や予算管理を支援します。さらに、AWS License Managerは、ライセンスの不正利用や無駄遣いを検知し、アラートを発する機能も備えています。

🔗 https://aws.amazon.com/jp/license-manager/?did=ft_card2&trk=ft_license-manager

---

### AWS re:Post

AWS re:Post は、AWS のお客様が技術的な疑問を解決するためのコミュニティ主導の質疑応答サービスです。ここでは、AWS の専門家や経験豊富なユーザーが、具体的な問題に対する解決策やベストプラクティスを提供しており、お客様は自身の課題解決に役立つ情報を効率的に見つけることができます。例えば、新しい AWS サービスの設定方法がわからない、発生したエラーの原因を特定したい、あるいは最適なアーキテクチャ設計についてアドバイスが欲しいといった場合に、re:Post で質問を投稿したり、過去の質問と回答を検索したりすることで、迅速な解決に繋がります。これにより、お客様は開発や運用における様々な障壁を乗り越え、AWS をより効果的に活用することが可能になります。

🔗 https://www.repost.aws/jp/?did=ft_card2&trk=ft_repost

---

### AWS Resource Explorer

AWS Resource Explorerは、AWSアカウント内のリソースをリージョンを横断して効率的に検索・発見できるサービスです。例えば、特定のタグが付与されたEC2インスタンスや、特定の名前を持つS3バケットなど、管理したいリソースを素早く見つけることができます。これにより、リソースの棚卸しや、インフラストラクチャの可視化、セキュリティ監査などを迅速に行うことが可能になり、運用管理の負担を軽減します。

🔗 https://aws.amazon.com/jp/resourceexplorer/?did=ft_card2&trk=ft_resourceexplorer

### AWS Service Catalog

AWS Service Catalogは、企業が承認済みのITサービス（アプリケーション、データベース、インフラストラクチャなど）をカタログ化し、ユーザーにセルフサービスで迅速に提供できるサービスです。これにより、IT部門は標準化された安全な環境を維持しながら、開発者やビジネスユーザーは必要なリソースをすぐに利用できるようになります。例えば、新しいプロジェクトを開始する際に、承認済みのアーキテクチャに基づいたインフラストラクチャを数クリックでプロビジョニングしたり、開発チームが迅速にテスト環境を構築したりすることが可能です。結果として、ITガバナンスを強化しつつ、イノベーションのスピードを加速させることができます。

🔗 https://aws.amazon.com/jp/servicecatalog/?did=ft_card2&trk=ft_servicecatalog

### AWS Systems Manager

AWS Systems Managerは、AWSリソースの運用を効率化し、管理を自動化するための包括的なサービスです。これにより、EC2インスタンスやオンプレミスサーバーなど、様々な環境にまたがるインフラストラクチャの運用データを一元管理し、パッチ適用、設定管理、コマンド実行、インベントリ収集といった日常的なタスクを自動化できます。例えば、多数のサーバーに対して一括でOSのパッチ適用を行ったり、特定のソフトウェアのインストールや設定変更を自動化したりすることが可能です。これにより、運用の手間を大幅に削減し、セキュリティレベルの向上やプロビジョニング時間の短縮を実現します。

🔗 https://aws.amazon.com/jp/systems-manager/?did=ft_card2&trk=ft_systemsmanager

## ✈️ 移行

### AWS Application Discovery Service

AWS Application Discovery Serviceは、オンプレミス環境のサーバーに関する詳細な情報を自動で収集し、AWSへの移行計画を支援するサービスです。サーバーのハードウェア仕様、CPUやメモリの使用率といったパフォーマンスデータ、さらには実行中のプロセスやネットワーク接続状況まで把握することで、アプリケーションの依存関係を可視化します。これにより、移行対象のサーバーやアプリケーションを正確に特定し、計画立案やコスト試算を効率化することで、スムーズなクラウド移行を実現することが可能です。

🔗 https://aws.amazon.com/jp/application-discovery/?did=ft_card2&trk=ft_appdiscovery

---

### AWS Migration Hub

AWS Migration Hub は、オンプレミスや他のクラウドから AWS へのアプリケーション移行プロセス全体を、単一の場所で可視化・追跡・管理できるサービスです。これにより、移行対象のサーバーやアプリケーションが、どの段階にあるのかを把握し、移行計画の立案や進捗管理、潜在的な課題の特定に役立ちます。例えば、多数のアプリケーションを段階的に AWS へ移行する際に、各アプリケーションの検出、計画、移行、実行といった各フェーズの状況を一元管理することで、移行プロジェクト全体の効率化とリスク低減を実現します。

🔗 https://aws.amazon.com/jp/migration-hub/?did=ft_card2&trk=ft_migrathub

---

### Migration Evaluator

Migration Evaluatorは、AWSへの移行を検討しているお客様が、オンプレミスのIT資産をAWSで運用した場合の予測コストを迅速に把握できるサービスです。これにより、事前にコスト感を掴み、予算策定や移行計画の立案を効率化できます。例えば、サーバー、データベース、ストレージなどのオンプレミス資産の情報を入力するだけで、AWSでの利用料金を試算し、コスト最適化のヒントを得ることが可能です。これは、データセンターの刷新やクラウド移行によるコスト削減を目指す企業にとって、意思決定の強力な支援となります。

🔗 https://aws.amazon.com/jp/migration-evaluator/?did=ft_card2&trk=ft_migeval
