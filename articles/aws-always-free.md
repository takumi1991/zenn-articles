# AWS 常時無料サービス 一覧 (Always Free Services)

Amazon Web Services の常時無料枠（Always Free Services）はアカウント作成後の12ヶ月間のみ利用できる無料枠（Free Tier）とは異なり、**一定の使用量までは期限なく無料**で利用できるサービス群です。完全に無制限で無料というわけではなく、各サービスごとに定められた無料枠を超えた場合は従量課金が発生します。

本記事では、AWS公式が公開している常時無料対象サービスを一覧で整理しています。個人開発・学習・コスト最適化の参考として活用してください。

👉 English version: https://zenn.dev/good_sleeper/articles/aws-always-free-en

## 💻 コンピューティング

### AWS Lambda

## AWS Lambda

AWS Lambdaは、サーバーのプロビジョニングや管理なしにコードを実行できるイベント駆動型のコンピューティングサービスです。画像やファイルのアップロード、ウェブサイトのクリック、APIゲートウェイからのリクエストなど、様々なイベントをトリガーとしてコードを実行できます。これにより、例えば、アップロードされた画像を自動的にリサイズしたり、データベースへの変更を検知して通知を送信したり、ウェブサイトのバックエンド処理をサーバーレスで構築するといったことが可能になり、開発者はインフラ管理から解放され、アプリケーション開発に集中できます。

🔗 https://aws.amazon.com/jp/lambda/?did=ft_card2&trk=ft_lambda

## 🧱 データベース

### Amazon Aurora DSQL

Amazon Aurora DSQLは、高性能でスケーラブルな分散SQLデータベースであり、常時稼働が求められるアプリケーションに最適です。このサービスは、自動スケーリングや耐障害性を備え、開発者はインフラ管理に煩わされることなく、ビジネスロジックに集中できます。特に、急激なトラフィック変動に対応する必要があるWebサイト、eコマースプラットフォーム、IoTデータ処理などのユースケースで、その真価を発揮します。サーバーレスであるため、利用した分だけの課金となり、コスト効率にも優れています。

🔗 https://aws.amazon.com/jp/rds/aurora/dsql/?did=ft_card2&trk=ft_dsql

---

### Amazon DynamoDB

Amazon DynamoDBは、あらゆる規模で1桁ミリ秒のパフォーマンスを提供するサーバーレスNoSQLデータベースです。これは、ウェブアプリケーション、モバイルバックエンド、ゲーム、IoTデバイスなど、迅速かつ一貫したパフォーマンスが求められる多様なユースケースにおいて、データストアとして活用されます。フルマネージドサービスであるため、インフラストラクチャの管理は不要で、開発者はアプリケーション開発に集中できます。スケーラビリティに優れ、トラフィックの変動にも柔軟に対応するため、ビジネスの成長に合わせて安心して利用できます。

🔗 https://aws.amazon.com/jp/dynamodb/?did=ft_card2&trk=ft_dynamodb

---

### Amazon SimpleDB

Amazon SimpleDB は、ウェブアプリケーションなどのデータ保存・取得を容易にする、スケーラブルな NoSQL データベースサービスです。データベース管理の煩雑さから解放され、開発者はアプリケーション開発に集中できます。例えば、ブログのコメント管理や、製品カタログ、ユーザープロファイルといった、構造が頻繁に変わる可能性のあるデータを扱う場合に特に有効です。SimpleDB は、データ構造の柔軟性が高く、インデックス作成やクエリがシンプルであるため、迅速な開発と拡張が可能です。

🔗 https://aws.amazon.com/jp/simpledb/?did=ft_card2&trk=ft_simpledb

## 🧩 アプリケーション統合

### Amazon EventBridge

Amazon EventBridgeは、AWSサービス、自社システム、SaaSアプリケーションなど、さまざまなソースからのイベントをルーティングし、イベント駆動型アプリケーションを大規模に構築できるサーバーレスイベントバスサービスです。例えば、S3バケットにファイルがアップロードされたことをトリガーに、Lambda関数を実行してそのファイルを分析したり、EC2インスタンスのステータス変更を検知して通知を送信したりするなど、システム間の連携を容易にし、自動化を実現します。これにより、ビジネスロジックの変更に柔軟に対応し、スケーラブルでレジリエントなアプリケーションを構築できます。

🔗 https://aws.amazon.com/jp/eventbridge/?did=ft_card2&trk=ft_eventbridge

---

### Amazon SNS

Amazon SNSは、アプリケーションとエンドユーザー間のメッセージングを可能にする、高速で柔軟な完全マネージド型のプッシュメッセージングサービスです。このサービスを利用することで、アプリケーションは様々なエンドポイント、例えばモバイルデバイスへのプッシュ通知、メール、SMSメッセージ、さらには他のAWSサービスへのメッセージ送信を容易に行えます。例えば、システム障害発生時に管理者へ即座に通知を送信したり、ユーザー登録完了時に確認メールを自動送信したりするといったユースケースが考えられます。これにより、リアルタイムな情報伝達と、ビジネスプロセスにおける効率化が実現されます。

🔗 https://aws.amazon.com/jp/sns/?did=ft_card2&trk=ft_sns

---

### Amazon SQS

Amazon SQSは、アプリケーションコンポーネント間のメッセージを耐久性高く、スケーラブルにやり取りできるマネージドメッセージキューサービスです。これにより、マイクロサービスアーキテクチャにおいて、各サービスが独立して処理を進めつつ、非同期で情報を連携させることが可能になります。例えば、Webアプリケーションからの注文情報をバックエンドの処理システムにキューイングしておけば、バックエンドシステムは注文の負荷に応じて柔軟に処理能力を調整でき、システム全体の可用性と応答性を向上させることができます。また、バッチ処理のタスクをキューに格納し、ワーカープロセスが順次処理していくようなシナリオにも適しています。

🔗 https://aws.amazon.com/jp/sqs/?did=ft_card2&trk=ft_sqs

---

### Amazon SWF

Amazon Simple Workflow Service (SWF) は、クラウドアプリケーションの複雑なワークフローを管理するための強力なサービスです。SWFを利用することで、複数のマイクロサービスやタスクが連携する分散システムにおいて、各ステップの実行順序、状態遷移、エラーハンドリングを正確に制御できます。例えば、ECサイトでの注文処理のように、在庫確認、決済、発送指示といった一連の処理を確実に完了させるためにSWFが活用されます。また、ユーザーの操作を待つような人間による承認プロセスを含むワークフローや、バッチ処理の実行管理など、様々なビジネスロジックの実装に貢献します。SWFは、アプリケーションの信頼性とスケーラビリティを高め、開発者が複雑なステート管理から解放されることを可能にします。

🔗 https://aws.amazon.com/jp/swf/?did=ft_card2&trk=ft_swf

---

### AWS Step Functions

AWS Step Functionsは、分散アプリケーションのコンポーネントを視覚的にワークフローとして定義し、実行できるサービスです。これにより、マイクロサービスやAWS Lambda関数などの複雑な処理の流れを、ステートマシンとして容易に管理・オーケストレーションできます。例えば、ECサイトでの注文処理において、在庫確認、決済、出荷通知といった一連のステップをStep Functionsで定義することで、各処理の成功・失敗に応じた分岐やリトライを自動化し、信頼性の高いアプリケーションを構築できます。また、バッチ処理の実行順序制御や、機械学習パイプラインのオーケストレーションなど、多様なユースケースで活用されています。

🔗 https://aws.amazon.com/jp/step-functions/?did=ft_card2&trk=ft_stepfunctions

## 🌐 ネットワーク

### Amazon CloudFront

Amazon CloudFrontは、世界中に広がるエッジロケーションを活用し、WebサイトのコンテンツやAPIレスポンスを低レイテンシーかつ高速にエンドユーザーへ配信するCDN（Contents Delivery Network）サービスです。これにより、画像や動画などの静的コンテンツだけでなく、動的なWebアプリケーションの応答速度も劇的に向上させることができます。例えば、グローバルに展開するECサイトでは、世界中の顧客に対してスムーズなショッピング体験を提供し、グローバルなゲーム配信では、プレイヤーにラグの少ない快適なプレイ環境を実現するために利用されています。CloudFrontは、オリジンサーバーへの負荷を軽減しながら、ユーザーの最も近い場所からコンテンツをキャッシュして配信するため、ウェブサイトのパフォーマンス改善とスケーラビリティ向上に大きく貢献します。

🔗 https://aws.amazon.com/jp/cloudfront/?did=ft_card2&trk=ft_cloudfront

---

### Amazon Route 53

Amazon Route 53 は、ウェブサイトのドメイン名とIPアドレスを紐づける、可用性と拡張性に優れたクラウドDNSサービスです。これにより、ユーザーが覚えやすいドメイン名でウェブサイトにアクセスできるようになります。例えば、インターネットに接続されたアプリケーションのトラフィックを複数のEC2インスタンスに分散させたり、ユーザーの地理的位置に基づいて最適なエンドポイントにルーティングしたりすることが可能です。また、ドメイン名の登録やDNSレコードの管理も一元的に行えるため、ウェブサイトの運用管理を効率化できます。

🔗 https://aws.amazon.com/jp/route53/?did=ft_card2&trk=ft_route53

## 🔐 セキュリティ

### Amazon Cognito

Amazon Cognitoは、Webやモバイルアプリに、シンプルかつ安全なユーザーサインアップ、サインイン、およびアクセスコントロール機能を手軽に組み込めるマネージドサービスです。開発者は、ユーザーディレクトリの構築や管理、認証フローの実装といった複雑な作業をAmazon Cognitoに任せることで、アプリケーション開発に集中できます。例えば、ソーシャルログイン（Google, Facebookなど）や、カスタム属性を用いたユーザー管理、MFA（多要素認証）によるセキュリティ強化などが実現できます。これにより、ユーザーは迅速かつ安全にサービスにアクセスできるようになり、企業はセキュリティリスクを低減しつつ、スムーズなユーザー体験を提供できます。

🔗 https://aws.amazon.com/jp/cognito/?did=ft_card2&trk=ft_cognito

---

### AWS Certificate Manager

AWS Certificate Manager (ACM) は、AWS、ハイブリッド、マルチクラウド環境におけるSSL/TLS証明書のプロビジョニングと管理を簡素化するサービスです。ACMを利用することで、ウェブサイトやアプリケーションへの安全な接続を確立するために不可欠な証明書を、手間なく取得・更新・展開できます。例えば、Amazon CloudFrontと連携させてCDN経由の通信を暗号化したり、Elastic Load Balancing (ELB) でロードバランシングされたアプリケーションのSSL終端を処理したりする際に役立ちます。証明書の有効期限管理も自動化されるため、セキュリティリスクの低減に貢献します。

🔗 https://aws.amazon.com/jp/certificate-manager/?did=ft_card2&trk=ft_certmanager

---

### AWS Key Management Service

AWS Key Management Service (KMS) は、AWSサービスやアプリケーションでデータを暗号化および管理するための、シンプルで安全な鍵管理サービスです。KMSを利用することで、お客様は鍵の作成、管理、利用を容易に行え、データの機密性を保つことができます。例えば、S3に保存される機密情報や、RDSデータベースのデータを保護するためにKMSで生成した鍵を利用することで、不正アクセスからデータを守ることができます。また、KMSはAWSの他のサービスとシームレスに連携するため、特別な開発作業なしに、既存のAWSリソースのセキュリティを強化することが可能です。

🔗 https://aws.amazon.com/jp/kms/?did=ft_card2&trk=ft_kms

---

### AWS Resource Access Manager

AWS Resource Access Manager (RAM) は、AWS アカウント間や組織内で、Amazon S3 バケット、VPC、EC2 スポットフリートリクエストなどの AWS リソースを安全かつ効率的に共有できるサービスです。これにより、複数のアカウントで共通のリソースを利用する際に、リソースの重複作成や管理の手間を削減できます。例えば、中央集権的なセキュリティアカウントで管理している VPC を、開発アカウントやテストアカウントと共有することで、ネットワーク設定の一貫性を保ちつつ、各アカウントでのリソース作成を容易にします。また、組織全体で共通のログバケットを共有する際などにも利用され、ガバナンスと運用効率を向上させます。

🔗 https://aws.amazon.com/jp/ram/?did=ft_card2&trk=ft_resourceaccess

---

### AWS Shield

AWS Shieldは、DDoS攻撃からお客様のAWS上のアプリケーションを保護するマネージド型DDoS保護サービスです。ネットワークトラフィックを常時監視し、悪意のあるトラフィックを検知・緩和することで、ウェブサイトやAPIの可用性を維持します。例えば、ゲームのリリースイベントや大規模なプロモーションキャンペーンなど、トラフィックの急増が予想される際に、DDoS攻撃によるサービス停止のリスクを軽減し、ビジネスへの影響を最小限に抑えるのに役立ちます。AWS Shield Advancedでは、さらに高度な保護機能やコスト管理、専門家によるサポートも提供されます。

🔗 https://aws.amazon.com/jp/shield/?did=ft_card2&trk=ft_shield

---

### AWS WAF Bot Control

AWS WAF Bot Controlは、一般的なウェブボットによる悪意のあるアクティビティからウェブアプリケーションを保護するマネージドサービスです。これにより、スクレイピング、アカウント乗っ取り、DDoS攻撃などの bot トラフィックを検知・ブロックし、ビジネスロジックの悪用や、高負荷によるサービス停止を防ぐことができます。例えば、ECサイトでの不正な価格変更や、チケット販売サイトでの bot による大量購入といったシナリオにおいて、ボットの挙動を分析して自動的に緩和策を適用することで、正当なユーザー体験を維持し、ビジネスの機会損失を防ぎます。

🔗 https://aws.amazon.com/jp/waf/features/bot-control/?did=ft_card2&trk=ft_WAFbc

## 📊 データ分析

### Amazon DataZone

Amazon DataZoneは、組織内のあらゆる場所にあるデータを、ガバナンスを維持しながら安全かつ効率的に発見、共有、活用できるサービスです。例えば、マーケティング部門が営業データを分析してキャンペーンの効果を測定したり、エンジニアリング部門が開発データを参照して製品の品質改善に繋げるといったユースケースが考えられます。このサービスを利用することで、データサイエンティストやアナリストは、社内外のデータへのアクセス権限を管理しつつ、必要なデータに容易にたどり着き、より迅速にビジネス上の洞察を得られるようになります。

🔗 https://aws.amazon.com/jp/datazone/?did=ft_card2&trk=ft_datazone

---

### Amazon OpenSearch Service

Amazon OpenSearch Serviceは、インタラクティブなログ分析、リアルタイムのアプリケーションモニタリング、ウェブサイト検索などを容易に実行できるマネージドサービスです。このサービスを利用することで、大量のデータを迅速に検索、分析、可視化することが可能となり、例えば、ウェブサイトのトラフィック分析や、アプリケーションのエラーログ追跡、セキュリティイベントの監視といった用途に活用できます。サーバーのプロビジョニングや運用管理の手間を削減し、スケーラビリティと高可用性を備えた環境で、データに基づいた意思決定を強力にサポートします。

🔗 https://aws.amazon.com/jp/opensearch-service/?did=ft_card2&trk=ft_opensearch

---

### AWS Glue

AWS Glueは、データレイクの構築、データ分析、機械学習などのための、フルマネージドなETL（抽出、変換、ロード）サービスです。サーバーレスで実行されるため、インフラストラクチャの管理は不要で、実行時間に基づいた課金でコスト効率に優れています。主なユースケースとして、様々なデータソースからデータを抽出し、クリーニングや変換を経てデータウェアハウスやデータレイクにロードするデータ統合処理、リアルタイムストリーミングデータの処理、機械学習モデルのトレーニング用データセットの準備などが挙げられます。これにより、開発者はデータ準備に費やす時間を削減し、より価値の高い分析や洞察の獲得に集中できます。

🔗 https://aws.amazon.com/jp/glue/?did=ft_card2&trk=ft_glue

## 🛠️ 開発者ツール

### Amazon CodeCatalyst

Amazon CodeCatalystは、AWS上でアプリケーションを迅速かつ効率的に構築・配信するための統合開発環境です。開発チームは、CI/CDパイプラインの構築、コードリポジトリの管理、プロジェクトの進捗管理といった一連の開発プロセスを、このプラットフォーム上で完結できます。例えば、新しいWebアプリケーションを開発する際に、コードのコミットからテスト、デプロイまでを自動化することで、市場投入までの時間を大幅に短縮し、開発者の生産性を向上させることができます。これにより、アジャイル開発を推進し、変化の速いビジネスニーズに柔軟に対応することが可能になります。

🔗 https://aws.amazon.com/jp/codecatalyst/?did=ft_card2&trk=ft_codecatalyst

### AWS CodeArtifact

AWS CodeArtifactは、ソフトウェア開発における依存関係管理を効率化する、セキュアでスケーラブルなパッケージ管理サービスです。開発者は、Maven、npm、NuGetなどの様々なパッケージリポジトリから依存関係をダウンロード・管理したり、自社で開発したライブラリをプライベートリポジトリとして保管・共有したりできます。これにより、組織内外のコードを安全に再利用でき、ビルドプロセスを迅速化し、依存関係の衝突やセキュリティリスクを軽減することが可能になります。例えば、複数のチームが共通のライブラリを利用する際のバージョン管理や、社内標準ライブラリの配布基盤として活用できます。

🔗 https://aws.amazon.com/jp/codeartifact/?did=ft_card2&trk=ft_codeartifact

### AWS CodePipeline

AWS CodePipelineは、ソースコードの変更から本番環境へのデプロイまで、アプリケーションのリリースプロセス全体を自動化し、迅速かつ信頼性の高いアプリケーション更新を実現する継続的デリバリーサービスです。開発者がコードをコミットすると、CodePipelineは自動的にビルド、テスト、そしてデプロイの各ステージを実行します。例えば、Webアプリケーションの更新や、マイクロサービスの継続的なデプロイメントなど、CI/CDパイプラインの構築に不可欠なツールとして利用され、手作業によるミスを削減し、開発サイクルの短縮と品質向上に貢献します。

🔗 https://aws.amazon.com/jp/codepipeline/?did=ft_card2&trk=ft_codepipeline

## 🏛️ 管理とガバナンス

### Amazon CloudWatch

Amazon CloudWatchは、AWSのクラウド上のリソースやアプリケーションのパフォーマンスを監視し、運用上の問題や異常を検知・通知するサービスです。例えば、EC2インスタンスのCPU使用率やディスクI/Oをリアルタイムで収集・可視化することで、リソースの逼迫を早期に発見し、キャパシティプランニングに役立てたり、Lambda関数の実行回数やエラー率を監視して、アプリケーションの正常性を維持したりすることができます。さらに、カスタムメトリクスを定義して独自のビジネス指標を追跡することも可能であり、ログデータを一元管理して分析することで、トラブルシューティングの迅速化にも貢献します。

🔗 https://aws.amazon.com/jp/cloudwatch/?did=ft_card2&trk=ft_cloudwatch

---

### Amazon Managed Service for Prometheus

Amazon Managed Service for Prometheus (AMP) は、Prometheus と互換性のあるマネージドサービスであり、コンテナ化されたアプリケーションのメトリクスを収集、保存、クエリ、アラート通知するために利用できます。Kubernetes 環境など、動的に変化するインフラストラクチャにおけるアプリケーションのパフォーマンス監視や、異常検知による迅速な問題解決に役立ちます。AMP を利用することで、Prometheus サーバーの運用・管理に関する負担を軽減し、スケーラビリティと可用性の高い監視基盤を構築できます。これにより、開発チームはアプリケーション開発に集中し、運用チームはインフラストラクチャの安定稼働に注力することが可能となります。

🔗 https://aws.amazon.com/jp/prometheus/?did=ft_card2&trk=ft_msfp

---

### AWS CloudFormation

AWS CloudFormationは、コードを用いてAWSインフラストラクチャ全体を定義し、自動的にプロビジョニングできるサービスです。これにより、EC2インスタンス、S3バケット、RDSデータベースなどのリソースをテンプレートとして記述し、再現性高くデプロイすることが可能になります。例えば、Webアプリケーションの環境構築において、サーバー、データベース、ロードバランサー、セキュリティグループなどをまとめて定義することで、手作業による設定ミスを防ぎ、迅速な環境展開や災害復旧を実現できます。また、インフラストラクチャの変更管理もコードで行えるため、バージョン管理システムとの連携でコンプライアンスの維持やトラブルシューティングが容易になります。

🔗 https://aws.amazon.com/jp/cloudformation/?did=ft_card2&trk=ft_cloudformation

---

### AWS CloudTrail

AWS CloudTrail は、AWS アカウント全体で実行された API コールなどのアクティビティを記録し、継続的に監視することで、セキュリティ、ガバナンス、コンプライアンスの向上に貢献するサービスです。このサービスを利用することで、誰が、いつ、どこで、どのようなリソースに対して操作を行ったのかを詳細に把握でき、不正アクセスや意図しない設定変更の早期発見、インシデント発生時の原因究明に役立ちます。例えば、重要なリソースへのアクセス権限が変更された場合、CloudTrail のログを追跡することで、変更が行われた日時や変更者、変更内容を特定し、迅速な対応が可能となります。これにより、AWS 環境の安全性を高め、監査要件への対応を容易にします。

🔗 https://aws.amazon.com/jp/cloudtrail/?did=ft_card2&trk=ft_cloudtrail

---

### AWS Control Tower

AWS Control Towerは、セキュアで管理しやすいマルチアカウントAWS環境を素早く構築・運用できるサービスです。組織全体でAWSアカウントを効果的に管理し、セキュリティとコンプライアンスを強化するために利用されます。例えば、新規プロジェクトごとに新しいAWSアカウントを自動的にプロビジョニングし、一元化されたアクセス管理やログ収集の仕組みを適用することで、ガバナンスを維持しつつ、各チームが独立してAWSリソースを利用できる環境を提供します。これにより、セキュリティポリシーの遵守と運用効率の向上が同時に実現できます。

🔗 https://aws.amazon.com/jp/controltower/?did=ft_card2&trk=ft_controltower

---

### AWS License Manager

AWS License Managerは、AWS上やオンプレミス環境で利用するサードパーティ製ソフトウェアライセンスの管理、検出、およびレポート作成を自動化するサービスです。これにより、組織はライセンスのコンプライアンスを維持し、意図しないライセンス超過によるコスト発生を防ぐことができます。例えば、特定のインスタンスタイプやアカウントにライセンスの使用を制限するルールを設定したり、ライセンスの利用状況を定期的に確認してレポートを生成したりすることが可能です。これにより、ライセンス管理にかかる人的コストを削減し、より戦略的なITリソースの活用を促進します。

🔗 https://aws.amazon.com/jp/license-manager/?did=ft_card2&trk=ft_license-manager

---

### AWS re:Post

AWS re:Postは、AWSの技術的な疑問や問題を解決するためのコミュニティ主導の質疑応答サービスです。AWSの利用者同士が互いに助け合い、経験を共有することで、様々な課題に対する解決策を見つけ出すことができます。例えば、特定のサービスの設定方法が分からない、エラーの原因が特定できない、あるいはベストプラクティスを知りたいといった場合に、re:Postで質問を投稿したり、過去の質問と回答を検索したりすることで、迅速かつ的確な情報を得ることが可能です。これにより、開発者はより効率的にAWSを活用し、プロジェクトを成功に導くことができます。

🔗 https://www.repost.aws/jp/?did=ft_card2&trk=ft_repost

---

### AWS Resource Explorer

AWS Resource Explorerは、AWSリージョン全体に散らばるリソースを横断的に検索・発見できるサービスです。これにより、例えば「特定のタグが付与されたEC2インスタンスを全リージョンから探し出したい」といった運用時の課題を迅速に解決できます。開発者や運用担当者は、リソースの所在を把握するための手作業を大幅に削減し、設定ミスや管理漏れを防ぐことで、より効率的かつ安全にAWS環境を管理できます。

🔗 https://aws.amazon.com/jp/resourceexplorer/?did=ft_card2&trk=ft_resourceexplorer

---

### AWS Service Catalog

AWS Service Catalog を利用すると、組織内で承認済みの IT サービス（アプリケーション、ソフトウェア、インフラストラクチャなど）のカタログを作成・管理し、ユーザーが容易にデプロイできるようになります。これにより、開発チームは標準化された安全な環境ですぐに作業を開始でき、IT 部門はガバナンスとコンプライアンスを維持しながらリソースの調達プロセスを効率化できます。例えば、新しいプロジェクトのために迅速かつ一貫性のある開発環境をセットアップしたい場合や、規制要件を満たすために特定の構成のインスタンスのみをデプロイできるようにしたい場合に役立ちます。

🔗 https://aws.amazon.com/jp/servicecatalog/?did=ft_card2&trk=ft_servicecatalog

---

### AWS Systems Manager

AWS Systems Managerは、AWSリソースの運用データを集約し、複数サービスにまたがるタスクを自動化できるサービスです。例えば、パッチ適用、設定変更、インベントリ収集といった運用管理作業を、EC2インスタンスだけでなくコンテナやオンプレミスサーバーに対しても一元的に実施できます。これにより、手作業によるミスを削減し、運用効率を大幅に向上させることが可能です。さらに、SSMドキュメントを活用することで、複雑な運用手順も自動化ワークフローとして定義・実行でき、セキュリティ強化やコンプライアンス遵守にも貢献します。

🔗 https://aws.amazon.com/jp/systems-manager/?did=ft_card2&trk=ft_systemsmanager

## ✈️ 移行

### AWS Application Discovery Service

AWS Application Discovery Serviceは、オンプレミス環境にあるサーバーのハードウェア仕様、パフォーマンスメトリクス、実行中のプロセス、ネットワーク接続といった詳細情報を自動的に収集し、AWSへの移行計画を支援するサービスです。これにより、アプリケーションの依存関係やリソース使用状況を正確に把握し、最適な移行戦略の策定やコスト削減の機会特定に役立ちます。例えば、多数のサーバーが稼働する大規模なデータセンターからAWSへの移行を検討する際に、本サービスを活用することで、移行対象のサーバー群を効率的に特定し、各サーバーの特性に基づいた移行計画を具体的に立てることが可能となります。

🔗 https://aws.amazon.com/jp/application-discovery/?did=ft_card2&trk=ft_appdiscovery

---

### AWS Migration Hub

AWS Migration Hubは、オンプレミスや他のクラウドからAWSへのアプリケーション移行プロセス全体を一元管理し、進捗状況を可視化できるサービスです。これにより、移行対象のサーバーやアプリケーションの発見から、評価、計画、そして実行までの各フェーズにおける状態を把握し、移行プロジェクトの全体像を容易に把握することが可能になります。例えば、多数のアプリケーションを段階的にAWSへ移行する際に、各アプリケーションの移行ステータスや依存関係をMigration Hub上で確認することで、計画の遅延や予期せぬ問題を早期に発見し、効率的かつスムーズな移行を実現します。

🔗 https://aws.amazon.com/jp/migration-hub/?did=ft_card2&trk=ft_migrathub

---

### Migration Evaluator

Migration Evaluator は、オンプレミスのIT資産をAWSへ移行する際の予測コストを迅速に把握できるサービスです。お客様は、既存のサーバーやストレージなどの情報を入力することで、AWS環境で同等のリソースを運用した場合のコストを試算できます。これにより、移行計画の初期段階で費用対効果を評価し、予算策定や移行戦略の立案を支援します。例えば、データセンターの刷新やクラウドへの移行を検討している企業が、移行先のAWSでの運用コストを事前に見積もる際に役立ちます。

🔗 https://aws.amazon.com/jp/migration-evaluator/?did=ft_card2&trk=ft_migeval
