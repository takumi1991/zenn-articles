# AWS 常時無料サービス（Always Free Services） 一覧

AWS の常時無料サービス（Always Free Services）はアカウント作成後の 12 か月間だけ利用できる無料利用枠（Free Tier）とは異なり、12 ヶ月を超えても **特定の使用量まではずっと無料で使えるサービス群** です。

完全に無制限で無料というわけではなく、各サービスの無料枠（リクエスト数、GB、クォータなど）を超えた部分は通常の従量課金が発生します。

本記事では AWS が公式に公開している Always Free 対象サービスを一覧でまとめています。  
クラウド学習、個人開発、コスト最適化の参考にぜひご活用ください。


## Amazon Aurora

Serverless relational database with unparalleled high performance and availability at global scale.

比類のない高性能と可用性をグローバル規模で実現する、サーバーレス型リレーショナルデータベース。

## AWS Transform

The first agentic AI service to accelerate the transformation of Windows, mainframe, VMware, and more.

Windows、メインフレーム、VMwareなどの変革を加速させる、初のエージェント型AIサービス。

## Amazon DynamoDB

Serverless, NoSQL, fully managed database with single-digit millisecond performance at any scale.

サーバーレス、NoSQL、フルマネージド型のデータベースで、あらゆる規模において1桁ミリ秒のパフォーマンスを実現します。

## AWS Lambda

Run code without thinking about servers or clusters

サーバーやクラスターのことを気にせずにコードを実行できます。

## AWS Security Incident Response

Automated security incident response with AWS expert guidance.

AWSのエキスパートによるガイダンスに基づいた、自動化されたセキュリティインシデント対応。

## AWS License Manager

Set rules to manage, discover, and report third-party license usage proactively.

サードパーティのライセンス使用状況を積極的に管理、検出、報告するためのルールを設定します。

## AWS Key Management Service

AWS Key Management Service is a managed service that provides easy encryption with administrative controls.

AWS Key Management Serviceは、管理制御機能を備えた容易な暗号化を提供するマネージドサービスです。

## AWS HealthLake

Securely store, transform, transact, and analyze health data in minutes

健康データを安全に保管、変換、処理、分析する（数分で完了）

## Amazon SQS

Scalable queue for storing messages as they travel between computers.

コンピュータ間を移動するメッセージを一時的に保存するための、拡張性の高いキュー。

## AWS Shield

Protects networks and applications by analyzing network security configurations and providing managed DDoS protection

ネットワークセキュリティ構成を分析し、マネージドDDoS防御を提供することで、ネットワークとアプリケーションを保護します。

## AWS Glue

Simple, flexible, and cost-effective extract, transform, and load (ETL) service.

シンプルで柔軟性があり、費用対効果の高い抽出、変換、ロード（ETL）サービス。

## Amazon CloudFront

Web service to distribute content to end users with low latency and high transfer speeds.

エンドユーザーに低遅延かつ高速な転送速度でコンテンツを配信するウェブサービス。

## AWS CodeArtifact

Secure, scalable, and cost-effective package management for software development

ソフトウェア開発のための、安全で拡張性が高く、費用対効果の高いパッケージ管理

## AWS Certificate Manager

Provision and manage SSL/TLS certificates for use with AWS, hybrid, and multicloud workloads

AWS、ハイブリッド、マルチクラウドワークロードで使用するためのSSL/TLS証明書をプロビジョニングおよび管理します。

## AWS CloudFormation

Model and provision all your cloud infrastructure resources with code to enable configuration compliance and faster troubleshooting.

クラウドインフラストラクチャのすべてのリソースをコードでモデル化およびプロビジョニングすることで、構成のコンプライアンスを確保し、トラブルシューティングを迅速化できます。

## AWS WAF Bot Control

Protect your web applications from common and pervasive web bots

一般的で蔓延しているウェブボットからウェブアプリケーションを保護しましょう

## Amazon OpenSearch Service

Simplify AI-powered search, observability, and vector database operations with a secure, cost-effective managed service.

安全で費用対効果の高いマネージドサービスにより、AIを活用した検索、監視、およびベクトルデータベースの操作を簡素化します。

## Amazon Q Developer

The most capable generative AI–powered assistant for software development

ソフトウェア開発のための最も高性能な生成型AI搭載アシスタント

## AWS re:Post

A community-driven, questions-and-answers service to help AWS customers remove technical roadblocks.

AWSのお客様が技術的な障害を克服できるよう支援する、コミュニティ主導型の質疑応答サービス。

## AWS Resource Explorer

Use AWS Resource Explorer to easily search for and discover your resources across AWS Regions.

AWS Resource Explorer を使用すると、AWS リージョン全体にわたってリソースを簡単に検索および検出できます。

## Migration Evaluator

Migration Evaluator helps customers rapidly see projected costs of running their on-premises estate in AWS.

Migration Evaluatorは、顧客がオンプレミス環境をAWSで運用する際の予測コストを迅速に把握できるように支援します。

## AWS CodePipeline

Continuous delivery service for fast and reliable application updates.

迅速かつ信頼性の高いアプリケーションアップデートを実現する継続的デリバリーサービス。

## Amazon CodeCatalyst

Quickly build and deliver apps at scale on AWS

AWS上でアプリを迅速に構築し、大規模に配信する

## AWS Systems Manager

Centralize operational data from multiple AWS services and automate tasks across your AWS resources.

複数のAWSサービスから運用データを一元管理し、AWSリソース全体にわたるタスクを自動化します。

## AWS Application Migration Service

Simplify and expedite migrations while reducing cost.

移行プロセスを簡素化・迅速化し、コストを削減します。

## Amazon SNS

Fast, flexible, fully managed push messaging service.

高速で柔軟性に優れた、完全管理型のプッシュメッセージングサービス。

## Amazon EventBridge

Build event-driven applications at scale across AWS, existing systems, or SaaS applications

AWS、既存システム、またはSaaSアプリケーション全体で、イベント駆動型アプリケーションを大規模に構築します。

## Amazon CloudWatch

Monitoring for AWS cloud resources and applications.

AWSクラウドのリソースとアプリケーションの監視。

## Amazon SimpleDB

Amazon SimpleDB is a highly available NoSQL data store that offloads the work of database administration.

Amazon SimpleDBは、データベース管理の手間を軽減する、可用性の高いNoSQLデータストアです。

## AWS Resource Access Manager

Securely share your resources across AWS accounts or within your organization.

AWSアカウント間、または組織内でリソースを安全に共有できます。

## AWS Control Tower

The easiest way to set up and govern a new, secure multi-account AWS environment.

新しい安全なマルチアカウントAWS環境をセットアップおよび管理する最も簡単な方法。

## Amazon Q Business

Unleash the power of generative AI in the workplace with Amazon Q Business

Amazon Q Businessで、職場における生成型AIの力を解き放ちましょう。

## AWS CodeBuild

Fully managed build service that builds and tests code in the cloud.

クラウド上でコードのビルドとテストを行う、完全マネージド型のビルドサービス。

## Amazon DataZone

Unlock data across organizational boundaries with built-in governance capabilities

組み込みのガバナンス機能で組織の境界を越えたデータ活用を可能にする

## AWS CloudTrail

Log, continuously monitor, and retain account activity related to actions across your AWS infrastructure.

AWSインフラストラクチャ全体における操作に関連するアカウントアクティビティをログに記録し、継続的に監視および保持します。

## AWS X-Ray

Analyze and debug your applications.

アプリケーションの分析とデバッグを行います。

## Amazon Route 53

Amazon Route 53 is a highly available and scalable cloud Domain Name System (DNS) web service.

Amazon Route 53は、可用性と拡張性に優れたクラウド型ドメインネームシステム（DNS）ウェブサービスです。

## AWS Service Catalog

Create and manage catalogs of IT services that are approved for use on AWS.

AWSでの利用が承認されているITサービスのカタログを作成および管理します。

## Amazon Cognito

Simple and Secure User Sign-Up, Sign-In, and Access Control.

シンプルで安全なユーザー登録、ログイン、およびアクセス制御。

## Amazon SWF

Task coordination and state management service for Cloud applications.

クラウドアプリケーション向けのタスク調整および状態管理サービス。

## AWS Step Functions

Coordinate components of distributed applications.

分散アプリケーションの構成要素を調整する。

## AWS Budgets

Improve planning and cost control with flexible budgeting and forecasting

柔軟な予算編成と予測により、計画とコスト管理を改善する
