# Azure常時無料サービス一覧

### Azure AI Search

Azure AI Search は、Web アプリケーションやモバイルアプリに高度な検索機能を簡単に追加できる、フルマネージドのクラウド検索サービスです。AI を活用したインテリジェントな検索エクスペリエンスを提供し、ユーザーが求める情報を迅速かつ正確に見つけられるように支援します。例えば、EC サイトで商品の詳細な絞り込み検索を実現したり、社内ドキュメントポータルで関連情報を効率的に探したりする際に活用できます。自然言語処理や画像認識などの AI 機能と連携させることで、よりリッチでパーソナライズされた検索体験の構築が可能です。

**毎月の上限：** サービスごとに 10,000 件のホスト ドキュメントと 3 つのインデックスを保存できる 50 MB のストレージ

🔗 https://azure.microsoft.com/ja-jp/products/ai-services/ai-search/

### Azure Language

Azure Languageは、Azure AI Languageの一部として提供される、自然言語処理（NLP）の強力なサービス群です。このサービスを利用することで、テキストデータから意味のある情報を抽出・理解することが可能になります。具体的には、文書の感情分析を行い、肯定的なのか否定的なのかを判断したり、文章の主題となっている主要なフレーズを特定したり、人名や地名、組織名といった固有表現を検出したり、さらにはテキストの言語を自動的に識別したりできます。これらの機能は、顧客からのフィードバック分析、コンテンツのモデレーション、情報検索の高度化、多言語対応アプリケーションの開発など、多岐にわたるユースケースで活用されています。

**毎月の上限：** 5,000 テキスト レコード

🔗 https://azure.microsoft.com/ja-jp/products/ai-foundry/tools/language

### AI Bot Service

Azure AI Bot Serviceは、自然言語理解や機械学習を活用したインテリジェントなボットを、ビジネスニーズに合わせて柔軟に拡張しながら開発できるプラットフォームです。顧客サポートの自動化、社内ヘルプデスク、情報検索など、様々なユースケースで活用され、ユーザーエクスペリエンスの向上や業務効率化に貢献します。API連携や既存システムとの統合も容易で、高度な対話能力を持つボットを迅速に構築・展開できます。

**毎月の上限：** プレミアム チャネル メッセージ 10,000 件と無制限の標準チャネル メッセージ

🔗 https://azure.microsoft.com/ja-jp/products/ai-services/ai-bot-service/

### AI Immersive Reader

AI Immersive Readerは、アプリケーションに高度なテキスト読み取りおよび理解機能を提供するAzure Cognitive Serviceです。このサービスを活用することで、ユーザーは文章の読解を支援する様々な機能を利用でき、教育現場やアクセシビリティ向上に貢献します。例えば、学習者は単語の意味や品詞を調べたり、文章を音声で聞いたり、翻訳したりすることが可能になります。また、文章の視覚的な表現を調整する機能も提供されており、集中力を高めたり、学習スタイルに合わせた読書体験を実現したりできます。これにより、より多くの人々が情報にアクセスしやすくなります。

**毎月の上限：** 300 万文字

🔗 https://azure.microsoft.com/ja-jp/products/ai-services/ai-immersive-reader/

### 音声テキスト変換

音声テキスト変換は、音声データを高精度なテキストに自動で変換するAzureのサービスです。会議の議事録作成、カスタマーサポートの通話分析、動画コンテンツの字幕生成といった様々なユースケースで活用できます。話者の特定や、特定の業界用語への対応も可能で、リアルタイムでの変換やバッチ処理にも対応しており、業務効率化や新たなインサイトの発見に貢献します。

**毎月の上限：** リアルタイム音声テキスト変換を毎月 5 時間分の音声に使用可能

🔗 https://azure.microsoft.com/ja-jp/products/ai-foundry/tools/speech

### テキスト読み上げ

Azure テキスト読み上げは、入力されたテキストを自然で人間らしい音声に変換する Azure Cognitive Services の機能です。このサービスを利用することで、アプリケーションに音声合成機能を簡単に組み込むことができ、アクセシビリティの向上や、ユーザーエクスペリエンスの強化に貢献します。例えば、聴覚障がいのあるユーザー向けのコンテンツ提供、学習支援アプリでの文章の読み上げ、スマートスピーカーやボイスアシスタントのような対話型インターフェースの開発、オーディオブックの自動生成などに活用できます。多様な言語と音声スタイルをサポートしており、ニーズに合わせた最適な音声出力を実現することが可能です。

**毎月の上限：** 標準ニューラル音声を毎月 50 万文字分使用可能

🔗 https://azure.microsoft.com/ja-jp/products/ai-foundry/tools/speech

### 音声翻訳

Azure 音声翻訳は、リアルタイムで話し言葉をテキストや指定した言語の音声に変換するサービスです。会議での多言語コミュニケーションを円滑にしたり、グローバルな顧客サポートの応答を自動化したりするなど、様々な場面で活用できます。例えば、海外のチームとのWeb会議で、発言された内容をリアルタイムで自分の母国語の音声として聞くことができるため、言語の壁を越えたスムーズな意思疎通が可能になります。また、多言語対応のチャットボットに組み込むことで、世界中の顧客からの問い合わせに柔軟に対応できるようになります。

**毎月の上限：** リアルタイム音声翻訳 (標準音声) を毎月 5 時間分の音声に使用可能

🔗 https://azure.microsoft.com/ja-jp/products/ai-foundry/tools/speech

### 翻訳ツール

Azure Translator は、アプリケーション、Web サイト、およびその他さまざまなソリューションに多言語サポートを組み込むための強力なクラウドベースの翻訳サービスです。このサービスを利用することで、リアルタイムでのテキスト翻訳や、ドキュメント全体の翻訳が可能になります。例えば、グローバル展開する Web サイトのコンテンツを多言語化して世界中のユーザーに対応させたり、顧客サポートチャットボットの対話を複数の言語で処理したり、あるいは社内ドキュメントをグローバルチーム間で共有するために翻訳したりといったユースケースが考えられます。機械学習を活用した高精度な翻訳エンジンにより、自然で流暢な翻訳結果を提供し、コミュニケーションの壁を取り払います。

**毎月の上限：** 標準翻訳とカスタム翻訳トレーニングを、任意の組み合わせで 200 万文字に使用可能

🔗 https://azure.microsoft.com/ja-jp/products/ai-foundry/tools/translator

### Face

Azure Face APIは、画像内の顔を高度に認識・分析するサービスです。顔の検出、識別、検証、類似顔検索、属性分析（年齢、性別、感情など）といった機能を提供し、例えば、大規模な写真アーカイブからの特定人物の検索や、顧客の感情分析によるサービス改善、セキュリティシステムにおける顔認証などに活用できます。これにより、顔データを活用したインテリジェントなアプリケーション開発が容易になります。

**毎月の上限：** Free インスタンスの 30,000 トランザクション

🔗 https://azure.microsoft.com/ja-jp/products/cognitive-services/face/

### Open Datasets

**毎月の上限：** ユーザー数無制限

🔗 https://azure.microsoft.com/ja-jp/products/data-catalog/

### Data Factory

Azure Data Factoryは、様々なデータソースからデータを収集、変換、移動するETL/ELTプロセスを、クラウド上で自動化・管理するためのサービスです。これにより、オンプレミスのデータベース、SaaSアプリケーション、ストレージサービスなど、多岐にわたるデータを統合し、分析や機械学習などの用途に活用するためのデータパイプラインを構築できます。例えば、販売データを集計してBIツールで可視化したり、IoTデバイスから収集したデータを分析基盤にロードしたりする際に利用されます。コードを記述することなく、直感的なGUIでパイプラインを設計・監視できるため、データエンジニアリングの効率を大幅に向上させることができます。

**毎月の上限：** 5 つの低頻度アクティビティ

### App Service

App Serviceは、WebアプリケーションやAPIを効率的に開発、デプロイ、実行するためのAzureのフルマネージドプラットフォームです。開発者はインフラストラクチャの管理に煩わされることなく、コードの開発に集中できます。様々なプログラミング言語やフレームワークに対応しており、WindowsおよびLinux環境で動作します。例えば、顧客向けのWebポータルや、バックエンドで動作するAPIサーバーの構築に最適です。負荷に応じて自動的にスケールアップ・ダウンする機能や、セキュリティ機能も充実しており、ビジネスの成長に合わせて柔軟に対応できます。

### Azure Kubernetes Service (AKS)

Azure Kubernetes Service (AKS) は、コンテナ化されたアプリケーションのデプロイ、管理、スケーリングを容易にする、フルマネージドなKubernetesサービスです。開発者は、使い慣れたKubernetesツールを利用して、複雑なインフラストラクチャ管理から解放され、アプリケーション開発に集中できます。例えば、マイクロサービスアーキテクチャを採用したWebアプリケーションのデプロイや、バッチ処理ジョブの実行、機械学習モデルの推論基盤としても活用されています。AKSは、高可用性とセキュリティを確保し、オンプレミス環境や他のクラウド環境とのハイブリッド構成も柔軟に構築できるため、エンタープライズレベルのコンテナ運用を強力にサポートします。

**毎月の上限：** AKS クラスターの管理は無料です。ノードによって消費されるリソースに対して料金が発生する

🔗 https://azure.microsoft.com/ja-jp/products/kubernetes-service/

### Azure VM Image Builder

Azure VM Image Builder は、カスタム仮想マシン (VM) イメージを効率的に作成・管理するためのサービスです。このサービスを利用することで、セキュリティパッチが適用され、必要なアプリケーションがプリインストールされた、すぐに展開可能な VM イメージを自動的に構築できます。これにより、開発環境やアプリケーションのデプロイメントパイプラインの構築・維持にかかる時間と手間を大幅に削減し、迅速かつ一貫性のある環境展開を実現できます。例えば、最新のセキュリティアップデートが適用された Windows Server イメージや、特定の開発ツールがインストールされた Linux イメージなどを、定期的に自動生成するといったユースケースで活用されます。

**毎月の上限：** VM Image Builder は無料のサービスです。構築時にデータ転送や有料の Azure サービスを利用すると、料金が発生する場合があります

🔗 https://azure.microsoft.com/ja-jp/products/image-builder/

### Batch

Azure Batchは、大規模なコンピューティングワークロードをクラウドで効率的に実行するためのマネージドサービスです。開発者は、CPUリソースを大量に必要とするアプリケーションや、並列処理が可能なジョブをAzure Batchに投入することで、インフラストラクチャの管理を気にすることなく、必要なコンピューティングリソースを迅速に調達し、タスクを自動的にスケジューリング・実行できます。例えば、画像レンダリング、科学技術計算、データ分析、機械学習のトレーニングといった、膨大な計算能力を短期間で必要とするシナリオで活用することで、開発者は迅速な結果を得られるようになります。

**毎月の上限：** なし

🔗 https://azure.microsoft.com/ja-jp/products/batch/

### Functions

Azure Functionsは、イベント駆動型のコンピューティングサービスであり、コードを実行するためにサーバーをプロビジョニングしたり管理したりする必要がありません。これにより、開発者はコードの記述に集中できます。例えば、Web APIのバックエンドとして利用したり、データストレージへの変更をトリガーとして処理を実行したり、定期的なタスクを自動化したりするなど、様々なシナリオで活用できます。クラウド上のイベントに応じてコードが実行されるため、スケーラビリティが高く、コスト効率の良いソリューションを実現できます。

**毎月の上限：** 100 万回のリクエスト

🔗 https://azure.microsoft.com/ja-jp/products/functions/

Azure Resource Moverは、Azureリソースを異なるAzureリージョンへ、またはオンプレミス環境からAzureへ、あるいはその逆へ、ダウンタイムを最小限に抑えながら効率的に移行するためのサービスです。これにより、アプリケーションの可用性向上、災害復旧戦略の強化、またはグローバルな展開の必要性に対応できます。例えば、特定の地域でのリソースのパフォーマンス向上のため、または規制要件を満たすために、既存のリソース群を計画的に新しいリージョンへ移設する際に役立ちます。複雑な移行プロセスを簡素化し、手動での作業ミスを減らし、移行の全体的なコストと時間を削減します。

**毎月の上限：** 無料 (イングレスとエグレスの料金が適用される場合があります)

🔗 https://azure.microsoft.com/ja-jp/products/resource-mover/

### Azure Update Manager

Azure Update Manager は、Azure およびオンプレミス環境の Windows および Linux サーバーに対して、パッチ適用と OS の更新を統合的に管理・自動化するサービスです。これにより、セキュリティリスクの低減やコンプライアンス維持を効率化できます。例えば、複数の仮想マシンや物理サーバー群に対して、特定の更新プログラムを計画的に展開したり、更新適用後の状態を定期的に確認したりすることで、システム全体の健全性を維持し、運用負荷を大幅に軽減することが可能です。

**毎月の上限：** Azure リソースは無料 (Arc 対応サーバーは課金対象) です。詳細は価格ページをご覧ください

🔗 https://azure.microsoft.com/ja-jp/products/azure-update-management-center/

### Cloud Shell

Cloud Shellは、WebブラウザからAzureリソースを操作できるクラウドベースのシェル環境です。BashまたはPowerShellを選択でき、Azure CLIやAzure PowerShellといったコマンドラインツール、さらにはPythonやNode.jsなどのプログラミング言語も利用可能です。これにより、ローカル環境にツールをインストールすることなく、どこからでも手軽にAzureのデプロイ、管理、トラブルシューティングが行えます。例えば、仮想マシンの作成やネットワーク設定の変更、スクリプトによる自動化といった作業を、ブラウザを開くだけで即座に実行できます。開発者や運用担当者にとって、Azure管理の俊敏性と効率性を大幅に向上させる強力なツールです。

**毎月の上限：** Azure Files での 12 か月間 5 GB の無料ストレージ

🔗 https://azure.microsoft.com/ja-jp/get-started/azure-portal/cloud-shell/

### Cost Management

Azure Cost Management は、Azure 環境におけるコストを可視化し、効率的な管理を実現するためのサービスです。このサービスを活用することで、リソースごとのコストの内訳を詳細に把握し、予算策定やコスト削減のための戦略立案に役立てることができます。例えば、開発チームは自身の担当するサービスのコストをリアルタイムで確認し、無駄なリソースの発見や最適化を自主的に行うことが可能です。また、IT部門は組織全体のクラウド支出を俯瞰し、コスト配分や将来的な投資計画をより正確に立てることができます。これにより、クラウド利用の透明性を高め、IT投資対効果の最大化を目指します。

**毎月の上限：** なし

🔗 https://azure.microsoft.com/ja-jp/products/cost-management/

### Monitor

Azure Monitorは、クラウドおよびオンプレミスの環境全体を包括的に監視・管理するためのサービスです。アプリケーションのパフォーマンス、インフラストラクチャの状態、ネットワークのトラフィックなどをリアルタイムで収集・分析し、問題の早期発見と迅速な対応を支援します。例えば、Webアプリケーションの応答速度が遅くなった場合に、その原因となっているサーバーのCPU使用率の急増やデータベースのクエリ遅延などを特定し、インシデント対応やリソースの最適化に役立てることができます。また、セキュリティイベントの監視やコンプライアンス要件への対応、コスト管理のためのリソース利用状況の把握など、幅広いユースケースで活用されます。

**毎月の上限：** 機能ごとの無料利用額については、Azure Monitor の料金詳細を参照する

🔗 https://azure.microsoft.com/ja-jp/products/monitor/

### Resource Manager

Azure Resource Manager (ARM) は、Azure 上のリソースを効率的かつ一貫性のある方法でデプロイ、管理、および構成するための管理サービスです。ARM を使用すると、仮想マシン、ストレージ アカウント、仮想ネットワークなどのリソースを、JSON 形式のテンプレートを使用してコードとして定義し、自動化されたデプロイメントを実現できます。これにより、開発チームや運用チームは、インフラストラクチャを迅速にプロビジョニングし、環境の一貫性を保つことができます。例えば、新しいアプリケーション環境を迅速に構築したり、既存の環境を再現したりする際に、ARM テンプレートを活用することで、手作業によるミスを減らし、デプロイメントの速度と信頼性を向上させることが可能です。さらに、リソースへのアクセス制御や、リソースのライフサイクル管理も ARM を通じて統合的に行うことができます。

**毎月の上限：** なし

🔗 https://azure.microsoft.com/ja-jp/get-started/azure-portal/resource-manager/

### Azure Migrate

Azure Migrateは、オンプレミス環境のサーバーやアプリケーションを、迅速かつ安全にAzureクラウドへ移行するための統合サービスです。このサービスは、移行対象となるサーバーの検出、パフォーマンス評価、コスト試算、そして移行計画の策定までを包括的にサポートし、ダウンタイムを最小限に抑えながらスムーズな移行を実現します。例えば、老朽化したオンプレミスサーバーの延命や、クラウドネイティブなアーキテクチャへの移行による俊敏性の向上、運用コストの削減といった目的で活用されています。Azure Migrateを利用することで、ITインフラストラクチャのモダナイゼーションを効果的に推進できます。

**毎月の上限：** なし

🔗 https://azure.microsoft.com/ja-jp/products/azure-migrate/

### Azure Storage Mover

Azure Storage Moverは、オンプレミスや他のクラウド環境からAzure Storageへのデータ移行を効率化するサービスです。ダウンタイムを極力抑えながら、ファイルやフォルダーを安全かつ迅速にAzureへ移動させることができます。例えば、既存のファイルサーバーのデータをAzure Blob StorageやAzure Filesへ移行する際に、このサービスを活用することで、ビジネスの中断を最小限に抑えつつ、最新のクラウドストレージ機能を利用できるようになります。これにより、ストレージの管理コスト削減や、データ活用のためのスケーラビリティ向上などが期待できます。

### Notification Hubs

Notification Hubsは、クラウドベースのプッシュ通知サービスで、モバイルアプリやWebアプリケーションに対して、iOS、Android、Windowsなど、あらゆるプラットフォームのデバイスに効率的にプッシュ通知を配信します。バックエンドアプリケーションから一括で通知を送信できるため、ユーザーエンゲージメントの向上やリアルタイムな情報提供に役立ちます。例えば、ニュース速報、セール情報、イベントのリマインダーなどを、ユーザーが利用しているデバイスの種類を問わずに瞬時に届けることが可能です。これにより、開発者はプラットフォームごとの通知配信ロジックを個別に実装する手間を省き、より迅速かつ大規模な通知展開を実現できます。

**毎月の上限：** 100 万件のプッシュ通知と無料の名前空間

🔗 https://azure.microsoft.com/ja-jp/products/notification-hubs/

### Bandwidth (データ転送)

Azure Bandwidth (データ転送) は、Microsoft のグローバルネットワークインフラストラクチャを利用して、Azure 上のサービス間や Azure とオンプレミス環境間、あるいはインターネットとの間で、安全かつ信頼性の高いデータ転送を実現するサービスです。大量のデータを迅速に移動させたい場合や、グローバルに展開するアプリケーション間でデータを同期させたい場合に最適です。例えば、リモートオフィスから Azure へ大量のデータをアップロードしたり、Azure の仮想マシンからオンプレミスのストレージへデータをバックアップしたりするシナリオで活用できます。このサービスは、高帯域幅と低遅延を提供し、ビジネスの俊敏性と効率性を高めます。

**毎月の上限：** 送信 100 GB

🔗 https://azure.microsoft.com/ja-jp/products/virtual-network/

### Network Watcher

Azure Network Watcherは、Azure仮想ネットワークのパフォーマンスと健全性を監視、診断、トラブルシューティングするための統合サービスです。ネットワークトラフィックの分析、仮想マシンへの接続テスト、IPフロー検証によるネットワークセキュリティグループの確認、トポロジー表示によるネットワーク全体の可視化など、多角的な機能を提供し、ネットワーク上の問題を迅速に特定・解決するのに役立ちます。例えば、アプリケーションの遅延の原因調査や、意図しないネットワーク接続のブロック箇所の特定などに活用できます。

**毎月の上限：** 1,000 件のチェック、10 件のテスト、10 件の接続メトリックを含む 5 GB のストレージ

🔗 https://azure.microsoft.com/ja-jp/products/network-watcher/

### Private Link

Private Linkは、AzureのVNet（仮想ネットワーク）からMicrosoft Azureのバックボーンネットワークを経由して、Azure PaaSサービス（ストレージ、SQL Database、Cosmos DBなど）やAzureホスト型サービス（Azure Private Link Service経由で公開されたお客様のサービス）にプライベートに接続するためのサービスです。これにより、インターネットを経由することなく、セキュアかつ直接的にサービスへアクセスできるようになり、ネットワークセキュリティを大幅に向上させます。例えば、機密性の高いデータを扱うアプリケーションが、パブリックエンドポイントを持たない状態でAzure SQL Databaseに接続する際に利用されます。

**毎月の上限：** なし

🔗 https://azure.microsoft.com/ja-jp/products/private-link/

### Virtual Network

Azure Virtual Network（VNet）は、Azureクラウド内に構築されるプライベートネットワークサービスです。VNetを利用することで、Azure仮想マシンやその他のAzureサービスが互いに通信するための、論理的に分離された安全なネットワーク環境を構築できます。これにより、パブリックインターネットから隔離された、セキュアなアプリケーション環境を実現し、オンプレミスネットワークとのハイブリッド接続も容易に行えます。例えば、開発・テスト環境や、機密情報を扱う基幹システムをAzure上に構築する際に、VNetによってネットワークのセキュリティと管理性を向上させることができます。

**毎月の上限：** 50 仮想ネットワーク

🔗 https://azure.microsoft.com/ja-jp/products/virtual-network/

### Security Center

Azure Security Centerは、Azure環境全体のセキュリティ体制を強化し、潜在的な脅威からリソースを保護するための包括的なソリューションです。これにより、インフラストラクチャ、データ、アプリケーションといったあらゆるレベルでのセキュリティリスクを可視化し、迅速な検知と対応を可能にします。例えば、不正アクセスやマルウェア感染の兆候をリアルタイムで検知し、自動的にアラートを発報することで、セキュリティ担当者は迅速なインシデント対応を実行できます。さらに、推奨されるセキュリティ設定を提示し、コンプライアンス違反の是正を支援するため、継続的なセキュリティ維持に貢献します。

### Azure SignalR Service

Azure SignalR Serviceは、Webアプリケーションやモバイルアプリにリアルタイムな双方向通信機能を容易に実装するためのマネージドサービスです。WebSockets、Server-Sent Events、Long Pollingなどの技術を抽象化し、開発者は複雑なインフラストラクチャ管理なしに、リアルタイムな機能（チャットアプリ、ライブ更新、通知など）を構築できます。これにより、ユーザーエクスペリエンスを大幅に向上させる、インタラクティブなアプリケーション開発が可能になります。例えば、株式取引アプリでのリアルタイムな価格表示や、ゲームアプリでのプレイヤー間の即時同期などに活用できます。

**毎月の上限：** ユニットあたり 20 の同時接続と 20,000 件のメッセージ

🔗 https://azure.microsoft.com/ja-jp/products/signalr-service/

### Web PubSub

Azure Web PubSubは、Webアプリケーションやモバイルアプリケーションで、リアルタイムな双方向通信機能を簡単に実装できるマネージドサービスです。チャットアプリケーションやライブ通知、ゲームなど、ユーザーとの即時的なデータ交換が必要なシナリオで活用できます。このサービスを利用することで、開発者は複雑な WebSocket サーバーの構築や運用から解放され、アプリケーションロジックの開発に集中できます。セキュアでスケーラブルなリアルタイム通信基盤を迅速に構築し、ユーザーエクスペリエンスを向上させることが可能です。

**毎月の上限：** 1 ユニットあたり 1 日 20,000 件のメッセージ、1 ユニットあたり 20 の同時接続 (最大 1 ユニット)

🔗 https://azure.microsoft.com/ja-jp/products/web-pubsub/
