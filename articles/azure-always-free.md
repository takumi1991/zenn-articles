# Azure常時無料サービス一覧

### Azure AI Search

Azure AI Searchは、あらゆるデータソースから情報を迅速に検索、発見、分析するためのクラウドベースの検索サービスです。機械学習機能を活用し、画像、ドキュメント、構造化データなど、多様な形式のデータに対する高度な検索体験を提供します。これにより、顧客サポート、パーソナライズされたレコメンデーション、コンテンツ管理、内部ナレッジベースの強化など、様々なビジネスニーズに対応したインテリジェントなアプリケーションを構築できます。

**毎月の上限：** サービスごとに 10,000 件のホスト ドキュメントと 3 つのインデックスを保存できる 50 MB のストレージ

🔗 https://azure.microsoft.com/ja-jp/products/ai-services/ai-search/

---

### Azure Language

Azure Languageは、自然言語処理（NLP）技術を活用して、テキストデータの理解、分析、生成を支援するクラウドサービスです。文章の感情分析、キーワード抽出、固有表現抽出、言語検出、翻訳、要約などをAIによって自動化し、顧客の声の分析、コンテンツのモデレーション、多言語対応のチャットボット開発など、幅広いビジネスニーズに応えます。

**毎月の上限：** 5,000 テキスト レコード

🔗 https://azure.microsoft.com/ja-jp/products/ai-foundry/tools/language

---

### AI Bot Service

AI Bot Serviceは、自然言語処理（NLP）と機械学習を活用し、高度な対話型AIボットを容易に構築・展開できるクラウドサービスです。Webサイト、モバイルアプリ、Teamsなどのチャネルに統合し、顧客サポート、社内ヘルプデスク、FAQ自動応答、パーソナライズされたレコメンデーションなど、様々なユースケースで利用できます。開発者はコードをほとんど書かずに、直感的かつスケーラブルなチャットボットソリューションを迅速に実現し、ユーザーエクスペリエンスを向上させることができます。

**毎月の上限：** プレミアム チャネル メッセージ 10,000 件と無制限の標準チャネル メッセージ

🔗 https://azure.microsoft.com/ja-jp/products/ai-services/ai-bot-service/

### AI Immersive Reader

AI Immersive Readerは、読解力を向上させるための、学習者、言語学習者、読字障害のある方などを支援するAzure Cognitive Serviceです。テキストを音声で読み上げ、単語やフレーズの意味を視覚的に表示し、品詞や音節をハイライトする機能により、コンテンツへの理解を深めます。例えば、学習者が新しい言語の単語を学ぶ際や、難読漢字の理解を助ける場面で活用でき、より多くの人々が情報にアクセスしやすくなることを目指しています。

**毎月の上限：** 300 万文字

🔗 https://azure.microsoft.com/ja-jp/products/ai-services/ai-immersive-reader/

### Azure コンテナー ストレージ

コンテナー化されたアプリケーションのために、高パフォーマンスでスケーラブルなストレージを提供するサービスです。ファイル共有、ブロックストレージ、オブジェクトストレージなど、多様なニーズに対応し、コンテナーのライフサイクル全体をサポートします。例えば、Webアプリケーションの永続データ保存や、ビッグデータ分析基盤のデータレイク、IoTデバイスからのデータ収集などに活用できます。

**毎月の上限：** このサービスでは、ストレージ プール容量 5 TiB 未満のデプロイ向けに Free レベルが提供されます

🔗 https://azure.microsoft.com/ja-jp/products/container-storage/

### Face

Azure Face API は、画像中の顔を検出、認識、分析するためのクラウドベースのサービスです。顔の属性（年齢、性別、感情など）の特定や、顔の類似性比較、さらに特定の人物を識別することも可能です。このサービスは、顧客体験の向上、セキュリティ強化、アクセシビリティの改善など、幅広いユースケースで活用されています。例えば、小売店での顧客分析、イベント会場での顔認証による入場管理、写真共有アプリでの人物タグ付けなどに利用できます。

**毎月の上限：** Free インスタンスの 30,000 トランザクション

🔗 https://azure.microsoft.com/ja-jp/products/cognitive-services/face/

### Machine Learning

Microsoft Azure Machine Learning は、機械学習モデルの構築、トレーニング、デプロイを容易にするクラウドベースのプラットフォームです。ドラッグ＆ドロップでモデルを開発できるビジュアルツールと、コーディングによる高度なカスタマイズの両方に対応しており、データサイエンティストや開発者は、予測分析、画像認識、自然言語処理などの高度なAIソリューションを迅速に作成できます。例えば、顧客の購買行動を予測してパーソナライズされたレコメンデーションを提供したり、異常検知システムを構築して不正行為をリアルタイムで検出するといった活用が可能です。

**毎月の上限：** 無料

🔗 https://azure.microsoft.com/ja-jp/products/machine-learning/

### Open Datasets

Azure Open Datasetsは、Microsoftが提供する、世界中の公開データセットにアクセスできる無料のサービスです。気象データ、人口統計データ、地図情報など、多様なデータソースを利用して、機械学習モデルのトレーニングやデータ分析に役立てることができます。例えば、気象データを活用して将来の天候を予測したり、人口統計データを分析してターゲットマーケティングの精度を高めたりするユースケースが考えられます。このサービスを利用することで、データ収集の手間を省き、より迅速かつ効果的にインサイトを発見することが可能になります。

**毎月の上限：** 無料 (エグレスの料金が適用される場合あり)

🔗 https://azure.microsoft.com/ja-jp/products/open-datasets/

### Content Safety

Content Safetyは、AzureのAIを活用したサービスで、テキストや画像に含まれる不適切または有害なコンテンツを検出し、分類します。このサービスは、ヘイトスピーチ、性的なコンテンツ、暴力的な表現などを自動的に識別し、ビジネスのブランドイメージ保護やユーザーの安全確保に貢献します。例えば、オンラインコミュニティでの不適切投稿のモデレーション、広告コンテンツの審査、ユーザー生成コンテンツのフィルタリングなどに利用され、安全で健全なデジタル環境の維持を強力にサポートします。

**毎月の上限：** AKS クラスターの管理は無料です。ノードによって消費されるリソースに対して料金が発生します

🔗 https://azure.microsoft.com/ja-jp/products/ai-services/ai-content-safety/

### Data Catalog

Data Catalogは、組織内のデータ資産を効率的に発見、整理、管理できるクラウドベースのデータカタログサービスです。これにより、データサイエンティスト、アナリスト、ビジネスユーザーは、必要なデータソースを迅速に見つけ出し、その内容や出所を理解し、信頼性の高いデータに基づいて意思決定を行うことができます。例えば、マーケティングキャンペーンの効果測定のために過去の販売データと顧客アンケートの回答を組み合わせたい場合、Data Catalogを使えば関連するデータセットを容易に検索し、そのメタデータを確認して利用準備を整えることが可能です。データガバナンスの強化や、データサイロの解消にも貢献します。

**毎月の上限：** ユーザー数無制限

🔗 https://azure.microsoft.com/ja-jp/products/data-catalog/

### Data Factory

Data Factoryは、Azure上でデータ統合とETL（Extract, Transform, Load）/ELT（Extract, Load, Transform）ワークフローを構築・管理・自動化するためのクラウドベースのサービスです。様々なデータソースからのデータの抽出、変換、ロードをパイプラインとして定義し、スケジュール実行やトリガー実行が可能です。大量のデータを効率的に処理し、データウェアハウスやデータレイクへのロード、機械学習モデルのトレーニング用データ準備、ビジネスインテリジェンスレポート作成などに活用できます。オンプレミスとクラウドの両方のデータソースに対応し、複雑なデータ変換ロジックをコードなしで実現できるのが特長です。

**毎月の上限：** 5 つの低頻度アクティビティ

🔗 https://azure.microsoft.com/ja-jp/products/data-factory/

### App Service

App Serviceは、Webアプリ、モバイルバックエンド、RESTful APIなどを、WindowsまたはLinux環境で簡単に開発、デプロイ、スケーリングできるマネージドサービスです。コードを直接デプロイするだけで、インフラストラクチャの管理はAzureに任せることができます。例えば、ASP.NET、Java、Node.js、Python、PHPなどの各種言語で開発されたWebサイトや、IoTデバイスからデータを収集するバックエンドシステム、さらに、ゲームのスコアリングAPIなども構築・運用できます。自動スケーリング機能により、トラフィックの増減に合わせてリソースを調整し、可用性とパフォーマンスを維持することが可能です。

**毎月の上限：** 最大 10 個の Web アプリまたは API アプリ、1 GB のストレージ、1 日あたり 1 時間

🔗 https://azure.microsoft.com/ja-jp/products/app-service/

### Azure Kubernetes Service (AKS)

Azure Kubernetes Service (AKS) は、Kubernetes クラスターのデプロイ、管理、運用を簡素化する、フルマネージドのコンテナオーケストレーションサービスです。開発者は、インフラストラクチャの複雑さに煩わされることなく、コンテナ化されたアプリケーションの迅速なデプロイ、スケーリング、管理に集中できます。AKS は、マイクロサービスアーキテクチャの構築、CI/CD パイプラインの自動化、コンプライアンス要件を満たすためのワークロードの実行などに最適です。これにより、組織は俊敏性を高め、IT 運用コストを削減し、イノベーションを加速できます。

**毎月の上限：** AKS クラスターの管理は無料です。ノードによって消費されるリソースに対して料金が発生する

🔗 https://azure.microsoft.com/ja-jp/products/kubernetes-service/

### Azure VM Image Builder

Azure VM Image Builderは、カスタム仮想マシン（VM）イメージを効率的かつ自動的に作成するためのサービスです。WindowsやLinuxといったOSに加え、アプリケーション、設定、パッチなどを組み込んだ、すぐに利用できる状態のイメージを構築できます。これにより、開発環境やテスト環境、運用環境などに必要なVMを迅速にデプロイし、一貫性を保つことが可能になります。セキュリティ要件を満たしたイメージを定期的に更新・配布することで、インフラストラクチャの標準化と運用効率の向上に貢献します。

**毎月の上限：** VM Image Builder は無料のサービスです。構築時にデータ転送や有料の Azure サービスを利用すると、料金が発生する場合があります

🔗 https://azure.microsoft.com/ja-jp/products/image-builder/

### Batch

Azure Batchは、クラウド上の大規模な計算ワークロードを効率的に実行するためのマネージドサービスです。開発者は、カスタムアプリケーションをAzureのVM（仮想マシン）のプールにデプロイし、ジョブとタスクをスケジューリングして、並列処理やバッチ処理を容易に実現できます。これにより、レンダリング、科学技術計算、データ分析、エンコードなどの高密度コンピューティングタスクを、インフラストラクチャ管理の負担なく、オンデマンドでスケーラブルに実行することが可能になります。

**毎月の上限：** 無料

🔗 https://azure.microsoft.com/ja-jp/products/batch/

### Functions

Azure Functionsは、サーバーレスでイベント駆動型のコンピューティングサービスであり、インフラストラクチャの管理なしにコードを実行できます。HTTPリクエスト、タイマー、キューメッセージ、データベースの変更など、さまざまなイベントに応答してコードをトリガーできます。これにより、APIのバックエンド、リアルタイムのデータ処理、IoTデバイスからのデータ集約、バッチ処理など、多様なアプリケーションを迅速かつ効率的に開発できます。必要に応じて自動的にスケールするため、コスト効率も優れています。

**毎月の上限：** 100 万回のリクエスト

🔗 https://azure.microsoft.com/ja-jp/products/functions/

### Static Web Apps

Azure Static Web Appsは、静的コンテンツとAPIを効率的にデプロイ・ホストできるフルマネージドサービスです。HTML、CSS、JavaScriptといった静的ファイルに加え、Azure Functionsを利用したAPIエンドポイントを統合管理でき、GitHubやAzure DevOpsと連携したCI/CDパイプラインを自動構築することで、開発からデプロイまでのワークフローを劇的に簡素化します。これにより、Webアプリケーション、静的サイトジェネレーターで構築されたウェブサイト、PWA（Progressive Web App）などの高速でスケーラブルなホスティングが実現し、開発者はインフラ管理の手間を省き、アプリケーション開発に集中できます。

**毎月の上限：** サブスクリプションあたり 100 GBの帯域幅、2 つのカスタム ドメイン、アプリあたり 0.5 GB のストレージ

🔗 https://azure.microsoft.com/ja-jp/products/app-service/static/

### Container Apps

Azure Container Appsは、コンテナ化されたアプリケーションを簡単にデプロイ、実行、管理できるフルマネージドサービスです。サーバーレスでスケーリングやインフラ管理の複雑さから解放され、開発者はビジネスロジックに集中できます。マイクロサービス、Webアプリケーション、APIバックエンド、バッチ処理など、様々なユースケースに対応し、イベントドリブンな処理やHTTPリクエストに応じた自動スケーリングも可能です。Kubernetesの専門知識がなくても、コンテナの恩恵を迅速に享受できます。

**毎月の上限：** 180,000 vCPU 秒、360,000 GiB 秒、200 万リクエスト

🔗 https://azure.microsoft.com/ja-jp/products/container-apps/

### Service Fabric

Service Fabricは、マイクロサービスアーキテクチャを構築・実行するための分散システムプラットフォームです。ステートフルおよびステートレスなサービスを、信頼性が高くスケーラブルな方法でデプロイ・管理できます。高可用性、スケーラビリティ、そして開発の容易さを実現し、IoT、ビッグデータ処理、カスタムビジネスアプリケーションなどのユースケースで活用されています。コンテナ化されたワークロードやVMワークロードもサポートし、Azure内外のどこでも実行可能です。

**毎月の上限：** 無料

🔗 https://azure.microsoft.com/ja-jp/products/service-fabric/

### Azure Cosmos DB

Azure Cosmos DBは、グローバルに分散されたマルチモデルデータベースサービスです。あらゆる規模のアプリケーションに対して、低レイテンシ、高可用性、およびスケーラブルなパフォーマンスを提供し、NoSQLデータモデル（ドキュメント、キーバリュー、グラフ、列ファミリー）をサポートしています。これにより、IoT、ゲーム、Webアプリケーション、モバイルアプリケーションなど、多様なユースケースでリアルタイムなデータアクセスとグローバルなデータ同期を実現できます。

**毎月の上限：** 1,000 要求ユニット/秒のプロビジョニング済みスループット、25 GB のストレージ

🔗 https://azure.microsoft.com/ja-jp/products/cosmos-db/

### Azure Cosmos DB for MongoDB

Azure Cosmos DB for MongoDB は、MongoDB API を使用して、グローバル分散、マルチモデル、スケーラブルな NoSQL データベースを Azure 上で利用できるサービスです。既存の MongoDB アプリケーションを容易に移行でき、高い可用性と低レイテンシーを実現します。IoT データ分析、リアルタイム分析、ゲーム、モバイルアプリケーションなど、様々なユースケースで強力なパフォーマンスを発揮します。

**毎月の上限：** 32 GB のストレージを備えた専用の MongoDB クラスター

🔗 https://azure.microsoft.com/ja-jp/products/cosmos-db/

### Database Migration Service

Database Migration Serviceは、オンプレミスや他のクラウド環境のデータベースを、Azureの各種データベースサービス（Azure SQL Database, Azure Database for MySQL, Azure Database for PostgreSQL, Azure Cosmos DBなど）へ、ダウンタイムを最小限に抑えながら移行できるフルマネージドサービスです。複雑な移行プロセスを簡素化し、コストとリスクを削減します。例えば、レガシーなSQL ServerデータベースをAzure SQL Databaseへ移行し、アプリケーションのパフォーマンス向上やスケーラビリティの確保を目指す場合に活用できます。また、多様なデータベースエンジンに対応しているため、柔軟な移行戦略を立てることが可能です。

**毎月の上限：** 無料の Standard コンピューティング

🔗 https://azure.microsoft.com/ja-jp/products/database-migration/

### SQL Database

SQL Databaseは、Azureが提供するフルマネージドなリレーショナルデータベースサービスです。自動バックアップ、高可用性、パッチ適用などの運用管理をMicrosoftが行うため、開発者はアプリケーション開発に集中できます。Webアプリケーションのバックエンド、エンタープライズシステム、データ分析基盤など、幅広い用途で利用されており、グローバルなスケーラビリティとセキュリティ機能も備えています。

**毎月の上限：** 最大 10 個のデータベースを、それぞれ 100,000 vCore 秒のサーバーレス レベルと 32 GB のストレージを利用可能

🔗 https://azure.microsoft.com/ja-jp/products/azure-sql/database/

### App Configuration

App Configurationは、アプリケーションの設定や機能フラグを一元管理するクラウドサービスです。これにより、コードを変更せずにアプリケーションの動作を動的に変更でき、デプロイメントを簡素化します。例えば、新機能の段階的リリースや、特定のユーザーグループにのみ機能を有効化するといったシナリオで活用できます。また、異なる環境（開発、ステージング、本番）ごとに個別の設定を適用することも容易になり、管理効率と信頼性が向上します。

**毎月の上限：** 10 MB のストレージで 1 日あたり 1,000 件のリクエスト

🔗 https://azure.microsoft.com/ja-jp/products/app-configuration/

### Azure Deployment Environments

Azure Deployment Environmentsは、開発チームが迅速かつ一貫性のある開発・テスト環境をプロビジョニングできるマネージドサービスです。これにより、インフラストラクチャのセットアップと管理にかかる時間を短縮し、開発者がコード作成に集中できるようになります。例えば、最新の機能開発やデバッグのために、開発者ごとに独立した最新の環境を迅速に構築したり、本番環境とほぼ同等のステージング環境を容易に用意したりする際に活用できます。テンプレートベースのデプロイメントにより、環境の標準化とセキュリティポリシーの適用も容易になります。

**毎月の上限：** Azure Deployment Environments は、現在、無料のサービスです。ただし、サービスを通じてデプロイされた環境に作成されるコンピューティング、ストレージ、ネットワークなどの他の Azure リソースに対しては料金が発生します

🔗 https://azure.microsoft.com/ja-jp/products/deployment-environments/

### Azure DevOps

Azure DevOpsは、開発チームがアプリケーションを計画、開発、テスト、デリバリーするプロセス全体を合理化できる包括的なクラウドサービスです。コードのバージョン管理（Azure Repos）、アジャイル計画ツール（Azure Boards）、CI/CDパイプライン（Azure Pipelines）、テスト管理（Azure Test Plans）、パッケージ管理（Azure Artifacts）といった機能を提供し、開発ライフサイクル全体を単一のプラットフォームで管理します。これにより、開発者はより迅速かつ効率的に高品質なソフトウェアをリリースすることが可能になります。例えば、スタートアップ企業が新製品を市場に投入する際に、開発からデプロイまでを迅速に進めたり、エンタープライズ企業が既存システムの保守と並行して新機能開発を行う際にも、その自動化されたワークフローが開発効率を飛躍的に向上させます。

**毎月の上限：** 5 人のユーザーと無制限のプライベート Git Repos

🔗 https://azure.microsoft.com/ja-jp/products/devops/

Notification Hubsは、モバイルアプリやWebアプリにプッシュ通知を大規模かつ効率的に送信するためのフルマネージドサービスです。iOS、Android、Windowsなど、さまざまなプラットフォームに対応しており、ユーザーセグメントごとのターゲティングやパーソナライズされたメッセージングが可能です。例えば、アプリのアップデート情報、セール情報、緊急アラートなどを、数百万人のユーザーに同時に、あるいは特定のグループに絞って配信することができます。これにより、ユーザーエンゲージメントの向上や、重要な情報の迅速な伝達を実現します。

**毎月の上限：** 100 万件のプッシュ通知と無料の名前空間

🔗 https://azure.microsoft.com/ja-jp/products/notification-hubs/

### Bandwidth (データ転送)

Azure Bandwidthは、Azure内外へのデータ転送を最適化し、コスト効率を高めるサービスです。グローバルなネットワークインフラストラクチャを活用し、高速で信頼性の高いデータ転送を実現します。例えば、オンプレミス環境からAzureへ大量のデータを移行する際や、Azure上のアプリケーションからユーザーへコンテンツを配信する際の帯域幅を確保するのに役立ちます。これにより、アプリケーションのパフォーマンス向上や、グローバル展開における運用コストの削減に貢献します。

**毎月の上限：** 送信 100 GB

🔗 https://azure.microsoft.com/ja-jp/products/virtual-network/

### Network Watcher

Network Watcherは、Azure仮想ネットワークの監視、診断、およびパフォーマンス分析を可能にするサービスです。トラフィックフローログ、接続トラブルシューティング、IPフロー検証、ネクストホップなどの機能により、ネットワークの異常や遅延の原因を特定し、迅速な問題解決を支援します。これにより、インフラストラクチャの健全性を維持し、アプリケーションの可用性とパフォーマンスを最適化できます。

**毎月の上限：** 1,000 件のチェック、10 件のテスト、10 件の接続メトリックを含む 5 GB のストレージ

🔗 https://azure.microsoft.com/ja-jp/products/network-watcher/

### Private Link

Azure Private Linkは、Azure Virtual NetworkからAzure PaaSサービスやオンプレミスのサービスへ、インターネットを経由せずにプライベートな接続を確立するサービスです。これにより、ネットワークセキュリティを大幅に向上させ、データ漏洩のリスクを低減できます。例えば、WebアプリケーションからAzure SQL Databaseへ安全にアクセスしたり、オンプレミスのデータベースをAzureのサービスからプライベートに参照したりする際に利用されます。コスト効率も良く、管理も容易なため、セキュアなネットワーク設計において重要な役割を果たします。

**毎月の上限：** 無料

🔗 https://azure.microsoft.com/ja-jp/products/private-link/

### Virtual Network

Azure Virtual Network (VNet) は、Azureクラウド上で構築されるプライベートネットワークであり、仮想マシンやその他のAzureサービスが安全に通信できるようにします。これにより、オンプレミス環境とのハイブリッド接続や、Azure内のリソース間でのセキュアな通信を実現できます。例えば、企業が自社のデータセンターとAzure上のアプリケーションを接続し、あたかも一つのネットワークであるかのように利用したり、複数のAzureリージョンにまたがるシステムを構築したりする際に活用されます。VNetは、IPアドレス空間の定義、サブネット化、ルーティング、セキュリティグループ、VPNゲートウェイなどの機能を提供し、ネットワークの設計と管理を柔軟かつ強力に行うことを可能にします。

**毎月の上限：** 50 仮想ネットワーク

🔗 https://azure.microsoft.com/ja-jp/products/virtual-network/

### Azure Attestation

Azure Attestation は、ハードウェアベースのトラステッド実行環境（TEE）で実行されるコードの整合性と信頼性を、リモートの第三者に対して証明するためのマネージドサービスです。これにより、機密性の高いワークロードをクラウドで安全に実行し、データプライバシーとセキュリティを確保できます。例えば、機密データ分析やブロックチェーンアプリケーション、IoTデバイスの認証など、信頼性が不可欠なシナリオで活用できます。TEE内でのコード実行が正当であることを保証し、不正な改ざんや情報漏洩のリスクを低減します。

**毎月の上限：** 無料

🔗 https://azure.microsoft.com/ja-jp/products/azure-attestation/

### Security Center

Azure Security Centerは、オンプレミスやクラウド全体にわたるセキュリティ体制を可視化・強化し、脅威を検出・防御するための統合的なクラウドセキュリティ管理サービスです。これにより、リソースのセキュリティスコアを把握し、推奨事項に基づいて脆弱性や設定ミスを修正できます。また、高度な脅威分析機能により、ランサムウェアやマルウェアなどの攻撃を検知し、インシデント発生時には迅速な対応を支援します。例えば、仮想マシン、ストレージ、データベースなどのリソースに適用され、セキュリティポリシーの適用やコンプライアンスの遵守を容易にします。

**毎月の上限：** 無料のポリシー評価と推奨事項

🔗 https://azure.microsoft.com/ja-jp/products/defender-for-cloud/

### Azure SignalR Service

Azure SignalR Serviceは、リアルタイムWebアプリケーションの構築を容易にするマネージドサービスです。Webサイトやモバイルアプリで、チャット、通知、ゲームのスコア更新など、サーバーからクライアントへの即時プッシュ通信を実装できます。開発者は、WebSocketやServer-Sent Eventsなどの複雑なリアルタイム通信プロトコルの管理から解放され、ビジネスロジックに集中できます。これにより、ユーザーエクスペリエンスを大幅に向上させるインタラクティブなアプリケーションを迅速に開発・展開することが可能になります。

**毎月の上限：** ユニットあたり 20 の同時接続と 20,000 件のメッセージ

🔗 https://azure.microsoft.com/ja-jp/products/signalr-service/

### Web PubSub

Web PubSubは、リアルタイムのWebアプリケーションを容易に構築するためのマネージドサービスです。WebSocketやその他のリアルタイム通信プロトコルを抽象化し、開発者はバックエンドロジックに集中できます。リアルタイムのチャットアプリケーション、ライブダッシュボード、ゲーム、通知システムなどに最適で、スケーラブルかつ高可用性なリアルタイム機能を提供します。Web PubSubは、複雑なネットワーク管理やサーバー管理を不要にし、開発効率を大幅に向上させます。

**毎月の上限：** 1 ユニットあたり 1 日 20,000 件のメッセージ、1 ユニットあたり 20 の同時接続 (最大 1 ユニット)

🔗 https://azure.microsoft.com/ja-jp/products/web-pubsub/
