# Azure常時無料サービス一覧

最終更新日: 2026/4/18 15:36:11

AzureにもAWSやGoogle Cloud同様に「常時無料枠（Always Free Services）」が65件ほど用意されています。


## 🧠 AI + 機械学習

### AI Bot Service

AI Bot Service を利用すれば、オンデマンドで柔軟にスケールアップ・ダウンできる、インテリジェントなエンタープライズレベルのボットを開発できます。このサービスは、自然言語理解（NLU）や会話管理などの高度なAI機能を活用し、顧客サポートの自動化、社内ヘルプデスクの効率化、Webサイトでのインタラクティブな情報提供など、多岐にわたるユースケースに対応します。例えば、よくある質問への自動応答や、複雑な問い合わせへの一次対応をボットに任せることで、人的リソースをより戦略的な業務に集中させることが可能です。また、API連携により既存システムとの統合も容易で、パーソナライズされたユーザー体験の提供や、データ収集・分析基盤の強化にも貢献します。開発者は、Azureの豊富なAIサービス群と連携させることで、高度な対話能力を持つビジネスソリューションを迅速に構築・展開できます。

**毎月の上限：** プレミアム チャネル メッセージ 10,000 件と無制限の標準チャネル メッセージ

🔗 https://azure.microsoft.com/ja-jp/products/ai-services/ai-bot-service/

### Azure AI Search

Azure AI Searchは、Webおよびモバイルアプリケーションに高度なクラウド検索機能を容易に組み込むことができるサービスです。これにより、ユーザーは膨大なデータの中から目的の情報を素早く、かつ正確に見つけ出すことが可能になります。例えば、eコマースサイトで特定の商品を検索したり、社内ポータルで必要なドキュメントを効率的に探したり、あるいはカスタムアプリケーションで専門的な知識ベースを検索するといった、多岐にわたるシナリオで活用できます。Azure AI Searchは、全文検索、ファセット検索、地理空間検索、そしてAIを活用したスキルセットによるインテリジェントな検索など、幅広い検索機能を提供し、ユーザーエクスペリエンスを劇的に向上させます。開発者は、複雑な検索エンジンの構築や管理に煩わされることなく、アプリケーションのコア機能開発に集中できます。

**毎月の上限：** サービスごとに 10,000 件のホスト ドキュメントと 3 つのインデックスを保存できる 50 MB のストレージ

🔗 https://azure.microsoft.com/ja-jp/products/ai-services/ai-search/

### Machine Learning

Azure Machine Learning は、強力な R および Python モデルを開発・実行するための包括的なクラウドサービスです。このサービスを利用することで、データサイエンティストや開発者は、複雑な機械学習ワークフローを効率的に構築し、デプロイすることが可能になります。例えば、画像認識、自然言語処理、異常検知といった高度なAIアプリケーションの開発において、その真価を発揮します。

モデルのトレーニングからデプロイ、管理まで、ライフサイクル全体をサポートするツールが統合されており、GPU を活用した高速な学習や、AutoML による自動的なモデル探索も行えます。これにより、ビジネス上の課題解決に直結するインテリジェントなソリューションを迅速に実現し、競争優位性を確立するための強力な基盤を提供します。

**毎月の上限：** なし

🔗 https://azure.microsoft.com/ja-jp/products/machine-learning/

### Open Datasets

Azure Open Datasets を活用することで、高品質でキュレーションされた豊富なデータセットに容易にアクセスでき、機械学習モデルの開発とデプロイを大幅に加速させることが可能です。このサービスは、社会貢献や研究開発に役立つ、信頼性の高い公開データを提供しており、地理空間データ、気象データ、統計データなど、多岐にわたる分野のデータが含まれています。例えば、気候変動の分析、都市計画の最適化、新薬開発の初期段階におけるパターン発見など、複雑な課題解決にこれらのデータセットを直接利用できます。これにより、データ収集や前処理にかかる時間とコストを削減し、データサイエンティストや開発者は、より創造的で付加価値の高い作業に集中できるようになります。Azure Machine Learning とのシームレスな連携により、データセットの探索からモデルのトレーニング、運用までを統合的に行うことができ、イノベーションのスピードを加速します。

**毎月の上限：** 無料 (エグレスの料金が適用される場合あり)

🔗 https://azure.microsoft.com/ja-jp/products/open-datasets/

### Azure Language

**Azure Language** は、高度な自然言語処理 (NLP) 機能を活用し、膨大なテキストデータから有益な情報を効率的に抽出するための強力なサービスです。

このサービスを利用することで、顧客からのレビューやソーシャルメディアの投稿といった非構造化テキストから、**センチメント分析**による肯定・否定・中立といった感情の度合い、**キー フレーズ抽出**による主要なトピックやキーワード、**名前付きエンティティ認識**による人名、地名、組織名などの固有表現、そして**言語検出**によるテキストの言語を正確に特定することが可能になります。

これらの機能は、顧客満足度の向上、市場トレンドの把握、コンテンツの分類・整理、さらには不正検出など、多岐にわたるビジネスユースケースで活用できます。例えば、製品レビューを分析して改善点を見つけたり、ニュース記事から重要な情報を素早く収集したり、顧客からの問い合わせ内容を自動で分類して担当者に振り分けたりすることが容易になります。Azure Language を活用することで、テキストデータに隠されたインサイトを発見し、よりデータに基づいた意思決定を支援します。

**毎月の上限：** 5,000 テキスト レコード

🔗 https://azure.microsoft.com/ja-jp/products/ai-foundry/tools/language

### Advisor

Azure Advisor は、Azure 環境を最大限に活用し、パフォーマンスの向上、コストの削減、セキュリティの強化、信頼性の向上、運用効率の改善を図るための、パーソナライズされた推奨事項を提供するインテリジェントなサービスです。このサービスは、お客様の Azure リソースの使用状況と構成を継続的に分析し、ベストプラクティスに基づいた具体的なアクションを提示します。例えば、リソースの最適化によるコスト削減の機会、パフォーマンスボトルネックの解消、セキュリティ設定の強化、障害発生時の復旧能力向上など、多岐にわたるシナリオにおいて、実用的で実行可能なガイダンスを提供します。これにより、お客様は複雑な Azure 環境においても、専門知識の有無にかかわらず、効率的かつ安全にリソースを管理できるようになります。

**毎月の上限：** 無制限

🔗 https://azure.microsoft.com/ja-jp/products/advisor/

### Content Safety

Azure Content Safety は、テキストと画像を分析し、有害なコンテンツを検出し、自動的にフラグを立てることで、より安全でポジティブなユーザー エクスペリエンスを提供することを可能にします。このサービスは、ヘイトスピーチ、性的コンテンツ、暴力表現といった不適切なコンテンツをリアルタイムで識別し、企業が安心してサービスを運用するための強力な支援となります。例えば、オンラインコミュニティ、ゲームプラットフォーム、チャットアプリケーション、メディア共有サイトなど、ユーザー生成コンテンツを扱うあらゆる場面で、コンテンツモデレーションの負担を軽減し、安全な環境を維持するために活用できます。これにより、ブランドイメージの保護や、ユーザーの信頼獲得に貢献します。

**毎月の上限：** AKS クラスターの管理は無料です。ノードによって消費されるリソースに対して料金が発生します

## 拡張された説明文

Azureの音声テキスト変換サービスは、録音された音声ファイルやリアルタイムの音声ストリームを、高精度なテキストデータへと変換できる強力なソリューションです。このサービスを活用することで、会議の議事録作成、カスタマーサポートの通話内容分析、動画コンテンツの字幕生成、音声コマンドの認識など、多岐にわたるユースケースで業務効率を大幅に向上させることができます。最新のAI技術に基づいた自然言語処理能力により、話者の声質や背景ノイズに左右されにくい堅牢な認識を実現し、さらに話者分離機能も備えているため、複数の発言者がいる場面でもそれぞれの発言を正確に特定します。これにより、音声情報のデジタル化と活用が容易になり、新たなインサイトの発見やサービス改善に繋がるデータ分析が可能となります。

### テキスト読み上げ

## テキスト読み上げ

Microsoft Azure のテキスト読み上げ機能を利用すれば、まるで人間が話しているかのような自然で感情豊かな音声を、あらゆるテキストから手軽に生成できるアプリケーションを構築できます。このサービスは、単に文字を音声に変換するだけでなく、様々な言語、音声スタイル、話速、ピッチを細かく調整することで、ユーザーのニーズに合わせた最適な音声体験を提供します。

例えば、スマートフォンの音声アシスタントや、視覚障がいのある方々向けのスクリーンリーダー、インタラクティブな顧客サポートシステム、語学学習アプリ、オーディオブックの自動生成など、幅広いユースケースで活用できます。開発者は、REST API や SDK を通じて、この高度な音声合成技術を自社のサービスや製品に容易に組み込むことが可能です。これにより、アクセシビリティの向上、エンゲージメントの強化、そして新しいユーザー体験の創造を実現できます。

**毎月の上限：** 標準ニューラル音声を毎月 50 万文字分使用可能

🔗 https://azure.microsoft.com/ja-jp/products/ai-foundry/tools/speech

### Data Factory

## Data Factory

Data Factory は、Azure 上でデータ統合とデータ変換のためのクラウドベースの ETL (Extract, Transform, Load) および ELT (Extract, Load, Transform) サービスです。このサービスを活用することで、様々なデータソースからデータを抽出し、必要な形式に変換、そして目的のデータストアにロードする一連のデータパイプラインを、コードを書かずに直感的なインターフェースで効率的に設計・管理できます。

例えば、オンプレミスのデータベースやSaaSアプリケーションからデータを収集し、Azure Data Lake Storage に格納した後に、Azure Databricks や Azure Synapse Analytics で高度な分析を行うといったシナリオで、データ移動と変換のプロセスを自動化し、ビジネスインテリジェンスや機械学習のためのデータ準備を迅速に進めることが可能です。これにより、データサイエンティストや開発者は、データ処理の複雑な部分に時間を費やすことなく、より価値の高い分析や洞察の発見に集中できるようになります。

**毎月の上限：** 5 つの低頻度アクティビティ

🔗 https://azure.microsoft.com/ja-jp/products/data-factory/



## 📦 コンテナー

### Azure Kubernetes Service (AKS)

Azure Kubernetes Service (AKS) は、使い慣れたツールを活用してコンテナー化されたアプリケーションのデプロイと管理を容易にする、フルマネージドのKubernetesサービスです。このサービスを利用することで、複雑なインフラストラクチャの管理に煩わされることなく、開発者はアプリケーションの構築とイノベーションに集中できます。AKSは、マイクロサービスアーキテクチャの採用、CI/CDパイプラインの自動化、ハイブリッドクラウド環境の構築など、多岐にわたるユースケースに対応します。スケーラビリティ、可用性、セキュリティを強化し、コンテナーワークロードの運用を大幅に簡素化することで、ビジネスの俊敏性を高めることを可能にします。

**毎月の上限：** AKS クラスターの管理は無料です。ノードによって消費されるリソースに対して料金が発生する

🔗 https://azure.microsoft.com/ja-jp/products/kubernetes-service/

### Container Apps

Azure Container Apps を利用すれば、サーバーレスで最新のアプリケーションやマイクロサービスを効率的にビルド、デプロイ、実行できます。このサービスは、コンテナー化されたアプリケーションの管理を簡素化し、インフラストラクチャの管理から開発者を解放します。

例えば、Web API、バックエンドサービス、バッチ処理ジョブ、あるいはイベント駆動型アーキテクチャなど、さまざまな種類のワークロードに対応可能です。スケーリングは自動で行われるため、トラフィックの増減に合わせてリソースを最適化し、コスト効率を高めることができます。また、Dapr や KEDA といったオープンソースのプラットフォームとの統合により、高度なマイクロサービス機能やイベント駆動型の自動スケーリングを容易に実現できます。これにより、開発者はビジネスロジックの実装に集中でき、迅速なイノベーションを推進できます。

**毎月の上限：** 180,000 vCPU 秒、360,000 GiB 秒、200 万リクエスト

🔗 https://azure.microsoft.com/ja-jp/products/container-apps/

### Azure コンテナー ストレージ

Azure コンテナー ストレージは、ステートフルなコンテナーアプリケーションが必要とする永続的なストレージボリュームの管理を簡素化します。これにより、データベースやセッション管理など、データの永続化が不可欠なアプリケーションをコンテナー上で安心して実行できます。

例えば、Kubernetesなどのコンテナーオーケストレーションプラットフォーム上で、コンテナが再起動したり、別のノードに移動したりしても、データが失われる心配がありません。Azure Disk StorageやAzure FilesといったAzureの堅牢なストレージサービスをバックエンドとして利用し、コンテナのライフサイクルに合わせたストレージのプロビジョニング、アタッチ、デタッチ、そして削除までを統合的に管理します。この機能により、開発者はインフラストラクチャの複雑さを気にすることなく、アプリケーションのロジック開発に集中できるようになります。

**毎月の上限：** このサービスでは、ストレージ プール容量 5 TiB 未満のデプロイ向けに Free レベルが提供されます

🔗 https://azure.microsoft.com/ja-jp/products/container-storage/

### Functions

Azure Functions は、サーバーの管理なしに、コードを実行してイベントを処理できる、イベント駆動型のサーバーレスコンピューティングサービスです。

## 🔐 ID

### Microsoft Entra ID (旧称 Azure AD)

Microsoft Entra ID（旧称 Azure AD）は、クラウド環境におけるIDとアクセス管理を包括的に提供するサービスです。これにより、ユーザーが様々なアプリケーションやリソースに安全にサインインし、必要な情報や機能へアクセスすることを可能にします。例えば、社員が社内外のSaaSアプリケーション（Microsoft 365、Salesforceなど）にシングルサインオン（SSO）でアクセスできるようになり、パスワード管理の負担軽減とセキュリティ強化を実現します。また、条件付きアクセス機能により、サインイン元の場所やデバイスの状態といった状況に応じてアクセス制御を動的に適用し、不正アクセスを防止します。さらに、多要素認証（MFA）を必須とすることで、アカウント乗っ取りのリスクを大幅に低減し、組織全体のセキュリティ体制を堅牢化します。外部ユーザーやパートナーとのセキュアなコラボレーションを実現するゲストアクセス管理も容易に行えます。

**毎月の上限：** すべてのクラウド アプリへのシングル サインオン (SSO) を備えた 50,000 個の保存オブジェクト

🔗 https://www.microsoft.com/ja-jp/security/business/identity-access/microsoft-entra-id
