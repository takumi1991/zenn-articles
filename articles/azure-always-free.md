# Azure常時無料サービス一覧

### Azure AI Search

Azure AI Searchは、Webサイトやアプリケーションに高度な検索機能を組み込むためのクラウドベースの検索サービスです。ユーザーは自然言語で質問を投げかけることができ、Azure AI Searchはその意図を理解し、関連性の高い情報を迅速に返します。例えば、ECサイトであれば、商品名だけでなく、商品の説明文やレビューに含まれるキーワードからも最適な商品を検索し、顧客満足度向上に貢献します。また、社内ドキュメント検索システムに導入すれば、膨大な文書の中から必要な情報を容易に見つけ出すことができます。AIを活用したインテリジェントな検索体験を提供し、アプリケーションの利便性を飛躍的に向上させます。

**毎月の上限：** サービスごとに 10,000 件のホスト ドキュメントと 3 つのインデックスを保存できる 50 MB のストレージ

🔗 https://azure.microsoft.com/ja-jp/products/ai-services/ai-search/

### Azure Language

Azure Language は、自然言語処理 (NLP) を活用してテキストデータから深い洞察を抽出する、強力なクラウドベースのサービスです。このサービスを使用すると、テキストの感情分析を行い、肯定的、否定的、または中立的な意見を理解したり、文章の主要なトピックやキーワードを特定したりできます。また、人名、地名、組織名といった固有表現を抽出し、テキストの言語を自動的に検出することも可能です。これらの機能は、顧客からのフィードバック分析、コンテンツのモデレーション、情報抽出、多言語対応アプリケーションの開発など、幅広いユースケースで活用できます。

**毎月の上限：** 5,000 テキスト レコード

🔗 https://azure.microsoft.com/ja-jp/products/ai-foundry/tools/language

### AI Bot Service

AI Bot Service は、AIを活用したインテリジェントなチャットボットを、ビジネスニーズに合わせて柔軟に拡張しながら開発できるサービスです。顧客サポートの自動化、社内ヘルプデスクの効率化、Webサイトでの商品案内など、様々なユースケースで利用できます。自然言語処理能力により、ユーザーの意図を理解し、パーソナライズされた対話を提供することで、ユーザーエクスペリエンスの向上と業務効率化に貢献します。

**毎月の上限：** プレミアム チャネル メッセージ 10,000 件と無制限の標準チャネル メッセージ

🔗 https://azure.microsoft.com/ja-jp/products/ai-services/ai-bot-service/

### AI Immersive Reader

AI Immersive Readerは、アプリケーションに読解支援機能を組み込むためのAzure Cognitive Serviceです。このサービスを活用することで、ユーザーはテキストコンテンツをより深く理解できるようになります。例えば、教育分野では学習者が文章の難易度を調整したり、単語の意味を調べたりするのに役立ちます。また、ビジネスアプリケーションでは、契約書や報告書などの複雑な文書を読みやすくすることで、業務効率の向上に貢献します。Immersive Readerは、テキストの読み上げ、単語の区切り表示、品詞のハイライト、翻訳などの機能を提供し、多様なニーズに対応します。

**毎月の上限：** 300 万文字

🔗 https://azure.microsoft.com/ja-jp/products/ai-services/ai-immersive-reader/

### 音声テキスト変換

音声テキスト変換は、録音された音声データやリアルタイムの音声を、高精度な自然言語処理技術を用いてテキスト形式に変換するAzureのサービスです。これにより、会議の議事録作成、コールセンターでの顧客応対分析、動画コンテンツの字幕生成、聴覚障がい者向けのリアルタイム音声認識支援など、幅広い用途で活用できます。音声データをテキスト化することで、検索性や分析性を向上させ、業務効率化や新しいインテリジェントなアプリケーション開発に貢献します。

**毎月の上限：** リアルタイム音声テキスト変換を毎月 5 時間分の音声に使用可能

🔗 https://azure.microsoft.com/ja-jp/products/ai-foundry/tools/speech

### テキスト読み上げ

テキスト読み上げは、入力したテキストを自然で人間らしい音声に変換するAzure Cognitive Servicesの一つです。このサービスを利用することで、アプリケーションやウェブサイトに音声機能を組み込み、視覚障碍者向けのアクセシビリティ向上、教育コンテンツのオーディオ化、スマートデバイスの音声応答機能開発など、多岐にわたるユースケースを実現できます。様々な言語や話者音声に対応しており、感情表現豊かな合成音声も生成可能です。

**毎月の上限：** 標準ニューラル音声を毎月 50 万文字分使用可能

🔗 https://azure.microsoft.com/ja-jp/products/ai-foundry/tools/speech

### 音声翻訳

Azure 音声翻訳は、リアルタイムで話し声を高精度にテキスト化し、さらにそれを多様な言語へ翻訳するサービスです。会議やイベントでの多言語コミュニケーションを円滑にするだけでなく、グローバルな顧客サポートや、言語の壁を越えた情報共有を可能にします。例えば、海外からの参加者がいる国際会議で、各参加者の発言をリアルタイムで母国語に翻訳して表示することで、全員が内容を理解し、活発な議論を促進できます。また、グローバル展開する企業のコールセンターでは、オペレーターと海外顧客の会話をリアルタイムで翻訳し、スムーズな対応を実現します。

**毎月の上限：** リアルタイム音声翻訳 (標準音声) を毎月 5 時間分の音声に使用可能

🔗 https://azure.microsoft.com/ja-jp/products/ai-foundry/tools/speech

### 翻訳ツール

Azure Translator は、アプリケーション、Web サイト、およびその他のツールに多言語サポートを組み込むための強力なクラウドベースの翻訳サービスです。このサービスを利用することで、世界中のユーザーに対してコンテンツをローカライズし、グローバルなリーチを拡大することが可能になります。例えば、多言語対応のカスタマーサポートシステムを構築したり、グローバル展開するECサイトの商品説明を自動翻訳したり、あるいはローカライズされたゲームコンテンツを提供したりする際に役立ちます。リアルタイムのテキスト翻訳からドキュメント翻訳まで、幅広いシナリオに対応し、ビジネスの国際化を強力に支援します。

**毎月の上限：** 標準翻訳とカスタム翻訳トレーニングを、任意の組み合わせで 200 万文字に使用可能

🔗 https://azure.microsoft.com/ja-jp/products/ai-foundry/tools/translator

### Face

Azure Face API は、画像内の人物の顔を自動的に検出し、その特徴を分析・認識するクラウドベースのサービスです。顔の検出に加えて、表情、年齢、性別などの属性推定や、顔の類似性比較、さらに個々の人物の特定や追跡も可能です。これにより、写真ライブラリの整理、ソーシャルメディアでの人物タグ付け、セキュリティシステムでの顔認証、顧客の感情分析といった多様なアプリケーション開発に活用できます。例えば、イベント会場で参加者の顔を認識し、過去の参加履歴と照合するといった高度なユースケースも実現できます。

**毎月の上限：** Free インスタンスの 30,000 トランザクション

🔗 https://azure.microsoft.com/ja-jp/products/cognitive-services/face/

### Machine Learning

Azure Machine Learning は、機械学習モデルの開発、トレーニング、デプロイ、管理をエンドツーエンドで行えるクラウドベースのサービスです。R や Python といった使い慣れた言語で、データサイエンティストや開発者が高度な機械学習ソリューションを構築するのを支援します。例えば、製造業における予知保全、小売業での需要予測、医療分野での疾患診断支援など、様々な業界でビジネス課題の解決に活用されています。GUI ベースのデザイナーと、コードベースの SDK の両方を提供し、初心者からエキスパートまで、幅広いスキルレベルに対応しています。

**毎月の上限：** なし

🔗 https://azure.microsoft.com/ja-jp/products/machine-learning/

### Open Datasets

### Content Safety

Azure Content Safety は、テキストや画像に含まれる不適切または有害なコンテンツを自動的に検出し、フラグ付けすることで、安全でポジティブなオンライン環境の構築を支援するサービスです。例えば、ユーザー生成コンテンツ（UGC）プラットフォームにおいて、ヘイトスピーチや性的コンテンツ、暴力表現などをリアルタイムで検出し、モデレーション担当者の負担を軽減したり、自動的にブロックしたりすることが可能です。また、チャットアプリケーションでの嫌がらせの防止や、オンライン広告の安全性確保にも活用できます。AIを活用した高度な分析により、迅速かつ正確なコンテンツ管理を実現します。

**毎月の上限：** AKS クラスターの管理は無料です。ノードによって消費されるリソースに対して料金が発生します

🔗 https://azure.microsoft.com/ja-jp/products/ai-services/ai-content-safety/

### Data Catalog

Azure Data Catalog は、組織内のデータ資産を容易に見つけ、理解し、利用するためのクラウドベースのデータカタログサービスです。データスチュワードやデータアナリストは、このサービスを利用して、社内の様々なデータソース（データベース、データウェアハウス、ファイルストレージなど）に格納されているデータを登録・管理し、メタデータを付与することで、データの場所、意味、形式、所有者などを一元的に把握できます。これにより、データサイエンティストやビジネスユーザーは、必要なデータに素早くアクセスし、分析や意思決定に活用することが可能となり、データ活用によるビジネス価値の最大化に貢献します。例えば、マーケティング部門が過去のキャンペーンデータを分析したい場合、Data Catalog を使えば、関連するデータセットを容易に特定し、その内容を理解した上で分析に着手できます。

**毎月の上限：** ユーザー数無制限

🔗 https://azure.microsoft.com/ja-jp/products/data-catalog/

### Data Factory

Azure Data Factoryは、様々なデータソースからのデータを効率的に移動、変換、統合するためのクラウドベースのETL（Extract, Transform, Load）およびデータ統合サービスです。例えば、オンプレミスのデータベースからAzure SQL Databaseへのデータ移行、データウェアハウスへのデータロード、機械学習モデルのトレーニング用データセットの準備など、複雑なデータワークフローの自動化とオーケストレーションを実現します。コードを記述することなく、GUIベースのインターフェイスでパイプラインを設計・管理できるため、データエンジニアや開発者は迅速かつ柔軟にデータ処理プロセスを構築し、ビジネスインサイトの抽出を加速できます。

**毎月の上限：** 5 つの低頻度アクティビティ

🔗 https://azure.microsoft.com/ja-jp/products/data-factory/

### App Service

Azure App Serviceは、WebアプリケーションやAPIを迅速かつ効率的に開発、デプロイ、管理するためのフルマネージドなプラットフォームサービスです。開発者はインフラストラクチャの管理に煩わされることなく、アプリケーションのコード開発に集中できます。例えば、ECサイトのバックエンド、モバイルアプリのAPI、RESTful APIなどを、簡単なデプロイプロセスと自動スケーリング機能で、グローバル規模で公開・運用することが可能です。また、様々なプログラミング言語やフレームワークに対応しており、柔軟な開発環境を提供します。継続的なインテグレーション/継続的なデリバリ（CI/CD）パイプラインとの連携も容易で、開発から運用までのライフサイクル全体を効率化します。

**毎月の上限：** 最大 10 個の Web アプリまたは API アプリ、1 GB のストレージ、1 日あたり 1 時間

🔗 https://azure.microsoft.com/ja-jp/products/app-service/

### Azure Kubernetes Service (AKS)

Azure Kubernetes Service (AKS)は、コンテナー化されたアプリケーションのデプロイ、管理、スケーリングを簡素化する、マネージドなKubernetesサービスです。開発者は、使い慣れたKubernetesツールやオープンソースエコシステムを活用しながら、インフラストラクチャの管理から解放されます。AKSを利用することで、マイクロサービスアーキテクチャの構築、CI/CDパイプラインの自動化、ハイブリッドクラウド環境でのアプリケーション展開などが容易になり、開発効率と運用俊敏性を向上させることができます。これにより、ビジネスの変化に迅速に対応し、イノベーションを加速させることが可能になります。

**毎月の上限：** AKS クラスターの管理は無料です。ノードによって消費されるリソースに対して料金が発生する

🔗 https://azure.microsoft.com/ja-jp/products/kubernetes-service/

### Azure VM Image Builder

Azure VM Image Builder は、カスタム仮想マシン (VM) イメージの作成、管理、更新を自動化するサービスです。これにより、セキュリティパッチの適用やアプリケーションのインストール済みのイメージを、時間のかかる手動プロセスなしで迅速に展開できます。例えば、コンプライアンス要件を満たすための特定の構成を持つイメージを頻繁に更新する必要がある企業や、開発・テスト環境ですぐに利用できる標準化されたイメージを迅速にプロビジョニングしたい場合に非常に役立ちます。このサービスを利用することで、イメージのライフサイクル全体を効率化し、デプロイメントのスピードと一貫性を向上させることができます。

**毎月の上限：** VM Image Builder は無料のサービスです。構築時にデータ転送や有料の Azure サービスを利用すると、料金が発生する場合があります

🔗 https://azure.microsoft.com/ja-jp/products/image-builder/

### Batch

Azure Batchは、大量のコンピューティングリソースを必要とするアプリケーションをクラウド上で効率的に実行するためのサービスです。並列処理やバッチ処理といった、時間のかかる計算タスクを大規模に実行したい場合に最適です。例えば、科学技術計算、レンダリング、データ分析、機械学習のモデルトレーニングなどに活用でき、ジョブのスケジューリングやリソース管理を自動化することで、開発者はアプリケーションのコードに集中できます。必要な時に必要なだけコンピューティングパワーを利用できるため、コスト効率も向上します。

**毎月の上限：** なし

🔗 https://azure.microsoft.com/ja-jp/products/batch/

### Functions

Azure Functionsは、サーバーの管理なしにコードを実行できるイベント駆動型コンピューティングサービスです。HTTPリクエスト、データベースの変更、タイマーなどの様々なイベントをトリガーとして、小さなコード（関数）を自動的に実行できます。これにより、Web APIのバックエンド、IoTデバイスからのデータ処理、バッチ処理の自動化など、多様なアプリケーションを迅速に構築できます。開発者はインフラストラクチャの運用に手間をかけることなく、ビジネスロジックの実装に集中できます。

**毎月の上限：** 100 万回のリクエスト

🔗 https://azure.microsoft.com/ja-jp/products/functions/

### Static Web Apps

Azure Static Web Appsは、Webアプリケーションのフロントエンドとバックエンドを効率的に構築・デプロイできるマネージドサービスです。GitHubやAzure DevOpsなどのソースコードリポジトリと連携し、コードのプッシュをトリガーに自動ビルドとデプロイ、グローバルなCDNによる高速配信、SSL証明書の自動更新といった運用管理を簡素化します。SPA（シングルページアプリケーション）や静的サイト、API機能を持つWebアプリ開発に適しており、開発者はインフラ管理から解放され、ビジネスロジックの実装に集中できます。これにより、開発サイクルを短縮し、スケーラブルで高可用性なWebアプリケーションを迅速に提供することが可能です。

**毎月の上限：** サブスクリプションあたり 100 GBの帯域幅、2 つのカスタム ドメイン、アプリあたり 0.5 GB のストレージ

🔗 https://azure.microsoft.com/ja-jp/products/app-service/static/

### Azure コンテナー ストレージ

Azure コンテナー ストレージは、Kubernetesなどのコンテナー環境で実行されるアプリケーションのデータを安全かつ永続的に保存するためのサービスです。データベースやWebサーバーのように、処理中に生成・更新されるデータを失いたくないステートフルなコンテナーアプリケーションにおいて、そのデータの永続化を実現します。例えば、ECサイトの注文履歴や、顧客管理システムのデータなどをコンテナー内に保存し、コンテナーが再起動したり、別のノードに移動したりしても、データは失われずに利用し続けることができます。これにより、コンテナーアプリケーションの信頼性と可用性を高め、より堅牢なシステム構築を可能にします。

**毎月の上限：** このサービスでは、ストレージ プール容量 5 TiB 未満のデプロイ向けに Free レベルが提供されます

🔗 https://azure.microsoft.com/ja-jp/products/container-storage/

### Container Apps

Azure Container Appsは、コンテナー化されたアプリケーションやマイクロサービスを、インフラストラクチャ管理なしで迅速に構築・デプロイできるフルマネージドなサービスです。サーバーレスの実行モデルにより、コンピューティングリソースのプロビジョニングやスケーリングを自動で行うため、開発者はアプリケーションロジックに集中できます。HTTPリクエストへの自動スケーリングや、イベントドリブンな処理、バックグラウンドジョブの実行など、多様なシナリオに対応し、API、Webアプリ、マイクロサービス、バッチ処理などを効率的に運用するための強力なプラットフォームを提供します。

**毎月の上限：** 180,000 vCPU 秒、360,000 GiB 秒、200 万リクエスト

🔗 https://azure.microsoft.com/ja-jp/products/container-apps/

### Service Fabric

Service Fabricは、マイクロサービスアーキテクチャに基づいた、信頼性が高くスケーラブルな分散アプリケーションを開発・運用するためのプラットフォームです。ステートフルおよびステートレスなサービスを構築でき、高可用性と耐障害性を実現します。例えば、IoTデバイスからの大量のデータ処理、リアルタイム分析、Eコマースプラットフォームのバックエンドなど、ミッションクリティカルなアプリケーションの構築に適しています。開発者は、選択した言語（.NET、Java、Goなど）でアプリケーションを開発し、Service Fabricはデプロイ、スケーリング、監視、更新といった運用管理を自動化します。これにより、開発者はアプリケーションのコアロジックに集中できます。

**毎月の上限：** なし

🔗 https://azure.microsoft.com/ja-jp/products/service-fabric/

Azure Policyは、Azureリソースのコンプライアンスとガバナンスを確保するためのサービスです。組織が定義した標準や規則に従ってリソースが展開・設定されるように強制し、セキュリティ、コスト管理、運用効率の向上に貢献します。例えば、特定のタグが付与されていないリソースのデプロイをブロックしたり、すべてのストレージアカウントに暗号化を必須としたりすることで、意図しない設定ミスやコンプライアンス違反を防ぎます。これにより、クラウド環境全体で一貫した管理状態を維持することが可能になります。

**毎月の上限：** 構成および変更追跡機能への無料アクセス

🔗 https://azure.microsoft.com/ja-jp/products/azure-policy/

### Azure Resource Mover

Azure Resource Moverは、Azureリソースを異なるリージョンへ容易に移動できるように設計されたサービスです。このサービスを利用することで、オンプレミス環境からの移行や、災害対策（DR）サイトの構築、あるいはパフォーマンス改善のためにリソースを別のリージョンへ迅速かつ安全に転送できます。Azure Resource Moverは、依存関係のあるリソース群をまとめて移動できるため、手動での設定変更や影響範囲の確認にかかる手間と時間を大幅に削減します。例えば、Webアプリケーションとそのデータベース、ストレージアカウントなどを連携したまま、別のAzureリージョンへスムーズに移行させたい場合に非常に役立ちます。

**毎月の上限：** 無料 (イングレスとエグレスの料金が適用される場合があります)

🔗 https://azure.microsoft.com/ja-jp/products/resource-mover/

### Azure Update Manager

Azure Update Managerは、Azure仮想マシンやオンプレミスサーバーを含む、あらゆる環境のOS更新を統合的に管理・自動化できるサービスです。これにより、セキュリティパッチの適用漏れを防ぎ、コンプライアンスを維持しながら、IT管理者の運用負荷を大幅に軽減します。例えば、組織全体で定期的なOS更新を計画的に実施し、更新前後の状態を継続的に監視することで、システム障害のリスクを最小限に抑え、ビジネスの継続性を確保することが可能です。

**毎月の上限：** Azure リソースは無料 (Arc 対応サーバーは課金対象) です。詳細は価格ページをご覧ください

### Cloud Shell

Cloud Shellは、WebブラウザからAzureリソースを直接操作できるインタラクティブなコマンドライン環境です。BashやPowerShellなどの使い慣れたシェル環境で、Azure CLIやAzure PowerShellといったツールを使って、仮想マシンのデプロイ、ストレージアカウントの構成、ネットワーク設定の変更など、様々な管理タスクを迅速に実行できます。開発者はローカル環境にツールをインストールする手間なく、いつでもどこでもAzure管理を行えるため、開発・運用の効率化に貢献します。例えば、急なインシデント対応で、すぐにAzureリソースの状態を確認・修正したい場合などに非常に役立ちます。

**毎月の上限：** Azure Files での 12 か月間 5 GB の無料ストレージ

🔗 https://azure.microsoft.com/ja-jp/get-started/azure-portal/cloud-shell/

### Cost Management

Azure Cost Management は、Azure 環境におけるコストを詳細に把握し、管理するための包括的なソリューションです。このサービスを利用することで、組織はリソースごとの支出を可視化し、予算管理を徹底できます。例えば、開発チームが利用している仮想マシンのコストを特定し、不要なリソースの削除や、より低コストなコンピューティングオプションへの移行を検討することで、クラウド利用料の最適化を実現します。また、部門やプロジェクトごとにコストを割り当てることで、責任範囲を明確にし、コスト意識の向上を促進します。これにより、クラウド投資対効果の最大化と、無駄な支出の削減に貢献します。

**毎月の上限：** なし

🔗 https://azure.microsoft.com/ja-jp/products/cost-management/

### Monitor

Azure Monitorは、Azure環境全体のリソースの状態を包括的に把握し、パフォーマンスや可用性を維持するための統合監視サービスです。アプリケーションの応答時間、サーバーのCPU使用率、ネットワークトラフィックなどのメトリックとログを収集・分析し、異常の検知や問題の特定に役立ちます。例えば、ウェブアプリケーションのパフォーマンス低下を早期に発見し、原因を調査して迅速に復旧させたり、インフラストラクチャの容量不足を予測してリソースを最適化したりする際に活用されます。これにより、サービスの安定運用とビジネス継続性を実現します。

**毎月の上限：** 機能ごとの無料利用額については、Azure Monitor の料金詳細を参照する

🔗 https://azure.microsoft.com/ja-jp/products/monitor/

### Resource Manager

Azure Resource Manager (ARM) は、Azure 上のリソースを包括的に管理するためのサービスです。デプロイ、管理、監視を、単一の整合性の取れた管理エクスペリエンスで実行できます。例えば、仮想マシン、ストレージアカウント、仮想ネットワークといった複数のリソースを、JSON 形式のテンプレートを用いて一度にプロビジョニングし、一元管理することで、インフラストラクチャのデプロイメントを自動化し、一貫性を保つことができます。これにより、開発チームはインフラストラクチャの複雑さに煩わされることなく、アプリケーション開発に集中できます。

**毎月の上限：** なし

🔗 https://azure.microsoft.com/ja-jp/get-started/azure-portal/resource-manager/

### Azure Migrate

Azure Migrateは、オンプレミスのサーバーやアプリケーションをAzureクラウドへシームレスに移行するための統合プラットフォームです。このサービスを利用することで、既存のIT資産を詳細に発見・評価し、移行計画を策定、さらにはAzure環境への移行実行までを一貫して行うことができます。例えば、老朽化したオンプレミスサーバーの刷新や、災害対策・事業継続計画（BCP）の強化を目的としたクラウド移行において、その効果を発揮します。Azure Migrateは、移行前のアセスメントから実行、その後の最適化までをサポートし、スムーズなクラウドジャーニーを実現します。

**毎月の上限：** なし

### Azure Storage Mover

### Bandwidth (データ転送)

### Network Watcher

Network Watcherは、Azure仮想ネットワークのパフォーマンスと健全性を継続的に監視・診断し、問題解決のための詳細な分析情報を提供するサービスです。ネットワークのボトルネック特定、接続性のトラブルシューティング、パケットフローの分析などを通じて、アプリケーションの可用性とパフォーマンスを維持します。例えば、仮想マシン間の通信に問題が発生した場合、Network Watcherの接続トラブルシューティング機能を使用すれば、原因となっているファイアウォールルールやルーティングの問題を迅速に特定し、修正策を講じることができます。これにより、インフラストラクチャの信頼性を高め、運用コストの削減に貢献します。

### Private Link

Private Linkは、AzureのVNet（仮想ネットワーク）からAzure PaaS（Platform as a Service）サービスやAzureがホストする顧客所有のサービスへ、インターネットを経由せずにプライベートな接続を確立するサービスです。これにより、データやトラフィックがMicrosoftのプライベートネットワーク内にとどまるため、セキュリティが大幅に向上します。例えば、Azure StorageやAzure SQL Databaseへのアクセスを、インターネット公開せずにVNet内のリソースから安全に行いたい場合に利用できます。Private Endpointを介してサービスに接続することで、IPアドレスによるアクセス制御も可能になり、よりセキュアな環境を構築できます。

**毎月の上限：** なし

🔗 https://azure.microsoft.com/ja-jp/products/private-link/

### Virtual Network

Virtual Networkは、Azure上で構築されるプライベートなネットワーク環境です。これにより、仮想マシンやその他のAzureリソースを相互に接続し、セキュアな通信を実現できます。オンプレミスのデータセンターや他のクラウド環境との接続も可能で、ハイブリッドクラウド環境の構築に不可欠です。例えば、企業が自社内に持つサーバー群とAzure上のアプリケーションを安全に連携させたり、開発環境と本番環境を論理的に分離したりする際に利用されます。IPアドレス空間の定義やサブネット分割、ルーティング、ネットワークセキュリティグループによるアクセス制御などを細かく設定でき、高度なネットワーク管理を実現します。

**毎月の上限：** 50 仮想ネットワーク

🔗 https://azure.microsoft.com/ja-jp/products/virtual-network/

### Azure Attestation

Azure Attestation は、コンピューティング環境の信頼性を証明し、機密性の高いワークロードを保護するためのサービスです。ハードウェアレベルのセキュリティ機能（TPM など）や、暗号化されたメモリ領域（SGX など）を利用して、実行されているコードが改ざんされていないこと、および機密データが安全な環境で処理されていることを検証します。これにより、例えば、秘密鍵を安全に生成・保管したい場合や、機密性の高いデータを保護しながら分析を行いたい場合に、その実行環境の正当性をリモートで確認することが可能となり、クラウド上でのセキュアなアプリケーション開発を強力に支援します。

### Azure SignalR Service

Azure SignalR Service は、Web アプリケーションやモバイルアプリで、サーバーからクライアントへのリアルタイムな双方向通信を容易に実現するマネージドサービスです。これにより、チャットアプリケーション、リアルタイム通知、ライブダッシュボードなどの動的なユーザーエクスペリエンスを構築できます。開発者は、WebSocket や Server-Sent Events などの複雑な通信プロトコルを直接管理する必要がなく、API を介してメッセージをブロードキャストしたり、特定のクライアントに送信したりできます。スケーラビリティと可用性が高く、バックエンドサービスとの連携も容易なため、リアルタイム機能の開発を加速させ、ユーザーエンゲージメントの向上に貢献します。

**毎月の上限：** ユニットあたり 20 の同時接続と 20,000 件のメッセージ

🔗 https://azure.microsoft.com/ja-jp/products/signalr-service/

### Web PubSub

Azure Web PubSub は、Web アプリケーションやモバイルアプリケーションに、サーバーとクライアント間のリアルタイムな双方向通信機能を簡単に追加できるマネージドサービスです。WebSocket プロトコルを基盤として、メッセージの送受信を効率的に管理し、スケーラブルで高可用性なリアルタイム体験を提供します。例えば、チャットアプリケーション、リアルタイムの通知システム、ライブゲームのスコア更新、共同編集ツールなどで利用することで、ユーザーエンゲージメントを大幅に向上させることができます。開発者は複雑なネットワークインフラストラクチャの構築や管理から解放され、アプリケーションのコア機能開発に集中できます。

**毎月の上限：** 1 ユニットあたり 1 日 20,000 件のメッセージ、1 ユニットあたり 20 の同時接続 (最大 1 ユニット)

🔗 https://azure.microsoft.com/ja-jp/products/web-pubsub/
