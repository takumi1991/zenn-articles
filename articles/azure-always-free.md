# Azure常時無料サービス一覧

Azureには常時無料で利用できるサービスが多数存在しており、各サービス一定の上限までは課金されずに利用できます。本記事ではカテゴリごとにそれら常時無料サービス整理しています。

## 🧠 AI + 機械学習

### Azure AI Search

Azure AI Searchは、AIを活用して大量のデータから必要な情報を素早く見つけ出すためのクラウドサービスです。ウェブサイトやドキュメント、データベースなど、様々な場所にある情報を検索可能にし、ユーザーが求めている情報を的確に提示します。例えば、企業の顧客サポートで問い合わせ内容に合ったFAQを自動で探し出したり、ECサイトで商品の特徴から関連商品をレコメンドしたりする際に活用できます。

**毎月の上限：** サービスごとに 10,000 件のホスト ドキュメントと 3 つのインデックスを保存できる 50 MB のストレージ

🔗 https://azure.microsoft.com/ja-jp/products/ai-services/ai-search/

---

### Azure Language

Azure Languageは、AIの力でテキストを理解し、感情や意図を分析するサービスです。例えば、顧客からのレビューを分析して満足度を把握したり、SNSの投稿から世間の評判を検知したりできます。また、文章を自動で要約したり、誤字脱字を訂正したりする機能もあり、ビジネスでの情報活用やコンテンツ作成を強力にサポートします。

**毎月の上限：** 5,000 テキスト レコード

🔗 https://azure.microsoft.com/ja-jp/products/ai-foundry/tools/language

---

### AI Bot Service

AI Bot Serviceは、自然な言葉で対話できるAIチャットボットを簡単に作成・管理できるサービスです。顧客からの問い合わせ対応、社内ヘルプデスク、予約受付など、様々な場面で活用できます。プログラミング知識がなくても、用意されたテンプレートや直感的な操作で、目的に合わせたボットを素早く構築。ユーザーの質問を理解し、適切な情報を提供したり、タスクを実行したりすることで、業務効率化や顧客満足度向上に貢献します。

**毎月の上限：** プレミアム チャネル メッセージ 10,000 件と無制限の標準チャネル メッセージ

🔗 https://azure.microsoft.com/ja-jp/products/ai-services/ai-bot-service/

---

### AI Immersive Reader

AI Immersive Readerは、学習や読書を助けるためのAI搭載ツールです。文字の大きさや色を変えたり、単語の意味を調べたり、文章を読み上げたりする機能があり、文章を集中して理解しやすくなります。例えば、子供が難しい文章を読みたいときや、外国語の学習、視覚に障がいのある方などが、より快適に情報にアクセスできるようになります。

**毎月の上限：** 300 万文字

🔗 https://azure.microsoft.com/ja-jp/products/ai-services/ai-immersive-reader/

---

### Face

Azure Faceは、画像から顔を検出・認識・分析できるAIサービスです。写真に写っている人が誰なのかを特定したり、年齢や性別、表情などを分析したりできます。例えば、SNSで友達の顔を自動でタグ付けしたり、防犯カメラの映像から不審な人物を検知したりするのに役立ちます。

**毎月の上限：** Free インスタンスの 30,000 トランザクション

🔗 https://azure.microsoft.com/ja-jp/products/cognitive-services/face/

---

### Machine Learning

Machine Learningは、AI（人工知能）を使って、データから学習し、予測や自動化を行うためのクラウドサービスです。例えば、顧客の購買履歴から次回の購入を予測したり、画像認識で不良品を自動検出したりするのに役立ちます。プログラミングの知識があまりなくても、直感的な操作でAIモデルを作成・展開できるため、ビジネスの効率化や新しいサービスの開発を支援します。

**毎月の上限：** 無料

🔗 https://azure.microsoft.com/ja-jp/products/machine-learning/

---

### Open Datasets

Microsoft AzureのOpen Datasetsは、誰でも利用できる公開データセットのコレクションです。気象、人口統計、地図、画像など、多様な分野のデータが提供されており、AIや機械学習モデルのトレーニング、データ分析、研究開発に活用できます。例えば、AIで天気予報の精度を向上させたり、地域ごとの人口動態を分析してビジネス戦略を立てたりするのに役立ちます。これらのデータは、Azure Machine Learningなどのサービスから簡単にアクセス・利用でき、革新的なアイデアの実現を支援します。

**毎月の上限：** 無料 (エグレスの料金が適用される場合あり)

🔗 https://azure.microsoft.com/ja-jp/products/open-datasets/

---

### Content Safety

Content Safetyは、AIを活用して、画像やテキストなどのコンテンツに不適切または有害なものが含まれていないか自動で検出・分類するサービスです。例えば、オンラインフォーラムでユーザーが投稿した画像に暴力的な内容が含まれていないか、チャットで差別的な言葉が使われていないかなどをチェックし、健全なコミュニティ運営を支援します。アダルトコンテンツ、暴力、ヘイトスピーチなどの危険なコンテンツを未然に防ぎ、安全なデジタル環境の維持に役立ちます。

**毎月の上限：** AKS クラスターの管理は無料です。ノードによって消費されるリソースに対して料金が発生します

🔗 https://azure.microsoft.com/ja-jp/products/ai-services/ai-content-safety/

## 📦 コンテナー

### Azure コンテナー ストレージ

Azure コンテナー ストレージは、コンテナーアプリやKubernetesなどのコンテナ環境で、データを永続的に保存・管理するためのサービスです。ファイル共有やブロックストレージといった、様々なストレージの種類をコンテナから利用可能にします。例えば、Webアプリケーションでユーザーがアップロードした画像を保存したり、データベースのデータを永続化したりする際に役立ちます。これにより、コンテナの再起動や更新時にもデータが失われる心配がなくなります。

**毎月の上限：** このサービスでは、ストレージ プール容量 5 TiB 未満のデプロイ向けに Free レベルが提供されます

🔗 https://azure.microsoft.com/ja-jp/products/container-storage/

---

### Azure Kubernetes Service (AKS)

AKSは、マイクロソフトが提供するマネージドなKubernetesサービスで、コンテナ化されたアプリケーションのデプロイ、管理、スケーリングを容易にします。Kubernetesクラスターの構築・運用・管理をAzureが担うため、インフラ管理の手間を省き、開発者はアプリケーション開発に集中できます。例えば、Webアプリケーションのデプロイやマイクロサービスアーキテクチャの構築、バッチ処理の実行などに利用でき、ビジネスの俊敏性と拡張性を高めます。

**毎月の上限：** AKS クラスターの管理は無料です。ノードによって消費されるリソースに対して料金が発生する

🔗 https://azure.microsoft.com/ja-jp/products/kubernetes-service/

---

### Container Apps

Container Appsは、コンテナ化されたアプリケーションを簡単にデプロイ、実行、管理できるAzureのサービスです。コードをコンテナイメージにするだけで、インフラ管理を気にせず、スケーリングやHTTPトラフィックのルーティング、定期実行タスクなどを自動で行えます。マイクロサービス、Web API、バッチ処理など、様々な用途で利用でき、開発者はビジネスロジックに集中できます。

**毎月の上限：** 180,000 vCPU 秒、360,000 GiB 秒、200 万リクエスト

🔗 https://azure.microsoft.com/ja-jp/products/container-apps/

## 📊 分析

### Data Catalog

Azure Data Catalogは、組織内のデータ資産を検索・発見・理解するためのクラウドベースのサービスです。あらゆるデータソースを登録し、メタデータを付与することで、誰でも必要なデータを見つけやすくなります。例えば、マーケターが顧客データを分析したい場合や、データサイエンティストが機械学習モデルに使うデータを探す際に役立ちます。データの場所や意味、利用方法を共有し、データ活用を促進します。

**毎月の上限：** ユーザー数無制限

🔗 https://azure.microsoft.com/ja-jp/products/data-catalog/

---

### Data Factory

Data Factoryは、様々なデータソースからデータを集め、変換し、分析基盤やデータウェアハウスに格納するまでの一連のデータ統合プロセスを自動化できるクラウドサービスです。例えば、Webサイトのログデータを集めて分析しやすい形に加工し、BIツールで可視化するといった作業を、プログラミングなしで簡単に設定できます。ETL（Extract, Transform, Load）やELT（Extract, Load, Transform）といったデータ連携パイプラインを構築し、スケジュール実行したり、イベントをトリガーに実行したりすることも可能です。これにより、データ分析の効率を大幅に向上させることができます。

**毎月の上限：** 5 つの低頻度アクティビティ

🔗 https://azure.microsoft.com/ja-jp/products/data-factory/

## 🖥️ コンピューティング

### App Service

App Serviceは、Webアプリ、モバイルバックエンド、RESTful APIを簡単に作成、デプロイ、スケーリングできる、マネージドなPaaS（Platform as a Service）です。開発者はインフラ管理を気にせず、コードの開発に集中できます。簡単なWebサイトから複雑なバックエンドシステムまで、さまざまなアプリケーションをホストでき、WindowsやLinux、さまざまなプログラミング言語（.NET、Java、Node.js、PHP、Pythonなど）に対応しています。自動スケーリング機能により、トラフィックの増減に合わせてリソースを柔軟に調整でき、高可用性と信頼性の高いアプリケーション運用をサポートします。

**毎月の上限：** 最大 10 個の Web アプリまたは API アプリ、1 GB のストレージ、1 日あたり 1 時間

🔗 https://azure.microsoft.com/ja-jp/products/app-service/

---

### Azure VM Image Builder

Azure VM Image Builderは、カスタム仮想マシン（VM）イメージを自動で作成・管理できるサービスです。OS、アプリケーション、設定などをあらかじめ組み込んだイメージを準備することで、開発やテスト環境の構築、セキュリティパッチの適用を効率化できます。例えば、特定のミドルウェアがインストールされたWebサーバーイメージを定期的に最新の状態に保ち、迅速にVMを展開するといった運用が可能です。これにより、環境構築の手間を大幅に削減し、開発・運用チームの生産性向上に貢献します。

**毎月の上限：** VM Image Builder は無料のサービスです。構築時にデータ転送や有料の Azure サービスを利用すると、料金が発生する場合があります

🔗 https://azure.microsoft.com/ja-jp/products/image-builder/

---

### Batch

Azure Batchは、大量のコンピューティングリソースを効率的に利用して、大規模なバッチ処理を実行するためのクラウドサービスです。例えば、科学技術計算、画像レンダリング、金融モデリングなどの計算集約型のタスクを、必要な時に必要なだけコンピューティングパワーを借りて実行できます。これにより、高価なハードウェア購入や管理の手間を省き、コストを抑えながら処理能力を柔軟に拡張できます。

**毎月の上限：** 無料

🔗 https://azure.microsoft.com/ja-jp/products/batch/

---

### Functions

Azure Functionsは、サーバーレスでイベント駆動型のコンピューティングサービスです。コードを実行するためにサーバーを管理する必要がなく、HTTPリクエスト、タイマー、データベースの変更など、さまざまなイベントをトリガーにコードを自動実行できます。例えば、Web APIのバックエンド、リアルタイムのデータ処理、定時実行タスクなどに利用でき、必要な時に必要なだけリソースが使われるためコスト効率も高いのが特徴です。

**毎月の上限：** 100 万回のリクエスト

🔗 https://azure.microsoft.com/ja-jp/products/functions/

---

### Service Fabric

Service Fabricは、マイクロサービスアーキテクチャを構築・管理するためのプラットフォームです。ステートフルおよびステートレスなアプリケーションを、WindowsやLinux上のクラスターで実行でき、高可用性とスケーラビリティを提供します。例えば、リアルタイムのデータ処理、IoTバックエンド、ゲームサーバーなど、信頼性とパフォーマンスが求められるシステム開発に適しています。開発者は、複雑なインフラ管理を意識することなく、アプリケーションのロジックに集中できます。

**毎月の上限：** 無料

🔗 https://azure.microsoft.com/ja-jp/products/service-fabric/

## 🌎 Web

### Static Web Apps

Static Web Appsは、静的コンテンツ（HTML、CSS、JavaScript）とAPIを簡単にデプロイ・ホストできるAzureのサービスです。GitHubやAzure DevOpsと連携し、コードをプッシュするだけでWebサイトやWebアプリを自動的にビルド・デプロイできます。これにより、小規模なブログサイトの公開や、シンプルなWeb APIとの連携を持つフロントエンドアプリケーションの開発・運用が容易になります。スケーラビリティやセキュリティもAzureが担当するため、開発者はアプリケーション機能の実装に集中できます。

**毎月の上限：** サブスクリプションあたり 100 GBの帯域幅、2 つのカスタム ドメイン、アプリあたり 0.5 GB のストレージ

🔗 https://azure.microsoft.com/ja-jp/products/app-service/static/

---

### App Configuration

App Configurationは、アプリケーションの設定情報を一元管理できるAzureのサービスです。アプリケーションのコードを変更せずに、設定値（接続文字列や機能フラグなど）を動的に変更できるため、開発・運用効率が格段に向上します。例えば、新しい機能を一部のユーザーにのみ公開する機能フラグの切り替えや、環境ごとに異なるデータベース接続文字列の設定などに活用できます。これにより、デプロイメントを迅速化し、エラーのリスクを低減できます。

**毎月の上限：** 10 MB のストレージで 1 日あたり 1,000 件のリクエスト

🔗 https://azure.microsoft.com/ja-jp/products/app-configuration/

---

### Notification Hubs

Notification Hubsは、プッシュ通知を簡単かつ大量に配信できるAzureのサービスです。iOS、Android、Windowsなど、様々なプラットフォームのアプリに、個別またはグループ単位でメッセージを送信できます。例えば、ゲームのアップデート情報や、ECサイトのセール情報、緊急時のアラートなどを、ユーザーのデバイスにリアルタイムで届けたい場合に最適です。多言語対応やターゲティング機能もあり、効果的なプッシュ通知戦略を実現します。

**毎月の上限：** 100 万件のプッシュ通知と無料の名前空間

🔗 https://azure.microsoft.com/ja-jp/products/notification-hubs/

---

### Azure SignalR Service

Azure SignalR Serviceは、ウェブアプリケーションやモバイルアプリにリアルタイムの双方向通信機能を簡単に追加できるマネージドサービスです。これにより、チャットアプリやライブ更新、プッシュ通知などを低遅延で実現できます。例えば、オンラインゲームでプレイヤー間のリアルタイムな情報共有をスムーズに行ったり、株式取引アプリで価格変動を瞬時に表示したりするのに役立ちます。開発者は複雑なインフラ管理なしに、ユーザー体験を向上させるリッチなリアルタイム機能を提供できます。

**毎月の上限：** ユニットあたり 20 の同時接続と 20,000 件のメッセージ

🔗 https://azure.microsoft.com/ja-jp/products/signalr-service/

## 🗄️ データベース

### Azure Cosmos DB

Azure Cosmos DBは、世界中のどこでも、どんな規模でも、低レイテンシーでデータの読み書きを可能にする、マイクロソフトのクラウドベースのデータベースサービスです。アプリケーションが急速に成長しても、パフォーマンスを維持しながら、スケーラビリティと可用性の高いデータベース環境を提供します。例えば、グローバルに展開するeコマースサイトの顧客データ管理や、リアルタイムのゲームデータ処理、IoTデバイスからの膨大なデータ分析などに活用でき、モダンなアプリケーション開発を強力にサポートします。

**毎月の上限：** 1,000 要求ユニット/秒のプロビジョニング済みスループット、25 GB のストレージ

🔗 https://azure.microsoft.com/ja-jp/products/cosmos-db/

---

### Azure Cosmos DB for MongoDB

Azure Cosmos DB for MongoDBは、MongoDBのAPI互換性を持ちながら、AzureのフルマネージドNoSQLデータベースサービスであるCosmos DBの利便性を享受できるデータベースです。スケーラビリティ、高可用性、低レイテンシを実現し、Webアプリケーション、モバイルアプリ、IoT、ゲームなどのバックエンドとして、データ量やアクセス負荷の増加に柔軟に対応しながら、安定したパフォーマンスを提供します。

**毎月の上限：** 32 GB のストレージを備えた専用の MongoDB クラスター

🔗 https://azure.microsoft.com/ja-jp/products/cosmos-db/

---

### SQL Database

SQL Databaseは、Microsoft Azureが提供する、クラウド上で利用できるデータベースサービスです。Webサイトやアプリケーションのデータ管理を任せることができ、自分でサーバーを管理する手間が省けます。例えば、オンラインショップの商品情報や顧客データを保存したり、ブログの投稿を管理したりするのに役立ちます。常に最新の状態に保たれ、セキュリティも強化されているため、安心して利用できます。

**毎月の上限：** 最大 10 個のデータベースを、それぞれ 100,000 vCore 秒のサーバーレス レベルと 32 GB のストレージを利用可能

🔗 https://azure.microsoft.com/ja-jp/products/azure-sql/database/

## ✈️ 移行

### Database Migration Service

Azure Database Migration Serviceは、オンプレミスや他のクラウドにあるデータベースをAzureのデータベースサービスへ、ダウンタイムを最小限に抑えながら安全かつ簡単に移行できるマネージドサービスです。SQL Server、MySQL、PostgreSQLなど、様々なデータベースに対応しており、アプリケーションの停止時間を短縮し、移行作業の複雑さを軽減します。例えば、古いバージョンのSQL ServerからAzure SQL Databaseへ移行する際や、MySQLデータベースをAzure Database for MySQLへ移動する際に利用できます。

**毎月の上限：** 無料の Standard コンピューティング

🔗 https://azure.microsoft.com/ja-jp/products/database-migration/

---

### Azure Migrate

Azure Migrateは、オンプレミスや他のクラウドにあるシステムを、コスト効率よく、かつ安全にAzureへ移行するための無料のサービスです。サーバー、データベース、アプリケーションなどを評価し、移行計画を立て、実行までをサポートします。例えば、古くなったオンプレミスサーバーの更新や、災害対策（DR）のためにAzureへシステムを移したい場合に役立ちます。移行後の運用管理も容易になり、ビジネスの俊敏性向上に貢献します。

**毎月の上限：** 無料

🔗 https://azure.microsoft.com/ja-jp/products/azure-migrate/

---

### Azure Storage Mover

Azure Storage Moverは、オンプレミスや他のクラウドからAzure Storageへのデータ移行を自動化・効率化するサービスです。数テラバイトからペタバイト規模の大量データを、ダウンタイムを最小限に抑えつつ、信頼性高く安全にAzureへ移動できます。例えば、古いファイルサーバーのデータをAzure Filesに移行したり、長期間保存が必要なデータをAzure Blob Storageにアーカイブする際に活用できます。複雑な設定やスクリプト作成の手間を省き、迅速なデータ移行を実現します。

**毎月の上限：** 無料

🔗 https://azure.microsoft.com/ja-jp/products/storage-mover#Azure-storage-mover

## 🛠️ 開発者ツール

### Azure Deployment Environments

**毎月の上限：** Azure Deployment Environments は、現在、無料のサービスです。ただし、サービスを通じてデプロイされた環境に作成されるコンピューティング、ストレージ、ネットワークなどの他の Azure リソースに対しては料金が発生します

🔗 https://azure.microsoft.com/ja-jp/products/deployment-environments/

**毎月の上限：** 無料

🔗 https://azure.microsoft.com/ja-jp/products/devtest-lab/

🔗 https://azure.microsoft.com/ja-jp/products/cost-management/

### Monitor

Monitorは、Azureのシステムやアプリケーションの稼働状況を把握し、問題発生を検知・通知するサービスです。CPU使用率やメモリ消費量、ネットワークトラフィックなどのメトリクスを収集・分析し、異常をリアルタイムで教えてくれます。例えば、ウェブサイトへのアクセスが急増して遅延が発生した場合、すぐにアラートを受け取って対応できるため、サービスの安定運用に役立ちます。ログ分析機能を使えば、エラーの原因究明も効率的に行えます。

**毎月の上限：** 機能ごとの無料利用額については、Azure Monitor の料金詳細を参照する

🔗 https://azure.microsoft.com/ja-jp/products/monitor/

---

### Resource Manager

Azure Resource Manager（ARM）は、Azureリソースを管理するためのサービスです。テンプレートを使って、仮想マシンやストレージ、ネットワークなどのリソースをまとめてデプロイ、設定、管理できます。これにより、インフラの構築を自動化し、一貫性を保ち、迅速な展開が可能になります。例えば、新しいWebアプリケーションを開発する際に、必要なサーバー、データベース、ネットワーク設定をテンプレート化しておけば、いつでも同じ環境を簡単に作成・再現できます。

**毎月の上限：** 無料

🔗 https://azure.microsoft.com/ja-jp/get-started/azure-portal/resource-manager/

## 🛡️ セキュリティ

### Azure Attestation

Azure Attestationは、実行中のコードやハードウェアが信頼できる環境で動作していることを証明するサービスです。これにより、機密性の高いデータやアプリケーションを保護し、セキュリティリスクを軽減できます。例えば、IoTデバイスが改ざんされていないことを証明したり、プルーフ・オブ・ステーク（POS）などのブロックチェーン技術でノードの正当性を確認したりするのに役立ちます。

**毎月の上限：** 無料

🔗 https://azure.microsoft.com/ja-jp/products/azure-attestation/

---

### Security Center

Security Centerは、Azure環境全体のセキュリティ状態を可視化し、脅威を検知・対応するサービスです。まるで、お家の警備員のように、勝手な侵入者や危険な活動がないか常に監視し、異常があればすぐに知らせてくれます。例えば、見慣れない場所からのアクセスがあったり、データが不正に操作されそうになったりした場合に、アラートを発してくれます。これにより、サイバー攻撃から大切なデータを守り、安心してクラウドを利用できるようになります。

**毎月の上限：** 無料のポリシー評価と推奨事項

🔗 https://azure.microsoft.com/ja-jp/products/defender-for-cloud/
