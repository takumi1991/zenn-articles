# Azure常時無料サービス一覧

### Azure AI Search

Azure AI Searchは、Webサイトやアプリケーションに高度な検索機能を簡単に組み込めるマネージド検索サービスです。大量のデータから関連性の高い情報を高速に見つけ出し、ユーザーエクスペリエンスを向上させます。例えば、ECサイトでの商品検索、社内ドキュメント検索、カスタマーサポートにおけるFAQ検索などに活用できます。AIを活用した検索機能により、自然言語でのあいまい検索や、画像・音声コンテンツからの情報抽出も可能となり、よりリッチな検索体験を提供します。

**毎月の上限：** サービスごとに 10,000 件のホスト ドキュメントと 3 つのインデックスを保存できる 50 MB のストレージ

🔗 https://azure.microsoft.com/ja-jp/products/ai-services/ai-search/

---

### Azure Language

Azure Language は、自然言語処理（NLP）の機能を提供するクラウドサービスです。テキストデータから、文書の感情分析、重要なキーワードの抽出、人名や地名などの固有表現の認識、さらには原文の言語判定まで、高度なインサイトを自動で引き出すことができます。これにより、顧客からのフィードバック分析、ニュース記事の要約、ソーシャルメディアのトレンド把握、ドキュメントの自動分類といった多様なアプリケーション開発に活用できます。開発者は、複雑なNLPモデルを自ら構築・管理する手間なく、これらの強力な機能を手軽に利用することが可能です。

**毎月の上限：** 5,000 テキスト レコード

🔗 https://azure.microsoft.com/ja-jp/products/ai-foundry/tools/language

---

### AI Bot Service

AI Bot Service は、高度な対話型AIを搭載したエンタープライズグレードのボットを、ビジネスニーズに合わせて柔軟に拡張しながら構築できるプラットフォームです。顧客サポートの自動化、社内ヘルプデスクの効率化、あるいはパーソナルアシスタントとして、様々なユースケースで活用できます。自然言語理解能力により、ユーザーの意図を正確に把握し、複雑な問い合わせにも適切に対応するインテリジェントな応答を提供します。開発者は、豊富なSDKやツールを活用して、迅速かつ効率的にボットを開発・展開できます。

**毎月の上限：** プレミアム チャネル メッセージ 10,000 件と無制限の標準チャネル メッセージ

🔗 https://azure.microsoft.com/ja-jp/products/ai-services/ai-bot-service/

### AI Immersive Reader

AI Immersive Reader は、アプリケーションに高度なテキスト読み上げと読解支援機能を統合するための Azure Cognitive Service です。このサービスを利用することで、ユーザーはテキストを自然な音声で聞くだけでなく、単語の意味や品詞の特定、文章の翻訳、さらには難易度の高い語彙の平易な言葉への置き換えといった、より深いレベルでのテキスト理解を促進できます。例えば、教育分野では学習者の読解力向上を支援する教材作成に、アクセシビリティ向上においては視覚障害を持つユーザーや言語学習者のためのコンテンツ提供に活用できます。これにより、より多くの人々が情報にアクセスしやすくなり、学習体験が豊かになります。

**毎月の上限：** 300 万文字

🔗 https://azure.microsoft.com/ja-jp/products/ai-services/ai-immersive-reader/

### 音声テキスト変換

音声テキスト変換は、音声を高精度なテキストデータに変換するAzureのサービスです。会議の議事録作成、コールセンターでの顧客対応分析、字幕生成、音声コマンドの理解など、幅広い用途で活用できます。リアルタイムの音声ストリームや保存されたオーディオファイルを処理でき、話者分離やカスタム語彙の登録といった高度な機能も提供し、様々なビジネスシーンでの音声データの活用を強力に支援します。

**毎月の上限：** リアルタイム音声テキスト変換を毎月 5 時間分の音声に使用可能

🔗 https://azure.microsoft.com/ja-jp/products/ai-foundry/tools/speech

### テキスト読み上げ

テキスト読み上げは、自然な響きの音声を生成するAzure Cognitive Servicesの一つです。このサービスを利用することで、入力されたテキストを多様な言語や声質で音声化するアプリケーションを開発できます。例えば、オーディオブックの作成、アクセシビリティ機能の向上、コールセンターにおける応答メッセージの自動生成、教育コンテンツへの音声ガイダンスの追加など、幅広い用途に活用されています。開発者は、APIを通じて簡単にテキストを音声に変換する機能を自身のアプリケーションに組み込むことができます。

**毎月の上限：** 標準ニューラル音声を毎月 50 万文字分使用可能

🔗 https://azure.microsoft.com/ja-jp/products/ai-foundry/tools/speech

### 音声翻訳

Azure 音声翻訳は、リアルタイムで話し声を高精度にテキスト化し、さらにそれを多言語の音声へと変換するサービスです。この機能により、国際会議でのリアルタイム通訳や、グローバルな顧客サポートにおける言語の壁の解消、教育現場での異文化理解促進など、多様なシーンでコミュニケーションを円滑にすることが可能になります。従来の翻訳ツールでは難しかった、自然な会話の流れを維持したまま、迅速かつ正確な言語処理を実現します。

**毎月の上限：** リアルタイム音声翻訳 (標準音声) を毎月 5 時間分の音声に使用可能

🔗 https://azure.microsoft.com/ja-jp/products/ai-foundry/tools/speech

### 翻訳ツール

Azure 翻訳ツールは、アプリケーション、Web サイト、および各種ソリューションに、高度な機械翻訳機能を手軽に組み込むことを可能にします。このサービスを利用することで、世界中のユーザーに向けて、多言語での情報提供やコミュニケーションをスムーズに実現できます。例えば、グローバル展開するECサイトの製品説明を複数の言語に自動翻訳したり、多言語対応のカスタマーサポートチャットボットを構築したりすることで、顧客体験を向上させ、ビジネスのリーチを拡大することが可能です。開発者は、API を介して迅速に翻訳機能を統合し、迅速な多言語展開を実現できます。

**毎月の上限：** 標準翻訳とカスタム翻訳トレーニングを、任意の組み合わせで 200 万文字に使用可能

🔗 https://azure.microsoft.com/ja-jp/products/ai-foundry/tools/translator

### Face

Azure Face APIは、画像内の顔を識別し、その特徴を分析するクラウドベースのサービスです。顔の検出、性別、年齢、感情、姿勢などの属性推定、さらには顔の類似性比較や個人識別まで実行できます。これにより、写真アルバムの整理、ソーシャルメディアでの顔検出、セキュリティシステムへの顔認識機能の統合、顧客の感情分析によるマーケティング戦略の最適化など、多岐にわたるアプリケーション開発が可能になります。

**毎月の上限：** Free インスタンスの 30,000 トランザクション

🔗 https://azure.microsoft.com/ja-jp/products/cognitive-services/face/

🔗 https://azure.microsoft.com/ja-jp/products/open-datasets/

### Content Safety

Azure Content Safetyは、AIを活用してテキストと画像に含まれる不適切または有害なコンテンツを検出・軽減するためのクラウドサービスです。これにより、ユーザーが生成するコンテンツの安全性を高め、不快な体験を未然に防ぎます。例えば、オンラインコミュニティでのヘイトスピーチや画像共有プラットフォームでの不適切画像のフィルタリング、AI生成コンテンツにおける倫理的な問題の回避などに活用できます。開発者はこのサービスを利用することで、より安全でポジティブなユーザーエクスペリエンスを構築し、プラットフォームの信頼性を向上させることが可能です。

**毎月の上限：** AKS クラスターの管理は無料です。ノードによって消費されるリソースに対して料金が発生します

🔗 https://azure.microsoft.com/ja-jp/products/ai-services/ai-content-safety/

### Data Catalog

Azure Data Catalogは、組織内のデータ資産を登録・管理し、発見を容易にするサービスです。これにより、データサイエンティストやアナリストは、必要なデータを効率的に見つけ出し、分析やインサイト抽出に活用できます。例えば、社内のさまざまな部署が持つ顧客データ、販売データ、Webアクセスログなどを一元管理することで、データ間の関連性を把握したり、新たなビジネスインテリジェンスを創出したりする際の強力な基盤となります。データレイクやデータウェアハウスなどのストレージに散在するデータを整理し、利用可能な状態にすることで、データドリブンな意思決定を推進します。

**毎月の上限：** ユーザー数無制限

🔗 https://azure.microsoft.com/ja-jp/products/data-catalog/

### Data Factory

Azure Data Factoryは、さまざまなデータソースからデータを移動・変換するためのクラウドベースのETL（抽出、変換、読み込み）およびデータ統合サービスです。これにより、データレイクやデータウェアハウスへのデータ取り込み、ストリーミングデータの処理、機械学習パイプラインの自動化など、複雑なデータワークフローを効率的に構築・実行できます。例えば、オンプレミスのデータベースからAzure Synapse Analyticsへ定期的にデータをロードしたり、複数のSaaSアプリケーションからデータを集約して分析基盤を構築したりといったユースケースに活用できます。コーディングを最小限に抑え、視覚的なインターフェイスでデータパイプラインを設計・管理できるのが特徴です。

**毎月の上限：** 5 つの低頻度アクティビティ

🔗 https://azure.microsoft.com/ja-jp/products/data-factory/

### App Service

App Serviceは、WebアプリやAPIを開発、デプロイ、管理するための、フルマネージドなAzureのPaaS（Platform as a Service）です。開発者はインフラストラクチャの管理に煩わされることなく、コードの開発に集中できます。例えば、顧客向けに最新のWebサイトを構築したり、社内システムと連携するRESTful APIを開発したりする際に活用できます。自動スケーリング機能により、アクセス数の増減に応じてリソースを柔軟に調整できるため、常に安定したパフォーマンスを提供し、コスト効率も最適化できます。DevOpsツールとの連携も容易で、迅速なリリースサイクルを実現します。

**毎月の上限：** 最大 10 個の Web アプリまたは API アプリ、1 GB のストレージ、1 日あたり 1 時間

🔗 https://azure.microsoft.com/ja-jp/products/app-service/

### Azure Kubernetes Service (AKS)

Azure Kubernetes Service (AKS) は、コンテナー化されたアプリケーションのデプロイ、管理、スケーリングを簡素化するマネージド Kubernetes サービスです。開発者は、使い慣れたツールやワークフローを活用して、コンテナー化されたアプリケーションを迅速に構築し、運用できます。これにより、インフラストラクチャの管理負担を軽減し、ビジネス価値の創出に集中できます。例えば、マイクロサービスアーキテクチャを採用したWebアプリケーションのバックエンドや、データ分析パイプライン、機械学習モデルのデプロイメントなど、多様なユースケースで活用されています。AKS は、自動化された機能と堅牢なセキュリティ機能を提供し、高可用性とスケーラビリティを実現します。

**毎月の上限：** AKS クラスターの管理は無料です。ノードによって消費されるリソースに対して料金が発生する

🔗 https://azure.microsoft.com/ja-jp/products/kubernetes-service/

### Azure VM Image Builder

Azure VM Image Builderは、カスタム仮想マシン（VM）イメージの作成、更新、管理を自動化・効率化するサービスです。OSのインストールからアプリケーションの展開、セキュリティパッチの適用まで、一連のイメージ構築プロセスをコードで定義し、再現性高く実行できます。このサービスを活用することで、開発環境やテスト環境、本番環境で一貫したOSイメージを迅速に準備し、デプロイメントのリードタイムを短縮したり、コンプライアンス要件に適合したイメージを維持したりすることが可能になります。例えば、特定のミドルウェアやツールがあらかじめインストールされたLinuxイメージを定期的に更新するといった運用に役立ちます。

**毎月の上限：** VM Image Builder は無料のサービスです。構築時にデータ転送や有料の Azure サービスを利用すると、料金が発生する場合があります

🔗 https://azure.microsoft.com/ja-jp/products/image-builder/

### Batch

Azure Batchは、大規模なコンピューティングワークロードをクラウドで効率的に実行するためのマネージドサービスです。大量の計算処理を必要とするタスク（例えば、科学技術計算、レンダリング、メディアエンコーディングなど）を、必要に応じて自動的にスケールアップ・スケールダウンされる仮想マシン上で並列実行します。これにより、インフラストラクチャの管理に煩わされることなく、開発者はアプリケーション開発に集中できます。バッチ処理、ハイパフォーマンスコンピューティング（HPC）アプリケーション、AI/MLのトレーニングなどに最適で、コスト効率とパフォーマンスの向上に貢献します。

**毎月の上限：** なし

🔗 https://azure.microsoft.com/ja-jp/products/batch/

### Functions

Azure Functionsは、イベント駆動型のサーバーレスコンピューティングサービスです。コードを実行するためにインフラストラクチャを管理する必要がなく、HTTPリクエスト、タイマー、キューメッセージなど、様々なトリガーに応じてコードを自動的に実行できます。これにより、APIバックエンド、リアルタイムデータ処理、タスク自動化など、多様なアプリケーションを効率的に構築できます。例えば、画像がストレージにアップロードされたらサムネイルを自動生成したり、定期的にデータベースのバックアップを実行したりするシナリオで活用できます。開発者はビジネスロジックに集中できるため、迅速な開発とコスト削減が実現します。

**毎月の上限：** 100 万回のリクエスト

🔗 https://azure.microsoft.com/ja-jp/products/functions/

### Static Web Apps

Azure Static Web Appsは、静的コンテンツとWeb APIを効率的にデプロイ・ホストできるフルマネージドサービスです。ReactやVue.jsなどのモダンなフロントエンドフレームワークで開発されたシングルページアプリケーション（SPA）や、Azure Functionsと連携したバックエンドAPIを持つアプリケーションのデプロイに最適です。ソースコードのコミットをトリガーに自動ビルド・デプロイが行われ、グローバルに分散されたCDNにより低レイテンシでの配信と高い可用性を実現します。GitHub ActionsやAzure DevOpsとの連携も容易で、開発から運用までをシンプルに統合し、迅速なアプリケーション公開を支援します。

**毎月の上限：** サブスクリプションあたり 100 GBの帯域幅、2 つのカスタム ドメイン、アプリあたり 0.5 GB のストレージ

🔗 https://azure.microsoft.com/ja-jp/products/app-service/static/

### Azure コンテナー ストレージ

Azureコンテナー ストレージは、Dockerコンテナーなどのステートフルなアプリケーションがデータを永続化するためのソリューションです。データはコンテナーのライフサイクルに依存せず、再起動や再デプロイ後も保持されるため、データベースやカスタムアプリケーションのデータ保存に最適です。これにより、コンテナー化されたアプリケーションでも、データの信頼性と可用性を確保し、ビジネス継続性を高めることができます。例えば、Webアプリケーションのセッション情報や、分析ツールの処理結果などを安全に保存・管理することが可能です。

**毎月の上限：** このサービスでは、ストレージ プール容量 5 TiB 未満のデプロイ向けに Free レベルが提供されます

🔗 https://azure.microsoft.com/ja-jp/products/container-storage/

### Container Apps

Azure Container Appsは、コンテナー化されたアプリケーションやマイクロサービスを、インフラストラクチャ管理なしで容易に構築・デプロイできるサーバーレスプラットフォームです。コードをコンテナーイメージ化するだけで、スケーリング、ロードバランシング、TLS終端といった運用上の複雑さを気にせず、アプリケーションの実行に集中できます。例えば、Web API、バッチ処理ジョブ、イベント駆動型マイクロサービスなどの開発に最適で、開発者は迅速にビジネスロジックに注力できます。これにより、開発サイクルの短縮と運用コストの削減を実現します。

**毎月の上限：** 180,000 vCPU 秒、360,000 GiB 秒、200 万リクエスト

🔗 https://azure.microsoft.com/ja-jp/products/container-apps/

### Service Fabric

Service Fabric は、ステートフルおよびステートレスなマイクロサービスを、信頼性が高く、スケーラブルで、常時稼働する環境で開発、デプロイ、管理するための分散システムプラットフォームです。このサービスを利用することで、開発者は複雑な分散アプリケーションの構築に集中でき、インフラストラクチャの管理にかかる負担を軽減できます。例えば、リアルタイムの分析処理、IoT デバイスの管理、ゲームのバックエンドサービスなど、高い可用性と低レイテンシが求められるユースケースに適しています。Service Fabric は、アプリケーションのライフサイクル管理を自動化し、障害発生時にも迅速な復旧と高可用性を実現します。

**毎月の上限：** なし

🔗 https://azure.microsoft.com/ja-jp/products/service-fabric/

### Azure Cosmos DB

Azure Cosmos DBは、グローバル規模で展開可能な、マルチモデル対応のNoSQLデータベースサービスです。高可用性と低レイテンシーを実現し、あらゆる規模の最新アプリケーション開発を支援します。IoTデバイスからの膨大なデータ収集、リアルタイム分析、ゲームのセッション管理、パーソナライズされたレコメンデーションなど、迅速なデータアクセスとスケーラビリティが求められる様々なユースケースで活用されています。HTTP/REST APIや多様なSDKを通じて、JavaScript、.NET、Java、Pythonなど、様々なプログラミング言語からアクセス可能です。

**毎月の上限：** 1,000 要求ユニット/秒のプロビジョニング済みスループット、25 GB のストレージ

🔗 https://azure.microsoft.com/ja-jp/products/cosmos-db/

Azure Resource Mover は、Azure リソースを異なるリージョンやサブスクリプション間で、ダウンタイムを最小限に抑えながら効率的に移動できるサービスです。例えば、開発環境から運用環境への移行や、災害対策のためにリソースを別リージョンに複製したい場合などに活用できます。このサービスを利用することで、個々のリソースの手動での再構成や設定変更にかかる手間と時間を大幅に削減し、デプロイメントの迅速化とリスク低減を実現します。

**毎月の上限：** 無料 (イングレスとエグレスの料金が適用される場合があります)

🔗 https://azure.microsoft.com/ja-jp/products/resource-mover/

### Azure Update Manager

Azure Update Managerは、Azure VM、オンプレミスサーバー、およびその他のクラウド環境のWindowsおよびLinuxマシン全体で、ソフトウェア更新プログラムの展開と管理を集中化するための包括的なソリューションです。このサービスを利用することで、組織はパッチ管理プロセスを自動化し、コンプライアンスを確保し、セキュリティリスクを低減できます。例えば、最新のセキュリティパッチをすべてのサーバーに定期的に適用したり、特定のアプリケーションに必要な更新プログラムのみを展開したりすることが可能です。Azure Update Managerは、更新プログラムの展開状況を詳細に把握できるレポート機能も備えており、IT管理者は常にシステムの状態を把握できます。これにより、運用効率が向上し、ダウンタイムを最小限に抑えることができます。

**毎月の上限：** Azure リソースは無料 (Arc 対応サーバーは課金対象) です。詳細は価格ページをご覧ください

🔗 https://azure.microsoft.com/ja-jp/products/azure-update-management-center/

### Cloud Shell

Cloud Shellは、WebブラウザーからAzureリソースを直接操作できるクラウドベースのシェル環境です。BashまたはPowerShellを選択でき、Azure CLIやAzure PowerShellなどのツールがプリインストールされているため、特別な環境構築なしに、仮想マシン、ストレージ、ネットワークなどのデプロイや設定変更、スクリプト実行が可能です。例えば、外出先からでも素早くAzure環境の確認や修正を行いたい場合や、開発・テスト環境での迅速なリソース管理に役立ちます。これにより、ローカル環境へのツールのインストールや設定の手間を省き、場所を選ばずにAzure管理業務を効率化できます。

**毎月の上限：** Azure Files での 12 か月間 5 GB の無料ストレージ

🔗 https://azure.microsoft.com/ja-jp/get-started/azure-portal/cloud-shell/

### Cost Management

Azure Cost Management は、Azure 環境におけるコストを詳細に把握し、最適化するための包括的なサービスです。これにより、組織はリソースの使用状況とそれに関連するコストをリアルタイムで可視化し、予測できます。例えば、開発チームが特定プロジェクトの予算超過を早期に検知し、不要なリソースの停止やサイズ変更を検討することで、無駄な支出を削減するといった活用が可能です。また、各部門やプロジェクトごとにコストを正確に割り当てるためのタグ付け機能や、コスト削減のための推奨事項も提供され、クラウド利用の効率化と財務健全性の維持を支援します。

**毎月の上限：** なし

🔗 https://azure.microsoft.com/ja-jp/products/cost-management/

### Monitor

Azure Monitorは、アプリケーション、インフラストラクチャ、ネットワークといったITリソースの状態を包括的に把握し、パフォーマンスの最適化や問題の早期発見を支援するサービスです。サーバー、仮想マシン、Webアプリ、データベースなど、Azure内外のあらゆるリソースからメトリクス（数値データ）やログ（イベント記録）を収集・分析します。これにより、リソースの応答時間、CPU使用率、エラー発生率などをリアルタイムで可視化し、異常を検知した際にはアラートを通知することが可能です。例えば、Webサイトのレスポンスが悪化した場合、その原因を特定するためにAzure Monitorで関連するリソースのメトリクスやログを確認し、ボトルネックとなっている箇所を突き止めて迅速に対処するといった運用に役立ちます。

**毎月の上限：** 機能ごとの無料利用額については、Azure Monitor の料金詳細を参照する

🔗 https://azure.microsoft.com/ja-jp/products/monitor/

### Resource Manager

Azure Resource Manager (ARM) は、Azure 上のリソースを効率的にデプロイ、管理、および整理するためのサービスです。ARM を利用することで、仮想マシン、ストレージ、ネットワークといった Azure リソースを、テンプレートを用いて宣言的に定義し、一貫性のある方法でプロビジョニングできます。これにより、手動での操作ミスを防ぎ、インフラストラクチャの再現性を高めることができます。例えば、開発環境やステージング環境を迅速かつ確実に構築したり、大規模なシステムを複数のリソースグループに分けて管理したりする際に役立ちます。また、アクセス制御のポリシーを適用することで、リソースへのアクセス権限を細かく管理することも可能です。

**毎月の上限：** なし

🔗 https://azure.microsoft.com/ja-jp/get-started/azure-portal/resource-manager/

### Azure Migrate

Azure Migrateは、オンプレミス環境のIT資産をAzureクラウドへスムーズに移行するための統合プラットフォームです。このサービスを利用することで、既存の仮想マシンやサーバー、データベース、Webアプリケーションなどを発見・評価し、移行計画の策定、コスト見積もり、そして実際の移行作業までを一元的に実行できます。例えば、老朽化したオンプレミスサーバーの刷新や、災害対策・事業継続計画（BCP）の強化を目的としたクラウド移行において、Azure Migrateは計画段階でのリスク低減と移行期間の短縮に大きく貢献します。Azure Migrateを活用することで、お客様はビジネスの俊敏性を高め、ITインフラの運用コストを最適化することが可能になります。

**毎月の上限：** なし

🔗 https://azure.microsoft.com/ja-jp/products/azure-migrate/

### Azure Storage Mover

Azure Storage Mover は、オンプレミスのファイルストレージや他のクラウドストレージから Azure のストレージサービスへ、ダウンタイムを最小限に抑えながらデータ移行を行うためのマネージドサービスです。これにより、企業はレガシーシステムから迅速かつ効率的に Azure へ移行し、最新のクラウドストレージ機能やスケーラビリティを活用できるようになります。例えば、長年利用してきたファイルサーバーのデータを Azure Files へ移行することで、運用コストの削減やデータアクセスの利便性向上を実現できます。また、既存のストレージ環境に影響を与えずに、増え続けるデータを Azure へ安全に集約することが可能です。

### Notification Hubs

### Bandwidth (データ転送)

Azure Bandwidthは、Microsoftのグローバルネットワークインフラストラクチャを活用し、Azureサービス間で、あるいはAzureとオンプレミス環境間での、安全かつ信頼性の高いデータ転送を可能にするサービスです。大量のデータを迅速に移動させたい、グローバルな拠点間でデータを同期させたい、といったニーズに応えます。例えば、Azure Blob Storageに保存されたビッグデータを分析のためにオンプレミスのデータセンターに転送したり、各地の支社からAzure上のアプリケーションへリアルタイムにデータを集約したりする際に利用できます。これにより、ビジネスの俊敏性を高め、グローバル展開を加速させることが可能です。

### Network Watcher

Network Watcherは、Azure仮想ネットワークのパフォーマンスと健全性を継続的に監視、診断、分析するための統合サービスです。ネットワーク接続の問題を迅速に特定し、原因を究明するために、パケットキャプチャ、IPフロー検証、接続トラブルシューティングなどの機能を提供します。これにより、アプリケーションの可用性を維持し、ユーザーエクスペリエンスを向上させることが可能です。例えば、仮想マシン間の通信が遅延している場合、Network Watcherを使用してボトルネックとなっている箇所を特定し、設定の最適化やリソースの追加といった対策を講じることができます。また、ネットワークセキュリティグループのルールが意図せず通信をブロックしている場合も、このサービスで確認し、修正することができます。

**毎月の上限：** 1,000 件のチェック、10 件のテスト、10 件の接続メトリックを含む 5 GB のストレージ

🔗 https://azure.microsoft.com/ja-jp/products/network-watcher/

### Private Link

**毎月の上限：** なし

### Virtual Network

Azure Virtual Network（VNet）は、Azureクラウド上に構築されるプライベートネットワーク機能であり、仮想マシンのようなAzureリソースが相互に通信するための基盤を提供します。これにより、クラウド環境内に安全で隔離されたネットワーク空間を構築できます。例えば、複数の仮想マシンをVNet内に配置し、それぞれにIPアドレスを割り当てることで、あたかもオンプレミスのネットワークのようにリソース間をセキュアに通信させることが可能です。さらに、VPNゲートウェイやExpressRouteを利用して、オンプレミスのデータセンターや他のクラウド環境との間に安全な接続を確立し、ハイブリッドクラウド環境を構築することもできます。このように、VNetはAzureでのネットワークインフラストラクチャの要となります。

**毎月の上限：** 50 仮想ネットワーク

🔗 https://azure.microsoft.com/ja-jp/products/virtual-network/

### Azure Attestation

**毎月の上限：** なし

Azure SignalR Serviceは、Webアプリケーションやモバイルアプリにリアルタイムの双方向通信機能を容易に実装できるマネージドサービスです。これにより、チャットアプリケーション、ライブ更新、ゲーム、通知システムなどの開発が簡素化されます。開発者は複雑なWebSocketインフラストラクチャを管理する必要がなく、スケーラブルで高可用性なリアルタイム機能を提供できます。例えば、株価のリアルタイム表示や、共同編集ツールでの複数ユーザーの操作反映などを実現する際に活用できます。
